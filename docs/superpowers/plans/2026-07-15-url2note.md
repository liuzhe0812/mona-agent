# URL2Note Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (recommended) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add one `url2note` extraction path for browser and Agent requests, then save generated Markdown to the notes-vault root.

**Architecture:** `mona/api/url2note.py` owns URL validation, article extraction, subtitle parsing and audio fallback. `VideoRuntime` only locates/downloads binaries into Mona resources. The browser asks the gateway for extracted text, asks the existing chat endpoint to format it, and invokes the existing notes command without a notebook ID.

**Tech Stack:** Python/aiohttp, existing `WebFetchTool`, yt-dlp/FFmpeg executables, existing transcription providers, React/TypeScript, Tauri notes IPC.
