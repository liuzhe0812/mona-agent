# 订阅权限与注册试用设计

## 目标

让登录成为 Mona 的使用前提，并把免费版与 Mona Pro 的能力边界、锁定入口和订阅展示统一起来。保留现有月付、季付、年付套餐，不改变支付渠道。

## 权益边界

| 状态 | 可用能力 |
| --- | --- |
| 未登录 | 只显示注册/登录界面，不能进入工作区。 |
| 免费版 | 完整本地笔记、终端、数据库、邮件等基础操作；Mona 基础对话。Agent 不得查询或读取既有笔记、邮件。 |
| Mona Pro | 免费版全部能力，加上笔记、终端、数据库、邮件中的场景 AI；知识库、AI 文档和跨模块知识沉淀。 |

“本地基础操作”与“场景 AI”必须分开：免费用户可以手工处理本地数据，但不能通过 Pro Agent 读取笔记或邮件内容。

## 登录与试用

1. 删除客户端本地试用的创建、显示和访问兜底逻辑；无登录时不能以本地试用获得 Pro 权限。
2. 注册成功后由认证服务创建服务端试用。已启用且在有效期内的“注册赠试用活动”使用活动配置天数；否则使用服务端 `trial_days=30` 的默认值。
3. 既有的设备试用防重复规则保留；同一设备已领取过试用时不再创建试用。
4. 已缓存的、由服务端验证过的有效订阅/试用可以继续用于离线访问；网络失败不能生成新的本地试用。

## 订阅与支付

1. 套餐代码仅接受 `monthly`、`quarterly`、`yearly`；移除 `lifetime` 下单入口。
2. 套餐价格、名称、原价和推荐标识继续由官网价格配置接口提供，客户端不复制价格。
3. 订阅页按“3 项核心收益 → 月/季/年套餐 → 支付”展示：
   - 让 Mona 理解你的工作上下文（笔记与邮件）；
   - 在终端、数据库中直接获得 AI 协作；
   - 使用知识库、AI 文档与跨模块知识沉淀。
4. 套餐有原价时，在现价旁显示“早期用户价”。不新增自动续费、支付渠道或支付协议功能。

## 锁定交互

1. 所有 Pro 功能入口继续可见。知识库和 AI 文档的入口显示锁定状态，点击打开订阅页；不再从侧边栏过滤。
2. 笔记、终端、数据库、邮件的基础界面保留；其场景 AI 入口在免费版显示锁定状态，点击打开订阅页。
3. 后端工具注册与执行层继续作为最终防线：非 Pro 请求不得获得笔记或邮件查询/读取工具，即使绕过前端也不能访问内容。

## 非目标

- 不更改月付、季付、年付的价格、排序、支付方式或线上官网配置。
- 不修改已有用户的订阅和试用到期时间。
- 不新增终身套餐、自动续费产品或新的支付集成。

## 验收

1. 未登录启动不能进入工作区；注册后试用时间来自活动天数或默认 30 天，绝不来自本地时钟。
2. 免费用户能看到所有 Pro 入口，点击任一锁定入口可到订阅页；基础本地操作仍可用。
3. 免费 Agent 的可用工具列表和实际执行都不包含笔记/邮件查询与读取。
4. 季付可创建订单，终身套餐请求被拒绝。
5. 订阅页在套餐前显示三项核心收益，并为有原价的套餐显示“早期用户价”。
