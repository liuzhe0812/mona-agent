# Mona Terminal 批量 SSH 模式设计方案

## 概述

设计一个批量 SSH 模式，支持左侧会话列表，右侧会话标签+批量命令输入框，提供多服务器批量操作能力。

---

## 核心功能设计

### 批量操作流程

```
用户在批量输入框输入命令
        ↓
    发送到所有选中的会话
        ↓
    并行执行
        ↓
    在对应的终端显示结果
```

### 批量命令特性

| 功能 | 说明 |
|------|------|
| **同步发送** | 命令同时发送到所有选中连接 |
| **独立执行** | 每个终端独立执行，输出独立显示 |
| **实时反馈** | 多个终端同时滚动显示输出 |
| **错误高亮** | 某个连接执行失败时高亮标签 |

---

## 推荐方案对比

| 特性 | 方案一：可切换视图 | 方案二：独立标签 |
|------|------------------|----------------|
| **与现有整合度** | 高，直接替换现有布局 | 中，保持现有标签栏 |
| **用户发现成本** | 中，需要知道有切换按钮 | 低，标签栏直接可见 |
| **单/多模式切换** | 一键切换，方便对比 | 需要关闭批量标签，略有不便 |
| **推荐度** | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |

**我推荐方案二（独立标签）**，因为：
1. 用户更容易发现
2. 不破坏现有单会话体验
3. 批量操作和单会话可以同时打开，更好的多任务体验

## 状态管理

```typescript
// 批量模式状态
interface BatchModeState {
  selectedSessions: string[];  // 选中的会话ID
  allSessions: BatchSession[]; // 所有打开的会话
}

interface BatchSession {
  id: string;
  name: string;
  host: string;
  status: 'connecting' | 'connected' | 'error';
}
```
