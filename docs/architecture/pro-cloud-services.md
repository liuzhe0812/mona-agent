# Mona Pro：设备与个人云工作空间

状态：用户已批准，基础云服务和账号密钥托管已在生产启用；客户端源码及必要验证完成，尚未重新打包。

## 产品边界

- 所有本地工具及其业务入口不以 Pro、订阅或试用状态为使用门槛，包括 Agent、笔记/资料问答、Office、邮件 AI 与日程提取、数据库、开发/运维、生图/视频和股票研究。工具注册、可见性和实际执行遵循同一规则；工具授权、数据范围、操作确认、运行环境、模型认证和模型余额检查仍然有效。
- Token 由用户自有模型来源或预充值承担；Pro 不赠送模型用量。
- 免费账号最多 1 台登录设备，已生效的 Pro 账号最多 3 台；多设备登录是独立权益，不以是否开启同步为条件。普通试用状态不自动增加设备名额，也不赠送云端容量。
- “设备”指同账号中仍有效的桌面设备登录，不是进程、窗口、安装次数或历史设备数量。关闭应用不自动退出；明确退出/移除设备释放名额。网页登录后台不冒充桌面设备，不能使用桌面设备专属云接口。
- 达到上限后，验证账号凭据并展示本人的设备列表；只有用户明确选择退出的设备才允许替换，不静默挤掉其他设备。免费用户可以换机，不设置累计一生一次的换机限制。
- Pro 到期后，云服务按权益降级；设备访问保留最早登记且仍有效的 1 台，其余设备可由用户在再次登录时明确替换。离线设备无法即时被远程注销，联网请求必须重新校验；不删除任何设备本地资料，也不强停正在运行的本地任务。

## 订阅支付与权益保护

- 当前已有有效 Pro（包括长期有效）时不重复创建订阅订单。历史订单稍后付款或回调时，记录已支付并幂等完成履约；历史订单、充值赠送及赠送退款扣回均不得将长期有效权益改为有限期限或过期。
- 套餐下架只阻止新订单；已经创建且经校验确认付款的订单仍完成开通。金额、商户身份、签名校验及重复回调保护保持有效。
- 后台补单每批最多核对 50 笔近 7 天的未完成支付宝订单，跨批次轮转，未打开的支付链接或单笔查询失败不能长期阻塞后续已付款订单。
- 关闭支付弹窗后重新读取权益，不重复发起支付。订阅与续费记录分别加载；查询失败保留已确认状态并允许刷新，不将无法查询解释为未订阅或无记录。

## 服务与存储

- 复用 `mona-auth/` 的账号、支付和 MariaDB。2核2GB VPS 只负责认证、设备会话、同步目录/版本、配额及对象授权，不运行用户 Agent、模型、文档解析或文件传输代理。
- 用户电脑对选定数据压缩、加密并直接上传七牛私有空间；下载也直连七牛。安装包/专家包/运行时分发与用户私有数据分开，不能拿现有公开下载域名承载私人资料。
- 私有下载可使用七牛提供的 HTTPS S3 服务域名，服务端签发绑定精确存储键和绝对截止时间的 AWS Signature V2 GET URL；既有自定义下载域名继续使用原七牛下载凭证。两种方式都由客户端直下，不向 React 暴露存储凭据，不需要为使用自带入口新增 DNS 或证书配置。
- 同步范围：**仅 Work 模式的普通会话**及其已关联附件/工作文件，另有笔记及附件、日程/待办、白名单内非敏感配置，以及用户独立选择的运维主机配置。开发会话、原生 CLI 状态、开发项目目录不在范围内；不得扫描/打包它们，也不新增开发同步入口。不同账号、Agent 知识与 Notes 的来源隔离保持不变。
- Work 会话保留完整持久对话、必要工具记录、摘要与计划；不从摘要反推原文。内容按完整记录分段，已有分段按密文内容标识复用，不在每次同步重传所有历史。
- Work 文件同步复用上传附件、明确交付和成功文件操作的真实归属记录。用户选定的 Mona 托管工作区支持同步业务文件；未授权目录、凭据和未知归属文件不因会话引用过一个路径而自动上传。文件标识与版本独立保存，会话只关联它，避免跨会话重复占用。
- 同步设置由 Gateway 原子更新，保存后的配置须能由完整配置加载器重新读取。关联文件缺失或超过单项上限时，该会话保留本地内容和原云版本，其他会话与同步类别继续处理；界面标明“部分内容待处理”，用紧凑的待处理入口代替常驻长红字。同步范围中受影响会话置顶，可批量取消选择，但须明确保存后生效；取消或关闭不变更真实范围。本地资料和已有云版本保留，整批状态不能把它们算作已完成。
- 新设备先拉取会话及文件目录，文件按需下载，选定范围可保留离线副本。下载后的会话只作为历史，不自动恢复旧 pending 命令/审批/任务运行态；继续执行必须由用户新请求发起并核对当前环境。并发离线编辑保留冲突分支，不覆盖历史或拼成同一轮执行。
- API Key、SSH 密码/私钥、Cookie、CLI 登录信息、运行中的任务、整个代码目录、依赖目录和模型缓存默认不上传。不能通过复制 SQLite、JSONL 或整个配置目录实现同步。
- 同步、备份和历史恢复是不同能力：同步支持多端增量提交/冲突，备份保留不可变快照，恢复建立新的可检查版本而不是覆盖当前未保存修改。
- 内容继续在客户端加密、直传私有空间；加密密钥由账号服务加密托管，服务端具备取得解密密钥的能力。普通首次启用只确认同步范围，不显示或要求用户抄写密钥；同账号新设备通过有效设备会话自动取得密钥，再按已确认的范围解密恢复。
- Auth 使用独立、持久保存的随机 32 字节托管加密密钥，以 AES-GCM 加密每账号的云空间密钥，认证附加数据绑定账号和空间。不得从登录密码临时派生、随登录重新生成或因账号密码重置而丢弃云空间密钥。托管加密密钥需受保护并备份，轮换时迁移已有密钥记录。
- 密钥获取只对当前账号的有效桌面设备开放，禁止网页登录、其他账号、被撤销设备读取。密钥只经过原生凭据所有者和 Gateway 私有桥，不返回 React 的状态、准备结果或普通配额响应，不写入日志。密码重置仍撤销旧设备会话；新设备重新登录后取得同一云空间密钥。
- 旧云空间保留原空间身份、数据密文和密钥校验值；在用户确认开启或保存范围时，用原设备已有密钥完成一次托管登记。没有原密钥的旧空间不得自动生成替代密钥；可在已有密钥的设备确认迁移，或一次性导入旧密钥。已确认的旧读取与本地资料不因迁移被删除。
- Pro 空间改为每账号共用 **10GB（10,000,000,000字节）**，不是每台设备10GB。密文、保留的历史版本及回收站计入实际占用，重复引用同一云对象只计一份，上传前事务预留。每月10GB下载、30天历史继续作为容量测算基线。值由服务端配置，不写死在前端；129元/年仅为前述测算方案，不能自动覆盖现有生产价格。
- 下载凭证的重复使用、Range/断点续传、七牛真实流量账单与申请量分别核算，不能把“签发一次URL”当作真实下载一次或严格流量上限。
- 下载计量分两种来源：本机按账号、UTC月份持久记录实际收到的密文字节，包含中断和重试；Auth 按七牛 Kodo V2 源站日志的 `SentBytes` 汇总账号下载记录。源站日志按不可变对象键及内容指纹幂等导入，重复请求分别累计，找不到所属空间的流量明确列为未归属；不保存签名 URL、IP 或 User-Agent。数据查询只允许当前有效设备读取本人的统计，不将缺少日志的零记录解释为真实零流量，也不据此启用月下载硬限制。
- 订阅到期不删除本地数据；云端停止新增写入。到期后已有内容默认允许下载30天，以服务端策略为准，签名下载授权不得超过截止时间；续订有效 Pro 后重新允许下载。超过下载期不自动删除云数据，已有历史、残留和回收站仍可明确管理；无法解密名称时显示类型和删除时间。删除与回收需独立策略和恢复验证，首期不部署自动清理用户数据的任务。

## 自动接收与本机上传

- 有效设备登录后自动接收同账号已有云内容，不要求再次选择云端会话或开启本机上传。后台接收不依赖用户打开设置或配置模型；登录成功会唤醒接收循环，网络失败不改变登录结果。没有云空间时不自动创建，也不上传本机资料。
- “上传本机资料”必须单独确认；会话选择及各类别开关仅授权本机上传，不阻止接收该账号已有内容。新设备默认没有上传授权，接收到的历史也不会隐式授权上传本机其他资料。
- “暂停同步”暂停本设备收发，重启及重新登录不会自行恢复。恢复只恢复原有策略，不新增上传授权；切换账号清除旧账号的上传范围，保留本设备的暂停意图。
- 旧版已确认的上传范围继续有效，旧版暂停状态继续保留；首次升级补读云历史，已确认版本按身份复用。恢复会话、主机配置和偏好均不恢复任何执行权限或运行态。
- 新设备收到笔记时，如从未配置仓库，由原生 Notes 在应用数据目录创建默认仓库。已有仓库选择、不可用路径或损坏的路径配置必须保留并明确报错，不能静默改用另一个目录；初始化目录与路径指针都需校验链接和解析后范围。

## 日程与待办同步

- 在上传范围中独立确认本机现有及后续的日程与待办，默认不因启用 Work 会话上传而上传。关闭该项不删除本地内容，云端已有内容仍自动接收。
- Gateway 复用同一账户、密钥、配额、版本日志和后台同步循环；业务数据通过带本地服务令牌的 Services 接口读取和条件写入，Gateway 不直接打开日程存储文件。
- 每条个人日程或待办对应独立云资源，更新、完成和已确认资源的删除按版本同步。只有个人日程参与；AI 自动任务、Cron 绑定、通知队列和运行结果不迁移。已有本地提醒观察状态保留，新设备仅安排未来个人提醒，不补跑错过的自动任务。
- 待办同步业务状态、时间、优先级和来源摘要，不复制邮箱凭据、邮件定位、私人本机路径或关联日程的本地标识；本机已有来源链接不被远端空值清除。
- 同步先核对本地内容指纹再写入，损坏的存储不能被当作空列表。两端同时编辑保留本地原条目和有明确名称的冲突副本；日程冲突副本默认关闭提醒，待办冲突副本不抢占重点排序。
- 删除与并发编辑冲突时优先保留修改，不静默丢弃内容。响应丢失按同一次提交身份核对，未确认创建成功的记录不向云端发送无效删除。
- 日程和待办复用 10GB 配额，正文只在客户端加密对象内保存。同步并不提供新的云端 Agent 或后台模型调用服务。

## 笔记及关联附件同步

- 上传范围单独确认本机笔记仓库及关联附件，默认关闭。只处理当前 Notes 仓库的笔记和正文明确关联的 `assets` 文件，不复制 Agent Knowledge、整个工作区、外部链接目标或本地凭据；关闭上传不阻止接收已有云笔记。
- Tauri Notes 是唯一笔记文件所有者；Gateway 通过受账号绑定保护的原生接口读取、分片传输和条件写入，不直接扫描或修改笔记目录。同步开始时绑定当前仓库身份，切换仓库后必须重新确认，旧保存请求和延迟回调不得写入新仓库。
- 每篇笔记独立同步标题、分类、完整正文、类型、别名、收藏及时间；本机聊天绑定、已应用消息标识和知识可见性不跨端授权。相同附件按内容标识复用；分片校验并确认全部附件可用后才发布笔记，不先展示缺图的成功状态。
- 保持现有笔记能力的大小边界：单篇正文最多2MiB、单个关联附件最多10MiB，每篇最多128个附件。超限或引用缺失明确报告并保留原文，不静默裁剪。现有笔记格式的一层分类、普通笔记、思维导图和流程图使用同一正文存储；不以同步为由新建资料库。
- 原生文件写入和本地编辑共享锁，在保存与删除前核对仓库身份和文件版本。批量删除先检查所有选中笔记，任一记录已被其他设备修改则不删除任何一项；不得自动读取新版并代替用户重新确认。前端串行处理自己的保存和删除请求，远端更新到达时保留当前输入；并发修改生成有明确名称的冲突副本，删除与修改冲突优先保留内容。普通保存返回真实文件版本，不用界面状态猜测保存成功。
- 恢复同步或新增同步类别时补读先前未选择的云历史；已确认版本按身份复用，不重新执行 Agent、旧通知或其他任务。Markdown 正文换行和末尾空白原样保留，避免跨端反复产生伪变化。空标题沿用本地笔记的合法语义，同步与恢复保留空标题，不阻断其他笔记。
- 笔记与附件复用个人10GB空间、客户端加密、对象配额与版本日志。关闭同步不删除本地或云数据；明确删除已同步笔记会产生版本化删除记录，但历史保留与回收站仍按独立策略实施。

## 使用偏好同步

- 上传范围单独确认界面使用偏好，默认关闭；云端已有偏好自动接收。白名单仅包含侧栏模块布局、启动默认页面、消息发送按键、快捷问答显示模式，读取和保存均复用 Tauri 原生 `settings.json` 所有者。
- 不复制完整配置文件，不上传模型供应商、API Key、CLI登录、工作区/笔记仓库路径、端口、操作权限、全局快捷键或同步授权本身。主题和语言等其他独立存储的设置不在本阶段白名单，不能泛称全部配置已经同步。
- 首次加入已有云空间时恢复其已保存偏好；后续以最近确认版本逐字段合并，不同字段的两端改动可以同时保留。同一字段发生并发修改时保留本机尚未上传的修改并提交新版本，旧云版本仍受历史策略保护。
- 原生保存共用文件锁与原子写入；远端更新及正常设置保存都核对当前偏好指纹。旧设置窗口不能静默把新同步值改回旧值，冲突时原数据保持不变并要求重新打开设置再确认。
- 同步成功通知只用于刷新侧栏和发送按键，不携带配置正文、凭据或跳转命令；不会切走当前页面或启动任务。默认页面在下一次启动时生效，快捷问答模式在下一次打开时读取。
- 偏好与其他内容共用账号、加密、10GB配额和版本通道。切换账号不自动沿用旧同步授权；关闭该类别不重置本机设置，重新开启会补读先前未选择的云历史。

## 运维主机配置同步

- 上传范围提供“运维主机配置”和从属的“包含密码和 SSH 私钥”，默认都关闭，用户分别选择。仅同步已保存远程主机的名称、协议、地址、端口、用户名及认证方式，不复制本机路径、会话历史、任务、连接状态或 SSH 主机信任记录。
- 密码、私钥和私钥口令仅在明确勾选包含凭据后进入加密云对象；不包含凭据时，云对象不携带它们。API Key、Cookie、模型和 CLI 登录信息仍禁止同步。关闭包含凭据只改变后续发布内容，不抹除受历史保留策略保护的旧版本。
- 每台主机使用独立的 `ops_host` 资源和条件版本；同账号新设备自动接收云记录。原生终端所有者负责读取、校验、保护凭据和条件落盘，Gateway 只经账号绑定私有桥传输；界面和状态接口不接收凭据明文。私钥必须校验为真实私钥，不能把任意路径指向的文件作为凭据上传。
- 接收的凭据写入本机受保护存储，配置文件只记录专用引用；私钥解密后仅在连接时于内存使用。没有云端凭据时，同目标、同认证方式的本机凭据保留；目标或认证方式改变时不得串用旧凭据。
- 接收只刷新已保存主机列表，不自动连接、授信或执行命令。普通编辑与云写入共用锁、原子保存和版本核对；冲突保留本机修改及独立远端副本，不用陈旧整列表覆盖新收到的主机。源端个别凭据不可用不阻止其他主机和类别同步。

## 云回收站

- 设置中统一查看已删除的 Work 会话、笔记、个人日程和待办云记录。列表按删除序号每页10项加载；标题由本机按需解密对应清单，服务器不保存明文名称，不为展示名称下载全部附件。
- Work 会话通过“会话与历史”中的“移至云回收站”明确移动云端副本；本地会话、文件和运行任务不删除。普通本地会话删除不自动授权删除云副本。已同步笔记和日程/待办沿用其现有版本化删除流程进入云回收站。
- 移动后，客户端持久记录云删除版本，保留本地后续修改但不自动重新上传该云副本。新设备只接收删除标记，不将其旧历史重新导入活动列表；恢复后再接收新的有效版本。
- 恢复复用尚存密文和关联文件，追加新云版本，不自动启动历史任务。未暂停的设备自动接收恢复内容；Work 本机原会话已删除时新建恢复会话，不覆盖同名文件。并发本地修改按原冲突规则保留。
- 移入、恢复及彻底删除均先预览再确认；确认绑定账号、设备会话代次、云空间、精确资源和版本，十分钟失效。未知结果只核对同一确认；预览后资源已恢复或更新时旧确认不能继续删除。
- 彻底删除清除该云记录的可恢复历史引用并封存资源身份，保留删除游标与重试身份；旧客户端不能用该资源标识复活内容。本地副本保留，无其他引用的密文对象由原有明确清理流程回收，不能在文件真正删除前减少配额。
- 有效设备即使 Pro 到期或暂停自动同步，仍可明确管理自己的已有回收站。被撤销的设备、切换账号及没有本地接口认证的请求不能使用旧确认。此阶段不安排自动清空或操作生产存储。

## 历史保留与明确清理

- 服务端配置历史保留天数，默认30天。设置中“清理过期历史”先预览并明确确认，只处理保留期外、且不是资源最新版本的旧内容；不安排自动删除任务，不因打开设置就清理。
- 最新版本不受年龄限制。资源已被删除时，其尚存历史全部保留供回收站后续恢复；本次功能不是清空回收站。确认后再次检查资源与版本状态，预览后变为受保护内容的记录不清理。
- 每批最多50个历史版本，签名确认绑定账号、当前设备会话代次、云空间、保留策略和精确版本；十分钟失效。结果未知时只重试原确认，不自动扩大范围或执行下一批。
- 退役内容清除密文对象引用，仍保留版本序号、同步游标和原请求身份。旧请求重放明确返回历史已清理，不能重新发布已退役内容；新设备增量拉取跳过退役版本并取得尚存的最新完整快照。
- 历史清理本身不宣称释放空间。只有现有“清理上传残留”重新核对全部引用、删除实际存储对象并确认不存在后，才减少配额。多个会话或较新版本共用的密文对象继续保留。
- 有效设备在Pro到期后仍可管理自己的已有历史；撤销设备、切换账号及无本地认证的请求不能沿用旧确认。本地会话、笔记、文件、运行任务均不被历史清理修改。
- 回收站按独立的明确确认流程管理；自动保留策略及生产流量核算另行验收，不以本阶段手动清理冒充后台自动清理。

## 上传残留回收

- 设置主操作保留回收站；过期历史清理与上传残留回收收在“空间管理”中，按需展开。展开只展示入口，实际清理仍须预览及明确确认。
- 设置的“清理上传残留”只回收未被任何资源或历史版本引用的对象；不是删除会话、精简历史或清空云空间。用户先查看本批数量和预计释放量，再明确确认，不自动执行后续批次。
- 普通候选对象至少创建24小时且最后一次上传/复用凭证已过期5分钟。复用已有对象和上传确认都会延长保护期，避免“已选为残留的文件又被新会话使用”时误删。
- 参考七牛官方[上传策略](https://developer-doc.qiniu.com/products/kodo/development-guidelines/security/1-put-policy)（2026-10-13核对）：`deadline` 在上传完成、空间生成文件时校验，并非只在上传开始时校验。回收仍须等最后授权过期、重新核对引用、删除精确存储键并确认不存在，不凭一次查询失败提前释放配额。
- 服务端预览签名绑定账号、设备、云空间及精确存储代次；客户端只向界面暴露本地确认编号。十分钟后重新检查，不能替换参数扩大范围。账户退出或切换使原确认失效。
- 每批最多10个对象，逐项持久化回收状态后才请求七牛删除；网络调用不占账号事务锁。回收期间禁止其他任务重新上传、确认或提交引用该对象。
- 只有七牛确认对象不存在且本地账目仍匹配原代次时才减少占用或上传预留；失败、超时和未知结果保留计量，可重试同一确认。新上传的同内容对象使用新的存储代次，旧确认不得删除它。
- 有效设备即使Pro到期仍可清理自己的残留，暂停自动同步也不阻止此明确操作。所有未退役历史继续保护其引用；历史退役和回收站管理不替代真实对象回收，账单流量核算仍须独立验收。

## 认证与设备

- 已退役旧的机器码激活、离线软件 JWT 授权、授权文件导入及本地工具订阅门控。“关于”只展示产品信息和软件更新；本地工具仍受用户权限、数据范围和运行上下文限制。账号订阅、模型计费与云端权益独立保留。
- 桌面状态只核对当前账号设备会话，离线时最多展示与当前账号令牌绑定的旧摘要；不会读取 `license.jwt` 或用摘要授权云操作。内部设备标识沿用现有值，确保原电脑仍被识别为同一登录设备，不再作为可复制的激活机器码。
- Auth 旧 `/license/*`、`/auth/device/*` 发证和绑定接口源码已移除，现行设备会话使用 `/auth/desktop/*`。历史数据库表/列及用户本机旧文件保留，不自动迁移删除或扫描清理；旧注册机器指纹试用绑定停止使用，账号验证与促销规则仍独立维护。
- 新桌面登录使用设备绑定的服务端会话；账户JWT和短期模型JWT同时携带该会话身份及轮换版本，服务器逐次校验所属账号、有效期、撤销状态和设备名额。
- 登录名额检查、明确替换、会话建立在同一账户级数据库事务内完成，避免并发第2/第4台同时越过检查。相同请求重试只恢复同一会话，不重复退出其他设备。
- Auth 的 MySQL/MariaDB 连接使用 `READ COMMITTED`，与账户行锁共同保护设备名额、对象预留和条件版本提交。等待行锁后必须读取最新已提交状态；ORM 刷新不能代替事务快照刷新。SQLite 保持既有隔离行为。
- 设备指纹只是本地设备标识，不声称提供硬件防克隆或抵御恶意修改客户端。客户端只在系统凭据存储保存令牌，React 不接收账户JWT或七牛密钥。
- 设备管理按当前账号列举/撤销；无权限、旧会话、已轮换或已撤销令牌不能获得访问。修改/重置密码撤销旧桌面会话。
- 历史普通账户登录不是新云服务的授权来源，云接口始终验证当前桌面设备会话。迁移前核对既有设备，不在迁移脚本中登录、退出或删除生产用户数据。
- 新客户端需要配套 Auth API 后才切换设备登录。服务器尚未升级时明确提示升级，不静默退回无限制登录。上线要先迁移和部署服务端，再发布客户端。
- 旧客户端的模型服务可由运维显式设置带时区的 `MONA_AUTH_LEGACY_MODEL_ACCESS_UNTIL` 截止时间，默认不开放。仅无设备身份的旧模型访问使用该过渡窗口，新签发模型令牌不越过截止时间；到期后要求升级并重新登录。已有设备身份仍验证撤销及代次，云同步始终要求设备身份。过渡期间不能宣称所有旧客户端已受新设备名额约束。

## 实施阶段

本地阶段提交只包含桌面应用及已跟踪的相应测试、架构文档。`mona-auth/` 依照现有仓库规则继续排除，服务端部署与数据库迁移必须单独验收；不能把桌面提交误称为 Auth 已发布。


1. 账号设备权益：服务端1/3台、绑定JWT/模型令牌、设备列表与明确替换、桌面登录和管理UI、离线/撤销边界测试。
2. 基础能力开放：移除本地AI的订阅门控与误导文案，保留授权/安全/计费校验；同步更新 Pro 介绍，不宣称未上线云能力可用。
3. 云备份：独立私有存储、客户端加密、限额/直传授权/确认、版本及恢复；先使用本地或协议fixture验证，不读取生产密钥。
4. 增量同步：优先 Work 普通会话及其关联附件/工作文件，再接选定笔记/附件、待办日程和配置白名单；离线队列、版本冲突、删除标记、多端隔离。开发会话和项目数据不在本期。
5. 联合验收与受控上线：真实私有七牛、容量与下载计量、双端/三端、降级恢复、生产迁移演练。线上部署、桶创建/权限调整、价格变更需明确目标和授权。

完整性以各阶段当前源码及测试为准；不得把对象上传成功称为同步完成，或把设备会话测试通过称为全部云服务已上线。
