# Agent 提示词边界

- 状态：Accepted
- 适用范围：主 Agent 的系统提示、工具能力发现和默认行为模板

系统提示保留任务目标、信息来源、授权和结果真实性等跨工具原则。工具描述负责作用对象、输入输出、前置条件与副作用；具体步骤由模型根据任务选择。相同接口约束尽量只维护一处。

- 电脑工具保持已授权时初始可见。其信息源是实时桌面或窗口；附件图片直接进入模型视觉上下文，图片问题本身不触发屏幕观察或生图。
- 普通图片附件不预加载生图能力。用户选择生图模式时预加载相应工具与 Skill；自然语言任务通过现有 `skill_read` / `load_capability` 按需发现。历史工具调用可恢复工具可见性，但不让新一轮自动携带完整生图流程。
- 电脑操作的目标标识、新鲜观察、坐标、前台输入和结果核对约束仍由工具描述及执行端维护。
- 任务计划按需要使用，不规定统一步数或每步词数。用户对具体行为的明确授权在对话中持续有效；敏感动作仍须处于授权范围内。
- 每个 Agent 只配置私有 `SOUL.md` 人设和 `MEMORY.md` 长期记忆。人设统一承载身份、语气和明确行为要求；用户画像由平台共享，只通过只读画像快照进入上下文，不属于 Agent 配置、私有 bootstrap、Dream 或 memory 工具的读写范围。
- 各 Agent 的 `SOUL.md`、`MEMORY.md` 分别只保留一个上一版文件（`<filename>.previous`）。内容变化时用当前内容更新上一版；内容未变时不覆盖上一版。恢复时交换当前文件与上一版，不回退 Dream 游标。
- 旧自定义 `AGENTS.md` 内容按人设兼容读取，并与 `SOUL.md` 内容统一呈现；默认 `AGENTS.md` 模板不并入人设。首次保存人设时，将合并后的人设写入 `SOUL.md` 并清空旧 `AGENTS.md`；内容变更时，保存前的合并人设由 `SOUL.md.previous` 保留，单纯迁移格式不产生重复备份。各 Agent 的人设与长期记忆相互隔离。
- 一次性兼容迁移只从可识别的 Mona 自建记忆仓库中为每个文件提取最近的不同版本到对应 `.previous`；校验成功后安全清理该仓库。此后不累积 Git 历史或行龄元数据，也不清理非 Mona 自建仓库。
- 仅完整匹配已知历史发行版的 `AGENTS.md` 默认模板在兼容读取时排除；仅完整匹配已知历史发行版的 `SOUL.md` 默认文本可在构建上下文时使用当前模板。用户修改过的 `SOUL.md` 保持原样，磁盘文件不会被模板覆盖；不通过关键词删除自定义规则。

回归检查覆盖图片附件保留视觉内容、生图工具按需加载、显式生图模式和上一版交换恢复，以及旧默认模板替换与自定义文本保留。静态提示词缩短不等同于已经证明模型任务完成率提高。
