# 线上工作台与桌面 Work 的执行差异

核对日期：2026-11-08。本文记录已核对的差异及处理方向，生产版本与后续上线结果以[生产上线手册](../../生产上线手册.md)为准；本地未发布的代码不等于线上可用。

## 已共用与已上线修复

网页与桌面共用 `AgentRunner`、上下文构建和整理、进度钩子、提问工具、部分文件与 Office 工具、内置 Skill 和子任务管理器。网页通过适配层连接账号、隔离工作区和持久化；共用这些类并不代表两侧能力已经完全一致。入口见 [turn.py](../../mona/hosted_work/turn.py) 和 [context.py](../../mona/hosted_work/context.py)。

生产后端 v54 已去掉默认的 15 分钟整轮截止和 10 分钟等待用户回答截止；单次工具或连接的时限是另一回事。v51 同时加入停止链路修复、已确认预扣拒绝的输入从模型历史排除，以及基于桌面搜索工具的公网搜索。拒绝输入的清理保留用户可见记录，仅对证据完整的记录生效；不重派历史任务。

真实网页停止及删除验收成功；公开搜索在 Ubuntu 候选环境真实返回结果，但网页搜索任务尚未单独验收。v54 上独立真实文件任务完成、保存并下载核对；此前一次文件验收失败的完整底层原因未记录。真实子任务已生成一张图片并按设置结算，重新打开会话和生产前端重放原事件都能显示；首次页面验收异常的直接原因未记录。

## 必须保留的网页边界

| 差异 | 必须保留的理由 |
|---|---|
| 工作区、会话和记忆按账号限定；执行与工具调用绑定账号及任务 | 网页是多用户环境，不能让一个账号读取或修改其他账号的数据。用户脚本在隔离容器内运行，平台模型凭据不交给用户容器。 |
| 公网请求经地址与 DNS 校验 | 用户提供的地址不能访问宿主、私网或其他内部服务；重定向也必须逐跳校验。安全网络适配不意味着必须缺少搜索或动态网页能力。 |
| 未确认的写入不自动重放 | 断线或取消不等于外部操作没有发生；先保存结果与检查点，避免重复写文件、调用服务或扣费。 |
| 停止与计费分开确认 | 停止要作用于本账号本轮及其本地执行；已发往供应商的请求若没有终止或用量回执，不能声称上游已停止计费，也不能伪造结算或自动退款。 |

## 仍需对齐或补齐

| 范围 | v51 已核对的差异 | 处理方向与约束 |
|---|---|---|
| 文档读取 | 网页 `read_file` 对 PDF、DOCX、XLSX、PPTX 返回不可用；桌面已有解析实现。网页 Office 编辑器属于另一条能力，不能代替通用读取。 | 在用户自己的隔离运行时交付并复用桌面解析代码及依赖；不能在可信宿主直接解析不可信用户文件。见 [filesystem.py](../../mona/hosted_work/filesystem.py)。 |
| 工具图片和大结果 | v54 通过账号及会话限定的持久引用对齐共享 Runner，先落盘再写检查点；图片复用已有历史媒体。真实基础文件任务已验收，长结果专项为候选定向测试，尚未使用真实模型专项验收。 | 出现存储或容量故障时保留已派发记录并禁止重跑；旧版不识别新引用，回退工具会拒绝不安全切换。见 [runner.py](../../mona/agent/runner.py)。 |
| 命令及 Skill 脚本时限 | v52 已对齐桌面的命令和 Skill 脚本单次时限参数，命令输出合并标准输出与错误输出。真实 gVisor 定向测试确认超时后不再写入。 | 执行结果未确认时结束当前轮，不自动重做写入；不同平台的进程和容器清理仍须分别确认。 |
| 子任务 | v53 已为子任务接入父任务的生图授权、按张计费及独立操作身份，真实子任务生成图片，单笔图片结算已核对。普通 spawn 与桌面一样继承父模型；桌面的具名 Agent 可绑定独立模型，网页尚未接入该路径。网页结果以 runtime 消息注入，与桌面持久化方式不同。 | 如接入具名 Agent，应使用网页已授权模型并正确归属用户、任务和费用；对齐结果身份和幂等语义。见 [subagents.py](../../mona/hosted_work/subagents.py) 和 [subagent_spec.py](../../mona/hosted_work/subagent_spec.py)。 |
| Skill、记忆、MCP 与资料 | 网页当前只装载内置 Skill；账号记忆已隔离，但笔记、资料及完整来源未接入，用户私有 Skill 与 MCP 也未接入。 | 复用桌面能力并增加每用户配置、凭据及数据范围隔离；不能读取平台宿主或其他用户的配置。见 [skills.py](../../mona/hosted_work/skills.py) 和 [owner_memory.py](../../mona/hosted_work/owner_memory.py)。 |
| 网页读取 | v51 的公网读取只提取静态文本，返回正文最多 24000 字；与桌面动态网页处理及完整内容恢复不同。网页搜索已接入桌面默认搜索实现，其桌面备用搜索通路未接入。 | 补齐动态内容与可恢复的完整结果，同时保留公网地址校验和可取消性。用户此前要求移除的浏览器及终端界面入口不因此自动恢复。见 [public_web.py](../../mona/hosted_work/public_web.py)。 |
| 自定义 API 计费 | 自定义 API 的付费模型目前被拒绝使用；Codex 已接入共用钱包。管理员可配置网页独立价格，但配置价格不等于收费链路已接通。 | 复用钱包预扣、价格快照及结算，完整核对主任务、子任务、摘要和重试的实际用量；缺少可靠回执时保留待核对状态，不用估算结算。见 [model_policy.py](../../mona/hosted_work/model_policy.py) 和 [billing.py](../../mona/hosted_work/billing.py)。 |
| Codex 长任务计费 | 当前整轮只预留一次，长任务或子任务多次调用可能超过预留；余额不足时 Auth 保留预留并标记待核对，已发生的供应商消耗无法事后阻止。 | 需要在每次上游调用前进行可核验的余额与预扣控制，并处理真实回执、子任务、并发及中断；现有一次预留不能当作完整余额保护。 |
| Codex 原生状态 | 目前平台 Codex 原生目录由多个网页账号共享，其会话文件和状态尚未按用户物理隔离；网页工作区和 Mona 记忆的隔离不能替代该隔离。 | 保留平台认证来源，但为各用户隔离原生会话、缓存和状态，并验证不会将凭据暴露给用户工具。见 [providers.py](../../mona/hosted_work/providers.py)。 |
| 执行参数与重试 | 网页把工具结果上限和部分重试策略固定，迭代上限配置范围也与桌面不同；当前默认迭代次数与桌面一致。 | 对照桌面配置与真实调用语义逐项同步；仅在回执不明或涉及未确认写入时保留必要的防重放限制。 |

上述差异不因用户隔离而天然必须存在；对应功能需在隔离和实际运行条件满足后补齐，不能以接口存在或模拟结果代替真实验收。
