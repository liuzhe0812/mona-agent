# Mona 用户画像与蒸馏架构

- 状态：Accepted
- 最后更新：2026-09-08

## 1. 所有权

用户画像是用户级平台数据，不属于 Mona Agent 或任何伙伴 Agent 的私有记忆。

- 用户级画像事实源位于 Mona 用户数据目录的 `profile/`。
- Agent 的 `MEMORY.md`、`SOUL.md`、`USER.md` 和历史继续按 Agent 隔离。
- 卸载伙伴 Agent、清理某个 Agent 私有记忆或切换工作区，不得删除全局用户画像。
- Dream 维护 Agent 私有记忆；ProfileService 维护用户级画像，两者不争用同一事实源。

## 2. 存储契约

用户画像目录包含：

- `USER.md`：用户可读、可纠正的显式偏好和紧凑画像段落。
- `profile.rich.json`：前端画像、确定性仪表盘、AI 建议、证据摘要、用户反馈和可视化结构。
- `profile_snapshots/`：受限数量的历史快照。

写入要求：

- 完整生成管线使用用户画像目录下的跨进程文件锁；短读改写使用独立文件锁并在锁内重新读取最新 revision。
- 文件通过同目录临时文件原子替换。
- `profile.rich.json` 每次写入递增 revision，并记录更新时间。
- 轨迹和快照有明确保留上限。
- 旧版本从 Mona 私有记忆目录迁移时只复制缺失文件、逐字节校验，并保留旧文件用于回滚。

## 3. 信号归因

画像只能从真实用户信号生成：

- 用户普通消息。
- 用户笔记以及可归因到可见会话的显式交付成果。
- 已完成的真实工具使用记录和工作模式。
- 用户通过画像上下文接口做出的显式修正。

必须排除：

- assistant 推理、内部任务提示和 subagent 指令。
- 系统消息、命令、UI-only 事件和运行时元数据。
- 隐藏执行房间、Job/Workflow 内部协调文本。
- 未获授权的邮件正文、联系人、其他 Agent 私有记忆和原始敏感证据。

同一用户消息在房间或多 Agent 路径中只归因一次。

画像页发起建议时生成的首条起步请求带 `origin=profile_advice`，不作为新的用户画像信号；用户随后主动补充的普通消息仍可进入下一次画像。

## 4. 蒸馏管线

- 固定顺序为：确定性仪表盘、Agent 执行活动、人物理解、AI 建议。
- 定时与手动蒸馏复用同一加锁管线，不能并发覆盖字段或重复追加轨迹。
- 确定性仪表盘不依赖 LLM；LLM 不可用时保留最近一次人物理解和建议，并明确标记对应阶段失败。
- 蒸馏结果保留来源覆盖和置信度，不把模型推断描述成用户明确事实。
- 用户显式填写的偏好优先于自动蒸馏，后续任务不得无条件覆盖。
- “我的画像”和“变化轨迹”的图表只展示记录数量、共现关系和相邻等长窗口变化，不把词频或提问次数命名为能力、技能掌握或完成质量。
- AI 建议通过一个业务提示词综合近期聊天、已有画像、工作方式与用户目标，每次只选择一项最值得用户知道、但用户可能还不知道或没有真正理解的道理或知识。模型自行完成分析，不预设学科答案、会话数量或应用领域数量；没有足够信息时允许不生成建议。
- 建议内容契约只有三部分：`knowledge`（标题和解释）、`learning_advice`（怎么提升、从何入手）和 `resources`（资料名称与 URL）。模型完成一次结构化生成后，服务端使用知识标题搜索公开资料；只有实际搜索结果中的安全 HTTP(S) URL 可以进入最终数据。搜索失败时仍保留知识解释与学习建议。

## 5. Agent 上下文投影

Agent 不直接读取完整 `profile.rich.json`。`mona.distill.snapshot` 生成白名单、裁剪后的只读快照：

- 默认只允许 preferences、work_context 和 current_focus。
- 不包含原始证据、联系人、邮件正文或隐藏字段。
- 快照包含 schema version、profile revision 和内容 hash 版本。
- Mona、伙伴直聊和协作房间只接收获准字段。
- AgentJob 和 WorkflowRun 启动时固定画像版本；运行中的画像更新不改变已经启动的步骤。
- 快照作为数据上下文，不是指令，Agent 不能通过 memory 工具修改全局画像。

## 6. 用户可见与可控

- 画像页是信息展示仪表盘，三个并列页签为“我的画像”“变化轨迹”“AI 建议”，不在页面内放置用户画像设置表单。
- 页面使用真实统计、图表、局部空态和来源入口；来源覆盖与更新时间保持次级展示，不用大段说明或身份介绍卡占据首屏。
- 显式偏好与当前目标仍可通过用户级画像存储接口维护；该能力属于上下文管理，不嵌入画像仪表盘。
- AI 建议使用单篇阅读布局，依次展示一条知识及解释、“怎么提升”和参考资源。页面不使用表格、Accordion、内容区导航、应用场景、依据按钮、聊天按钮或原型说明占位行。
- “我的画像”和“变化轨迹”使用近 30 天统计口径；AI 建议来自长期积累，因此该页顶栏不标记近 30 天。
- 页面不得用当前时间伪造缺失的历史日期、星期或活动数据。
- 画像不得自动扩大 Agent 的工具、知识库、脚本或数据权限。
