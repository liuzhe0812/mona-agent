# PDF 图文读取

- 状态：Accepted
- 适用范围：会话 PDF 附件、`pdf` 工具、模型图片降级

## 读取契约

- 会话 PDF 附件保留原有文字提取，并自动附带整页 PNG；每条消息最多自动预览 4 页，明确未提供画面的页码。文字提取完成不代表视觉内容全部读完。
- `pdf(action="inspect", path=..., pages=[...])` 返回可选文字、页面尺寸、页码及真实页面图片，每次最多 4 页，无须用户指定输出路径或 Agent 编写脚本。
- 整页渲染保留内嵌图片、矢量图表和扫描文字。由当前模型直接理解画面，不引入独立 OCR、额外模型调用或可下载运行时。
- 显式页码只表示本次选择范围；默认分页结果、文字截断和 `next_offset` 必须如实返回，不能将部分内容声明为全文解析。
- PNG 使用现有内容寻址媒体仓库；图像带可恢复文件路径。会话追问中位于活动工作区外的 PDF 同样保存受管副本，保证后续工具能继续读取。
- 页面渲染与现有 PDF 工具共享 MuPDF 锁；会话附件解析在线程中执行，避免阻塞事件循环。

## 降级契约

- 当前模型明确不支持视觉时，请求前去除图片，保留原文字并说明视觉内容未读取。流式和非流式请求使用相同逻辑。
- 视觉能力未知时允许尝试图片；沿用 Provider 对非瞬时错误的去图重试，成功后后续请求沿用文字内容。
- 去图重试不能把未知错误宣称为模型必然不支持视觉。占位说明只表示本次图像未读取。
- 附件页面渲染失败时保留已提取文字并给出具体失败提示；扫描页提取不到文字时不能认定页面空白。

## 验证

回归覆盖带图片的文字页、矢量图表、扫描页、分页上限、跨工作区追问，以及支持视觉、不支持视觉和未知能力三类模型请求。
