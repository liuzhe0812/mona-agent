# 投资工作台一屏布局与图内预测详情

- 日期：2026-10-19
- 分类：Mona界面接入适配；复用现有Vibe行情、预测与研究产物，本轮不调整预测算法、输入、缓存和更新策略。

## 布局

- 股票页的投资工作台填满桌面内容区，固定页头与页签；仅在该Tab调整间距，不修改全局主题或其他Tab的滚动行为。
- 左侧自选/持仓、中央行情、右侧研究保持三栏并排。自选列表、研究记录及右栏长内容分别内部滚动，不向下堆叠右栏。
- 图表按剩余宽高计算价格、成交量和时间轴的位置，保留原有文字阶梯；不通过整体缩小字号或拉伸SVG来容纳内容。
- “关联研究与任务”移入右侧研究区；中间仅显示当前报价、周期工具栏和行情图。研究摘要收紧到三行，完整报告与追问入口保留。

## 预测交互

- 移除独立的大预测卡片；图表底部保留期限、方向、预估幅度、参考价和更新状态的一行摘要，可自然换行。
- 预测区域具有完整悬停命中范围，不要求用户精确指向细虚线；最近的预测点显示时间、参考价、范围和历史误差。选中点有竖线和圆点反馈。
- 支持点击、键盘聚焦、左右键切换预测点与Escape关闭；明确的“预测详情”入口用现有对话框提供完整阅读。原有历史K线方向键操作保留。
- 历史误差采用“平均差约多少元／按预测时股价折算”；计算仍为预测起点股价乘历史收益率MAE，详细提示保留原百分点口径，明确整体历史表现不是所选预测点的未来误差范围。样本不足或数据无效时不展示误导金额。
- 生成中、数据不足、结果不匹配等状态直接可见；未作判断的结果不绘制虚假预测曲线，也不在详情中恢复无效参考价。

## 验证

- 工作台、股票页、图表、预测摘要4个相关测试文件共61项通过；TypeScript检查和Tauri模式前端构建通过。
- 图表回归覆盖900×370缩至600×220时价格、成交量和时间轴的边界，以及历史K线和预测点各自的键盘交互。
- 实际1280×720页面开启分时预测后，股票页、主行情栏和右栏的滚动高度均等于可用高度；图表实际绘图区为717×355，无整页或主栏纵向溢出。日K预测同样完成真实显示，已核对预测点详情、方向键切点、关闭及对话框入口。
