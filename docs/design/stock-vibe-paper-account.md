# 模拟持仓：需求、业务规则与实现

- 日期：2026-10-21
- 状态：工作台功能及生产链路验收通过；验收不含桌面窗口视觉和实盘撮合。
- 入口：投资工作台左侧“模拟持仓”，不增加股票一级 Tab。

## 用户故事与需求

普通投资者想练习记录买卖判断，却没有可接入的券商接口。他可以建立一份虚拟资金账本，在工作台选择股票、查看服务端参考报价与费用、确认模拟买卖，再查看资金、持仓和历史；可选记录理由或关联当时的研究报告，之后复盘自己的决定。

完整流程是：首次进入时主动设置初始资金 → 选择当前股票并输入买卖股数 → 核对报价时点、来源、费用和交易后资金 → 确认 → 查看更新后的持仓与交易记录。页面错误须说明本次是否记账；结果未知时只核对原请求回执，不重复派发。

Vibe 原有 A 股引擎提供费用、数量和持仓对象计算，但没有脱离券商的持久模拟账本。0052 在 Vibe 增加本地纸面账户；Mona Services 仅做鉴权、字段校验和请求转发，前端只展示服务端返回的账本与预览。买卖不依赖模型。

## 已实现业务规则

- 一个本地 CNY 账户。用户明确创建时输入初始资金，默认 1,000,000 元，范围大于 0 且不超过 1,000,000,000 元。创建后不能重置或追加初始资金；已有账户不会因打开页面而重建。
- 买入须为 100 股整数倍；卖出须为正整数且不超过持仓，可卖零股。不允许透支或做空。此流程不执行完整 T+1 限制，不能视为交易所撮合仿真。
- 每笔先由服务端取得报价并生成 60 秒有效、绑定账户版本的一次性预览。确认只提交预览 ID、可选理由和可选研究引用，客户端不能指定价格、资金或持仓。过期、账户变化或预览已使用时，须重新核对。
- 费用沿用 `ChinaAEngine` 默认模拟参数：双边佣金按成交额 0.025%、每笔最低 5 元；双边过户费 0.001%；卖出印花税 0.05%；本账本滑点设为 0。它们是统一的演练口径，不代表东方财富或用户真实费率。
- 当前报价使用 Vibe 行情快照中的 Tencent 未复权分时参考价。预览及成交记录保留价格、来源、行情时间 `as_of`、读取时间和市场状态；闭市标记不证明它是最近交易日。来源无可用报价时不能确认交易。当前来源不支持北交所时不补造报价。
- 持仓估值优先读取当前参考报价；失败时只能暂用该股票**最近一笔模拟交易保存的报价**，逐项标出来源和时点。它不使用任意一次 GET 的旧值。两种报价都没有时，市值和盈亏留空；不按零或成本价伪造。使用缓存参考价时总览标为部分估值。
- 用户可填写不超过 500 字的理由，并可关联同一股票、真实已完成且有报告的研究。保存当时报告标题、摘要、摘要哈希、完成时间和任务信息；历史交易打开冻结快照，不替换为更新后的报告。
- 现金、原生持仓与成交对象、预览消费状态、交易记录、业务回执和请求完成状态在 SQLite 同一事务提交。稳定请求 ID 重复查询返回原回执；提交结果不明时通过只读回执核对，绝不自动重发。重启后账户、持仓和交易历史恢复。

## 接口与数据

Mona 对前端提供以下鉴权路由，并转发至对应 Vibe 原生接口：

| Mona 路由 | 用途 |
| --- | --- |
| `GET /api/stock-vibe/paper/account` | 读取默认参数、账户、持仓及估值状态 |
| `POST /api/stock-vibe/paper/account` | 首次创建账户，正文 `{initial_cash}` |
| `GET /api/stock-vibe/paper/preview?symbol&side&quantity` | 获取买卖参考价与费用预览；代码使用六位数字加内部市场后缀 |
| `POST /api/stock-vibe/paper/trades` | 确认 `{preview_id, note?, research?: {session_id, attempt_id}}` |
| `GET /api/stock-vibe/paper/trades?limit&offset` | 分页读取交易记录 |

Vibe 使用已有 `mona-requests.sqlite3` 保存单账户 `paper_account` 状态，以及 `paper_previews`、`paper_trades`、`paper_receipts`。预览存冻结报价及账户版本；交易保存报价、费用、交易后现金/股数、理由和可选研究快照。前端不另算费用或盈亏。

主要账户字段包括 `initial_cash`、`cash`、`realized_pnl`、`unrealized_pnl`、`equity`、`total_pnl`、`total_return`；估值缺项时对应值为 `null`。持仓含数量、成本、参考价/时间/来源、市场价值和未实现盈亏。`total_return` 单位为百分比点。
