# PPT 原生设计能力

日期：2026-10-14

## 目标与边界

Mona 通过同一个 Office 编辑器实时生成、修改、观察和导出原生 PPTX。选定的 Dashi 源页通过受限模板目录导入为可编辑的 PowerPoint 文字、形状和独立素材；不接入 Dashi HTML 编辑器或运行时。最终表达取决于用户内容、受众和观看场景；不以图像相似度、固定主题、模板数量或内容占用比例衡量质量。

不恢复独立 `ppt-design` 工具，不增加代表页审批、主题冻结、整稿匹配或布局不得重复的状态机。不新增主题管理系统，也不引入 dashi HTML 运行时或导出组件。Agent 核心循环不因本改造新增 PPT 专属逻辑。

## 实现

- `mona/skills/mona-pptx/SKILL.md`：轻量入口、设计判断、已知操作与按需参考；不要求额外设计报告。
- `mona/agent/skill_previews.py`：开发期可按当前 Skill 的 `assets/previews.json` 读取真实图像；资源路径、文件大小和解码尺寸受限，不能跨 Skill 或 Agent 读取。安装内容不包含这批静态预览。
- `mona/agent/tools/skill_tools.py`：Skill 和相关参考读取可直接返回图像块。参考路径可保留 Markdown 中的 `references/` 前缀，仍做 resolved-path 校验。
- `slides-design.ts`：11 种原生整页表达；其中指标、列表、图表解读、瀑布与流向可在明确区域内作为正常字号组件。完整页、区域组件与自由原生对象可混用。
- `slides-typography.ts`：混合文字片段、数值与单位、基线、字距、行段距及明确文本内边距；测量复用编辑器的布局和字体度量。
- `custom-path.ts`：由有限 M/L/C/Z 指令生成原生自由形状。数据到几何的计算由代码完成，模型不用逐个猜坐标。
- `slides-dashi.ts`、`dashi-selection.json` 与 `assets/dashi/templates.json`：为12个用途场景登记96条源页引用、81个唯一 ID；每场景8页，选择集仅覆盖来源的可用子集，不表示1020个来源页全部迁入。导入保留原生文字、形状和独立素材，12个源3D WebP素材保留用于实际页面；静态预览PNG只用于开发，不进入安装内容。
- `slides-entry.tsx`、`slides-capabilities.ts` 与跨进程 Schema：`slide_add_template` 属于 `office`；图片沿用受限资源读取链路。
- `slides-visual.tsx`：真实单页捕获及多页总览，均绑定版本；总览不替代细节检查或清除待审阅页。

## 设计能力的使用

### 按用途组织场景

内置 PPT 提供12个用途场景：企业汇报、产品展示、技术方案、经营数据、战略规划、调研报告、商业路演、金融投研、品牌提案、企业故事、活动策划和教学培训。`presets/scenarios.json` 保留场景用途与通用原生构图；`dashi-selection.json` 是选定真实源页 ID 的目录，`scenario-pages.json` 保留既有通用特色原生页。Dashi 原始素材共有1020个布局，当前仅选96条场景引用、81个唯一页 ID，不能宣称全部迁入。浅色编辑式与深色产品式继续作为通用原生构图，不复制成12个新主题。

通用指标、比较、时间线等原生构图仍可跨场景共享；Dashi 源页只保留实际入选的几何和来源 ID，不重复复制场景主题或静态预览。特色页用于工作状态、产品证据、技术分层、驱动分析、战略选项、研究方法与结果、商业模式、投研情景、品牌创意、企业历程、活动议程和教学练习。

`slide_add_preset` 可用 `content.scenario` 选择通用原生构图；Dashi 源页通过 `inspect capabilities` 的 `presetScenario` 筛选，指定 `templateId` 时读取实际文本字段、例值和字数限制。`slide_add_template` 只在空白16:9页创建；仅接受能力回执列出的可编辑文字字段，省略字段保留来源示例文案。要预览候选，用 `inspect` 的 `mode:"visual"`、`templateId` 与 `templateFields`；渲染在隔离副本中完成，不改原稿。实际导入使用系统字体：mono映射到 Consolas、中文serif映射到 SimSun、拉丁serif映射到 Georgia、中文sans-serif映射到 Microsoft YaHei、拉丁sans-serif映射到 Arial；环境可用字体不同，需检查真实 Office 预览。场景只组织快捷能力，具体不适配时仍可组合原生对象。场景色彩属于用户产物，不改变应用 UI Token，不引入 HTML 运行时或新的下载组件。

成熟组件是起点，不是白名单。即使某个完整页面能够容纳内容，也允许模型为更好的表达重新组合、调整或自由绘制。教学页面不应因为参考样例是经营报告，就被改写成指标看板。

主指标、图表、解释和注释具有不同视觉权重；不把所有文字默认装入等权圆角框。但卡片、对称、重复构图本身并非错误，应由内容决定。

默认配色只是创建起点，可用 palette 调整；该创建参数不是已生成文稿的动态主题绑定。完成后改色用当前文稿的 palette 查询和 slide_replace_colors 精确修改已有颜色节点，可按页面、对象、属性范围选择或排除。字体、坐标、文字、形状和图表仍按真实稳定对象 ID 修改，不重新运行整页创建，也不保留一份覆盖用户编辑的第二文档模型。

## 准确性与可编辑性

内容按 label、detail、value、unit 等语义字段传入。文字过长时调整区域、布局或等义表达；不静默截断必含事实，不改变原始关系来匹配设计。零值、负向变化、起终点、单位和小数必须保留含义。

标准数据图表保留原生 chart 数据。导入源页的原生文字和形状可编辑；部分复杂 SVG 装饰或图表会以图片保留，没有 PowerPoint 原生图表数据表，也不把其中数字暴露为文本字段。需要可编辑数据时使用原生图表操作替代，不能声称 SVG 已转成可编辑图表。桑基和瀑布信息图形保存为原生路径、形状与文字，可分别编辑，但不声称具有 PowerPoint 标准图表的数据表编辑能力。照片、独立素材和截图仍为图片，不以整页图片替代正文。

HTML入场动画、编辑控件和原生源文件未导出的部分CSS装饰不属于本次原生导入内容。例如`theme06_page071`的大号半透明END水印已在来源HTML转PPTX时遗漏；`theme03_page021`的列填色6%透明度、蓝色阴影和文件夹图像在来源与导入PPTX中均保留，但Office阴影预览与HTML仍有视觉差异。不能用处于动画中的来源截图判定内容被删，也不能据排版检查通过宣称网页效果全部还原；实际复用仍需查看Office预览。

公共操作数组最多 50 项；非设计操作及其图表样式仍不超过 50 个内部操作；受控设计组件展开后的整批最多 256 个内部操作。所有写入共用原子事务、版本冲突和回滚语义，只推进一次 revision。

PPT Agent 正常导出要求处理真实硬错误和待检查页。模型不能用 `allow_unreviewed` 为自己授权；草稿可以保存，用户仍可从编辑器直接导出。该约束不阻止制作，也不影响已完成页面的保留。

## 样例和验收

### Dashi 资源与包体

资源包保留完整12幅来源3D图组，以及入选页使用的328幅独立素材，共340个无损WebP，合计18,558,018字节。相同素材按内容去重；读取时在既有后端链路还原为PNG并检查像素、透明通道、尺寸及颜色元数据。模板蓝图只编入Office前端，Python资源包使用小型素材索引，不再重复携带整份蓝图。静态模板预览和开发期预览PNG均不进入安装内容，候选页通过真实Office按需渲染。

2026-10-14以原两套方向所在的`b989898c81119f5ea8d592be81a9745d65c48838`为基线，重新构建Office并按真实打包过滤规则比较PPT Skill资源。对上述变更范围采用相同路径排序的solid LZMA压缩，净增14,755,109字节，约14.76 MB；完整安装包可预计增加约15 MB。这是受影响资源的压缩对比，未构建完整安装包，不能当成NSIS安装文件的精确大小。最终Office主包为`slides-MAxD821m.js`，原始9,367,766字节，gzip后1,467,612字节。

### 2026-10-14选定源页验收

Windows上的真实Office回放覆盖全部81个唯一模板页及12个来源主题，实时和保存重开后均无排版硬错误；2,415个文本对象的文字与几何全部保持一致。78页保存重开PNG完全相同，另外3页只有31、32、24个像素的单通道差值不超过1；原严格像素哈希断言仍为失败，报告未放宽阈值。这项结果不代表Dashi HTML逐像素复刻，也不代表已在PowerPoint、WPS或macOS上验收。相关52项前端测试、类型检查和Office生产构建通过；独立素材和打包规则另有针对性验证。

### 原生组件与Agent验收

`webui/office-editor/scripts/design-fixtures.mjs` 生成组件与自主组合用例。自主组合样例将局部指标、变化瀑布和原生行动标签组合成独立页面，不是从 dashi 模板替换文字。

Dashi 源页的候选预览由 `inspect mode:"visual"` 按需在隔离副本中调用真实 Office 渲染；Skill 不依赖场景 PNG 索引。`scripts/update_ppt_design_previews.py` 仍为其他原生组件保留开发期真实渲染预览；这些静态预览资源不随安装内容提供。

`scripts/verify_ppt_agent_live.py` 使用实际配置模型、生产 AgentRunner、认证 Office API 和真实编辑器，隔离于用户现有会话。模型自行决定内容与操作，没有预先编排页面 JSON。此测试不是整个桌面应用的端到端测试，也不自动证明审美质量。

实际验收结果与范围见 `docs/plans/2026-09-23-ppt-native-design-acceptance.md`。
