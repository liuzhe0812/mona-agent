## 字段与来源

Vibe托管行情原本已经取得腾讯完整`qt`报价数组，但只投影名称、现价、昨收和时间。本轮直接投影同次响应中的额外字段，不逐字段增加网络请求。字段位置对照[行情协议参考实现](https://github.com/shidenggui/easyquotation/blob/master/easyquotation/tencent.py)及本轮真实响应核对，继续沿用Vibe既有行情链路，没有引入该库依赖。原生源码没有完整实时指标映射，因此这是接入扩展，不冒称原生页面已经实现。

| 界面字段 | 实际源字段 | 标准化及含义 |
| --- | --- | --- |
| 最新价/涨跌额/涨跌幅 | 原有qt[3]/qt[4] | 价格和原有昨收比较，保留原有计算 |
| 今开 | qt[5] | 当前报价交易日开盘价 |
| 最高/最低 | qt[33]/qt[34] | 当前报价交易日日内高低 |
| 换手率 | qt[38] | 已为百分数值，不再乘100 |
| 成交量 | qt[6] | 手；保留A股原始手数，不乘100冒充股数 |
| 成交额 | qt[37] | 来源万元，标准化为元 |
| 总市值/流通市值 | qt[45]/qt[44] | 来源亿元，标准化为元 |
| 市盈率(动) | qt[52] | 动态口径；不混用qt[39]的泛PE或qt[53]的静态口径 |

2026-10-19实际88字段报价已核对今开38.08、最高38.74、最低37.67、总手245810等源值。另调用Vibe既有`etf_holdings_tool._cn_quote`的东方财富具名字段f116/f117核对元单位；用两源同次报价价格消除取数时差，所得隐含股份量相对差约0.0002%和0.0003%，支持腾讯市值字段的亿元尺度。该交叉核对只在开发验证中执行，不增加产品日常取数。

## 展示行为

- 股票名称、代码和行情时点放在同一区域；突出最新价，直接显示涨跌额与涨跌幅。
- 9项日内和估值指标紧凑排列，按摘要区域实际宽度调整为三列或两列，不让右侧栏下移。
- 最新价及涨跌、今开/最高/最低按昨收红涨绿跌。成交量、金额、市值和PE保持中性，不用装饰颜色表达无依据的涨跌。
- 金额使用元/万/亿/万亿，数量使用手/万手/亿手。源缺失或无效显示“—”；合法零交易值保留。负PE保留负数，不据此杜撰报告或未来盈利。
- 核对返回证券身份；新字段解析失败不丢掉已有基本报价。旧展示缓存不含新增字段时仍能读取，成功刷新后补全。
- 摘要始终是当前报价，不跟随历史K线焦点改变。周/月/分钟K使用现有intraday行情接口补充该股票报价；历史蜡烛图保持所选周期。
- 展示缓存及背景刷新仍按既有规则运行；旧报价保留时标明上次行情及原始时间，不修改观测时间。
- 不增加H股/AH比价、五档、新闻条、融资/陆股通标签等未纳入本轮的入口或不可验证字段。
