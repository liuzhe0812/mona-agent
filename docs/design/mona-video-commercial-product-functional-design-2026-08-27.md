# Mona AI 文档→视频模块商业产品功能设计

> 日期：2026-08-27  
> 状态：目标产品设计，不能作为当前已实现声明  
> 适用范围：Mona 桌面端「AI 文档 → 视频」模块  
> 关联文档：[系列风格系统落地方案](mona-video-series-style-system-design-2026-08-26.md)

## 1. 产品结论

Mona 视频模块应定位为“面向知识、课程、产品说明和企业内容的视频生产工作台”，而不是一键把文档变成若干静态画面。

高成熟度版本必须同时成立：

1. 用户能快速得到可用初稿。
2. 用户能理解并控制脚本、分镜、素材、动画、字幕和声音。
3. 系列视频保持稳定视觉身份。
4. 预览与最终导出使用同一套时间轴和渲染定义。
5. 长任务可后台运行、取消、重试、恢复并查看错误。
6. 每次生成的成本、时长、质量和影响范围在执行前可预期。
7. 任何 AI 自动化都不能绕过用户确认或破坏已经完成的视频。

产品主链路固定为：

```text
素材与目标
  → 内容大纲
  → 解说脚本
  → 分镜与屏幕文案
  → 动画节拍 + 字幕时间轴 + 配音
  → HyperFrames 预检与渲染
  → 审阅
  → MP4 / 字幕 / 封面交付
```

## 2. 目标用户与核心任务

| 用户 | 典型输入 | 目标输出 | 最关心的问题 |
|---|---|---|---|
| 课程与知识创作者 | PDF、Word、PPT、Markdown、笔记 | 课程单元、知识解释视频 | 内容准确、节奏清晰、字幕同步 |
| 产品与市场人员 | 产品文档、发布说明、网页 | 产品介绍、功能更新、社媒视频 | 品牌一致、转化表达、多画幅 |
| 企业培训人员 | SOP、制度、培训资料 | 入职、合规、操作培训视频 | 可审核、可复用、版本可追溯 |
| 系列内容创作者 | 选题、脚本、历史视频 | 连续多期系列视频 | 模板稳定、批量生产、低重复劳动 |

产品不以专业影视剪辑师为第一用户，不复制 Premiere 的全部能力；默认提供“自动化工作流 + 场景级控制”，需要时再展开图层与时间轴。

## 3. 成熟产品原则

### 3.1 先审阅结构，再投入生成

AI 首先生成大纲与脚本，用户确认后才生成完整场景和声音。成熟 AI 视频工具也普遍采用“大纲/Storyboard 宏观审阅 → 进入编辑器细化”的方式，而不是把一次生成当成终点。[Synthesia Assistant 官方说明](https://help.synthesia.io/en/articles/13759605-how-do-i-create-a-video-using-assistant)

### 3.2 模板是可执行结构，不是效果图

模板必须定义：

- 支持的场景角色。
- 每个角色的组件和版式。
- 动画语法。
- 字幕和安全区。
- 品牌资产与背景槽位。
- 横屏、竖屏、方形重排规则。

效果图只用于视觉方向，不能作为模板完成证据。

### 3.3 品牌能力独立于单个视频

品牌套件集中管理 Logo、颜色、字体、图像与模板，并能限制用户只能使用批准的视觉资产。Canva 和 Synthesia 都把 Brand Kit、模板和品牌控制作为规模化内容生产的核心能力。[Canva Brand Kit](https://www.canva.com/en_in/pro/brand-kit/)、[Synthesia Brand Kit](https://help.synthesia.io/en/articles/9046610-how-do-i-use-a-synthesia-brand-kit)

### 3.4 脚本、场景、图层与时间轴相互可追踪

用户选择一段脚本时，应能看到对应场景、字幕和动画区间；选择画面元素时，应能看到它在时间轴中的出现区间。这类脚本、场景和图层联动是成熟视频编辑体验的基础。[Descript 时间线说明](https://help.descript.com/hc/en-us/articles/10249307946893-Media-layers-scenes-and-the-script-in-the-Timeline)、[Adobe Express 视频时间线](https://helpx.adobe.com/express/web/video-creation-and-editing/create-videos/video.html)

### 3.5 字幕来自时间轴，不是静态文本框

字幕必须由解说脚本和语音时间戳生成，支持句级或词级同步、样式预设、主动词高亮以及 SRT/VTT 导出。动态字幕与脚本自动同步、逐词动画是成熟 AI 视频产品的明确能力。[Synthesia Captions](https://help.synthesia.io/en/articles/6341718-how-do-captions-work-in-synthesia)

## 4. 信息架构

继续沿用 Mona 真实界面：左侧项目历史、顶部四步流程、中间工作区，不新增独立应用外壳。

### 4.1 顶部四步

| 步骤 | 名称 | 核心产物 | 用户确认点 |
|---|---|---|---|
| 1 | 配置与规划 | 目标、受众、来源、大纲、系列风格 | 确认大纲与生产范围 |
| 2 | 脚本与分镜 | 解说脚本、屏幕文案、分镜角色、预计时长 | 锁定脚本与分镜 |
| 3 | 场景制作 | 素材、动画节拍、字幕、配音、场景 HTML | 场景级审阅与修订 |
| 4 | 审阅与交付 | 全片预览、检查报告、MP4、字幕与封面 | 确认导出版本 |

### 4.2 左侧项目区

- 系列分组与单条视频分组。
- 项目阶段、任务进度、失败状态、更新提示。
- 新建、复制、重命名、归档、删除。
- 搜索、最近使用、失败任务筛选。
- 系列展开后显示期数、风格版本与语言版本。

### 4.3 编辑区模式

- 默认模式：场景级工作流，不显示复杂图层。
- 精细模式：显示场景图层、音频波形、字幕 cue 和动画节拍。
- AI 助手始终作用于当前选中的项目、场景或脚本范围，并明确展示影响范围。

## 5. 完整功能规格

### 5.1 新建视频与内容规划

#### 输入方式

- 主题描述。
- 直接粘贴脚本。
- 导入 PDF、Word、PPT、Markdown、文本。
- 添加多个附件。
- 导入公开 URL。
- 从已有 Mona 笔记或 PPT 开始。
- 从已有视频复制内容结构或系列风格。

#### 生产目标

- 目标受众：新手、专业人员、管理层、客户等预设。
- 视频目标：解释、培训、营销、复盘、公告。
- 期望时长：短、中、长或精确分钟数。
- 语言、语气、信息密度。
- 画幅：16:9、9:16、1:1。
- 单条视频或系列视频。
- 模板：自动推荐或手动选择。
- 品牌/系列风格。
- 配音与字幕策略。

#### 生成前确认

系统先返回：

- 内容覆盖摘要。
- 预计场景数和时长。
- 大纲。
- 预计生成步骤与耗时。
- 需要的图片/视频素材数量。
- 预计积分或资源消耗。

用户确认后才创建完整生产任务。

### 5.2 大纲、脚本与来源追踪

每个大纲节点保存：

- 标题与目标。
- 来源文档片段。
- 解说要点。
- 是否必须保留原意。
- 预计时长。
- 场景角色建议。

脚本编辑器提供：

- 解说脚本与屏幕文案分离。
- 字数、语速和预计时长即时反馈。
- 一键缩短、扩写、口语化、专业化。
- 来源引用与事实核对提示。
- 修改差异对比。
- 场景拆分与合并。
- 脚本版本历史和恢复。

AI 重写默认只作用于选中段落，不能静默覆盖整片脚本。

### 5.3 分镜编辑

每个分镜必须包含：

| 字段 | 用途 |
|---|---|
| `role` | 封面、章节、内容、数据、对比、流程、引用、片尾 |
| `narration` | 解说文本 |
| `onScreenText` | 屏幕上展示的精简文案 |
| `visualIntent` | 希望画面表达什么 |
| `layout` | 模板允许的布局 |
| `assetSlots` | 所需图片、视频、图标、图表 |
| `duration` | 场景时长 |
| `motionPlanStatus` | 动画规划状态 |
| `subtitleTrackStatus` | 字幕同步状态 |

支持：

- 拖动排序、添加、复制、删除、拆分、合并。
- 批量修改角色、时长和模板主题。
- 自动识别内容过载或时长不足。
- 选中分镜后右侧显示脚本、画面、动画和声音摘要。
- 锁定后进入制作；修改锁定内容会明确标记下游产物失效。

### 5.4 素材与画面

#### 素材来源

- 用户上传。
- 文档内图片。
- Mona 素材库。
- AI 生图。
- 可授权的图库或视频库。
- 图表和信息图自动生成。

#### 素材控制

- AI 自动、始终替换、禁止替换三种策略。
- 来源、授权状态、生成提示词与使用场景可追溯。
- 图片裁切焦点、遮罩、滤镜和安全区继承系列规则。
- 素材缺失时使用明确占位状态，不能静默生成低质量图。
- 一个素材可复用于多个场景，但项目快照必须保证旧视频可重新导出。

### 5.5 系列、模板和品牌套件

#### 系列

- 系列名称、说明、默认画幅、片头、片尾、声音和背景策略。
- 每期自动编号。
- 系列封面与缩略图规则。
- 风格版本不可变，旧视频继续绑定旧版本。
- 批量选择旧视频升级风格。
- 删除系列时保留视频并解除分组；缺少本地快照时禁止危险删除。

#### 模板

- 内置模板和用户自定义模板。
- 模板发布前必须通过四角色、三画幅和自定义背景检查。
- 可从现有视频另存为模板。
- 模板资产支持“AI 可替换 / 始终保留 / 禁止修改”。
- 模板预览使用生产编译器渲染，不使用效果图冒充。

#### 品牌套件

- Logo 正版/反白版。
- 主色、辅助色和中性色板。
- 标题、正文和数字字体。
- 用户选定并确认使用权的图片、图标、片头、片尾和音乐。
- 用户可锁定系列必须保持一致的品牌字段。
- 模板和品牌套件分离：模板决定布局，品牌套件决定品牌身份。

### 5.6 动画规划

动画不能只给整个场景选择一个 `fade-rise`。每个分镜必须经过语义动画规划。

#### 输入

- 解说脚本与句子边界。
- 屏幕文案。
- 场景角色与模板组件。
- 素材类型。
- 场景时长。
- 系列动效强度。

#### 输出：`motion-plan.json`

```json
{
  "schemaVersion": 1,
  "sceneIndex": 3,
  "durationMs": 8200,
  "beats": [
    {
      "id": "beat-title",
      "startMs": 0,
      "endMs": 900,
      "trigger": "scene-start",
      "target": "title",
      "effect": "fade-rise",
      "intensity": "standard"
    },
    {
      "id": "beat-metric",
      "startMs": 2300,
      "endMs": 4200,
      "trigger": "subtitle-cue-2",
      "target": "metric.primary",
      "effect": "count-up",
      "contentRef": "metric-efficiency"
    }
  ]
}
```

#### 规划规则

- 标题、正文、图表、图片和字幕拥有独立时间段。
- 动画节拍应对齐解说句子或关键词，而不是平均分布。
- 数据场景支持数字递增、条形增长、折线绘制。
- 流程场景支持逐步点亮。
- 对比场景支持左右分阶段进入。
- 引用场景避免多余运动。
- 片尾必须预留品牌和行动号召停留时间。
- 一个场景默认不超过 5 个主要动画节拍。
- LLM 只能选择模板声明的目标和效果，不生成自由 CSS/JS。

#### 用户体验

- 默认显示“节奏摘要”，例如“标题淡入 → 三个要点依次出现 → 结论强调”。
- 精细模式显示可拖动节拍条。
- 提供“更克制 / 更有节奏 / 重新匹配脚本”操作。
- 修改脚本后，只重新规划受影响的节拍。

### 5.7 配音、音乐与字幕同步

#### 配音

- 多个音色和语速预设。
- 场景级试听与重生成。
- 发音词典、数字读法和专有名词纠正。
- 单场景失败不阻塞其他场景，但导出前必须明确提示。
- 音频缓存绑定脚本内容哈希。

#### 字幕

- TTS 提供词或句边界时直接使用。
- 无边界数据时运行强制对齐，生成句级/词级时间戳。
- 保存内部 JSON 轨道，同时导出 SRT、VTT。
- 支持关闭字幕、烧录字幕、外挂字幕三种交付方式。
- 动态字幕支持逐句、逐词、高亮当前词。
- 字幕样式继承系列字体和颜色。
- 自动检查每行字符数、阅读速度、安全区和遮挡。

#### 音乐

- 无音乐、轻背景、节奏型、品牌音乐预设。
- 自动侧链压低背景音乐，保证旁白清晰。
- 场景切换和片尾淡出。
- 音乐版权和来源可追踪。

### 5.8 场景制作工作台

默认界面维持三栏：

```text
场景列表 | 画布与真实预览 | 场景属性 / AI 助手
```

底部时间轴只在“精细模式”展开。

#### 画布

- 生产渲染器真实预览。
- 播放、暂停、逐帧、循环当前场景。
- 字幕安全区、品牌安全区和裁切参考线。
- 选择元素后展示语义名称，不展示 DOM/CSS。

#### 场景属性

- 布局预设。
- 素材槽位。
- 动画节奏摘要。
- 字幕与配音。
- 场景时长。
- AI 修改入口。

#### AI 操作

- 重写本场景脚本。
- 更换视觉表达。
- 重新匹配动画。
- 生成/替换素材。
- 缩短或延长场景。
- 检查内容与来源一致性。

每次 AI 操作先展示影响范围，执行后支持撤销。

### 5.9 审阅与版本

- 全片连续预览。
- 场景、脚本、音频和字幕状态总览。
- 按时间点添加审阅意见。
- 未解决意见阻止“正式版”导出，可允许草稿导出。
- 版本命名、创建说明和版本差异。
- 脚本、风格、素材和导出文件均可追溯到版本。
- 一键恢复上一版本。
- 已完成视频不因模板或系列修改而静默变化。

### 5.10 导出与交付

#### 导出预设

- 草稿：低分辨率快速审阅。
- 标准：1080p、30fps。
- 高质量：1080p/4K、30/60fps，按模板能力开放。
- 横屏、竖屏、方形独立输出。
- MP4、封面 PNG、SRT、VTT、纯音频。

#### 导出前检查

- 所有场景可渲染。
- 动画计划时间合法。
- 字幕时间轴合法且不越界。
- 音频总时长与场景总时长匹配。
- 背景和素材存在本地快照。
- 字体可用。
- 文字不溢出，安全区不冲突。
- 版权或来源警告已确认。

#### 后台任务

- 最小化后继续运行。
- 标题栏统一任务中心展示下载、TTS、场景生成、预览和导出。
- 支持取消、重试、查看错误详情和打开输出目录。
- 应用重启后恢复未完成任务状态。
- 导出使用项目快照，渲染中继续编辑不影响本次结果。

### 5.11 项目、模板与素材管理

- 自动保存与崩溃恢复。
- 项目复制、重命名、归档、删除和恢复。
- 模板复制、发布、停用和版本升级。
- 素材去重、引用追踪和安全删除。
- 存储占用统计与缓存清理。
- 导出历史与重新下载。
- 系列和项目搜索。

## 6. HyperFrames 执行架构

### 6.1 产品决策

HyperFrames 应成为正式的时间轴验证和渲染引擎；Mona 负责内容规划、语义组件和编辑体验。

职责边界：

| 层 | 职责 |
|---|---|
| Mona 内容规划器 | 文档理解、大纲、脚本、场景角色 |
| Mona 动画规划器 | 把脚本和字幕 cue 转为受约束的动画节拍 |
| Mona 场景编译器 | 把模板、内容、素材、动画计划编译成 HyperFrames composition |
| HyperFrames | 时间轴、预检、采样检查、预览和正式渲染 |
| FFmpeg | 音视频编码、混流、转码和多格式交付 |

### 6.2 生产调用链

```text
compile
  → hyperframes lint --json
  → hyperframes validate --json
  → hyperframes inspect --samples N --json
  → 用户低清预览
  → hyperframes render --strict
  → FFmpeg 音频混流与交付封装
```

当前自研 `render.py` 作为迁移期 fallback 保留，不能立即删除。迁移采用功能开关：

1. 相同项目同时执行 HyperFrames 验证和旧渲染器验证。
2. 建立固定项目的帧差、时长、字幕和音频基准。
3. HyperFrames 渲染失败自动回退旧渲染器，并记录原因。
4. 连续通过稳定性门槛后再切换默认引擎。
5. 保留旧项目兼容渲染，不强制重编译历史视频。

### 6.3 禁止双重真相

- 编辑器预览、低清预览和正式导出必须读取同一 composition。
- 不能前端实现一套动画、导出脚本再实现一套。
- 不能以模板截图替代时间轴预览。
- 不能让 LLM 直接写最终 HTML/CSS/JS。

## 7. 核心数据模型

### 7.1 项目结构

```text
video_projects/<project>/
```

## 8. 后台任务与可靠性

统一任务模型：

```json
{
  "jobId": "...",
  "type": "scene-build | voice | align | preview | export",
  "projectId": "...",
  "state": "queued | running | paused | failed | completed | cancelled",
  "stage": "...",
  "progress": 0,
  "retryable": true,
  "checkpoint": {},
  "error": {"code": "...", "message": "...", "action": "..."}
}
```

可靠性要求：

- 所有写入原子化。
- 重复请求幂等。
- 单场景失败不丢失其他成功结果。
- 每个任务保存阶段检查点。
- 应用重启后能够恢复任务或明确标记中断。
- 取消任务不删除已经完成的可复用产物。
- 输出文件先写临时路径，成功后原子替换。
- 项目目录损坏时提供诊断报告，不静默忽略。

## 9. 商业产品能力

### 9.1 成本与配额

- 生成前预估消耗。
- 区分脚本、图片、TTS、预览和正式渲染成本。
- 失败且没有有效产物时不重复扣费。
- 用户主动重试前展示是否会再次产生费用。
- 套餐限制在操作入口说明，不在任务执行后才报错。

### 9.2 本地工作区与账号边界

- 视频项目、系列、模板和品牌套件归当前用户的本地工作区所有。
- 风格锁定用于保证系列一致性和历史版本可复现，不代表管理员审批。
- Mona 账号只承载登录、套餐、积分和可选的多设备同步。
- 审阅意见和操作记录保存在用户自己的项目中。

### 9.3 隐私与合规

- 明确哪些步骤本地执行、哪些内容发送给模型或外部服务。
- 本地绝对路径不写入可分享项目。
- 渲染阶段默认禁止场景 HTML 访问外部网络。
- 上传素材进行 MIME、大小、路径和恶意内容检查。
- 记录 AI 生成素材与用户上传素材来源。
- 语音克隆、人物素材和版权音乐需要独立授权状态。

## 10. UI/UX 细节标准

- 默认只显示用户能理解的选项，禁止暴露组件 ID、CSS、动画内部名称和 Schema 字段。
- 常用参数用预设、分段按钮、色板和滑杆；自由输入只用于名称、脚本和用户内容。
- 每个 AI 操作说明“将修改什么”和“是否影响旧版本”。
- 保存中、已保存、失败、冲突必须可区分。
- 危险操作必须说明保留和删除范围。
- 后台任务不使用阻塞全屏弹窗。
- 错误信息包含用户可执行的下一步。
- 键盘可完成主流程，焦点状态可见。
- 支持减少动态效果。
- 在窄窗口仍可完成新建、脚本确认、场景审阅与导出。

## 11. 非功能要求

### 性能

- 配置与脚本自动保存：本地写入 p95 小于 300ms。
- 颜色、字体和模板预览更新：p95 小于 1s。
- 场景低清预览开始响应：p95 小于 3s，不含外部模型生成。
- 项目列表 1000 个项目仍可搜索与分页。
- 长视频按场景增量渲染，不因单处修改重渲染全部场景。

### 可用性

- 项目关键写入成功率不低于 99.9%。
- 导出任务有明确失败码和可重试策略。
- 应用异常退出后不丢失已确认脚本和分镜。
- 渲染器升级不改变旧项目输出，除非用户主动迁移。

### 质量

- 字幕不越界、不遮挡关键内容。
- 屏幕文字阅读速度、行数和字号通过门禁。
- 音频时长与画面时长误差不超过定义阈值。
- 同系列同版本的字体、组件、字幕和动效语法一致。
- 三种画幅分别执行溢出和安全区检查。

## 13. 分阶段交付路线

### P0：保护现有基本能力

目标：任何后续改造不得再次把动画视频退化为静态画面。

- 固化单条视频、系列视频、旁白、无旁白、三画幅的 MP4 黄金样例。
- 自动验证首帧、中间帧和末帧确有变化。
- 验证音频、时长、分辨率和可解码性。
- 为新引擎增加功能开关和自动回退。
- CI 必须实际渲染短 MP4，而不只测试 HTML 字符串。

退出标准：所有黄金样例可重复导出，旧项目回归通过。

### P1：脚本、字幕和动画时间轴

- `script.json`、`motion-plan.json`、`subtitle-track.json` schema。
- TTS 句/词边界或强制对齐。
- 场景语义动画规划器。
- 动态字幕三套预设。
- 场景低清时间轴预览。
- 动画与字幕门禁。

退出标准：旁白、字幕和主要视觉节拍在时间轴上可验证对应。

### P2：HyperFrames 正式接入

- 编译 HyperFrames composition。
- lint、validate、inspect 和 render 调用。
- 与旧渲染器双跑对比。
- 失败自动回退。
- 真实进度与取消。

退出标准：目标项目默认使用 HyperFrames 导出，连续稳定性指标达标。

### P3：成熟场景工作台

- 脚本/场景/素材联动。
- 精细模式时间轴。
- AI 局部修改与撤销。
- 素材库、来源和版权状态。
- 全片审阅和版本恢复。

退出标准：用户不用编辑代码即可完成从脚本到正式交付。

### P4：商业化与规模化生产

- 品牌套件和系列风格锁定。
- 用户自定义模板和品牌资产复用。
- 审阅意见与发布确认。
- 费用预估、配额和失败扣费规则。
- 多语言、字幕和配音版本管理。

退出标准：用户能够稳定批量生产、审核和维护系列视频。

## 14. 最终验收场景

1. 导入 20 页 PDF，生成大纲，用户删除一章后再生成脚本，删除内容不会进入后续场景。
2. 生成 8 个分镜，每个分镜的标题、数据、图片和结论按解说句子节拍出现。
3. TTS 生成后字幕逐句同步，修改一句脚本只让对应音频、字幕和动画节拍失效。
4. 使用同一系列风格生成三期视频，组件和字幕规则一致，内容与动画节拍不同。
5. 将横屏项目切换为竖屏，标题、字幕、背景焦点和数据卡完成重排且不溢出。
6. 导出中关闭页面，任务继续；重启应用后能够查看进度或恢复。
7. HyperFrames 验证失败时展示明确错误并自动回退旧渲染器，不丢失项目。
8. 正式导出同时得到 MP4、封面、SRT/VTT 和质量报告。
9. 修改系列风格生成 v2，旧视频继续按 v1 可复现，选择的项目可批量升级。
10. 删除有视频的系列时保留视频和本地风格快照；缺少快照时拒绝危险删除。

## 15. 不做空头承诺

- 文生图概念图不等于视频模板已实现。
- 有 MP4 文件不等于动画与脚本对应。
- 有字幕文本不等于字幕与声音同步。
- 仓库中存在 HyperFrames 包装代码不等于生产正在使用 HyperFrames。
- 前端预览可播放不等于正式导出使用同一时间轴。
- 测试 HTML 字符串不等于完成真实视频验收。

所有能力只有在真实项目、真实时间轴和实际 MP4 渲染通过后，才能标记为“已交付”。
