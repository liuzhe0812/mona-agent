# Mona 更新日志

## 1.8.2 · 2026-10-26

这一版让邮件处理、订阅账号连接和文档创作更顺手，同时完善股票研究、账户管理与多设备使用体验。

### 邮件处理

- 在“全部收件箱”集中查看多个邮箱，搜索已收取的邮件正文，并继续翻页查找较早的邮件。
- 支持安排稍后发送，Mona 保持运行时按计划发出；可在待发箱查看进度或取消尚未发送的邮件，结果暂时无法确认时先核对已发送邮件，避免重复发送。
- 后台持续补收历史邮件和正文，优先响应正在打开的邮件；已完整保存的邮件可离线阅读。
- 改善草稿、附件和内嵌图片的保存与读取，保留密送信息；完善文件夹操作、未读数和新邮件提醒。
- 改善从邮件提取日程时对收件人身份的判断，让待办更贴合当前账号。

### 订阅账号与模型

- 简化 Codex、Claude Code 和 WorkBuddy 的准备与登录流程，在模型来源页即可查看连接情况和可用模型。
- 使用 WorkBuddy 订阅时，可复用电脑中已有的 WorkBuddy 应用，也可不安装完整应用，直接在 Mona 中连接订阅账号。
- 可分别查看电脑已有程序和 Mona 管理的副本；更新或移除 Mona 副本不影响电脑原有程序和账号。
- 模型选择列表直接显示已知的消耗倍率；用量页面更清楚地区分模型输入、输出、缓存使用和账户费用。
- 改善通过订阅账号使用模型时生成长回答的稳定性。

### PPT 与思维导图

- 制作 PPT 时可从 Word、PDF 或已有 PPT 中提取原图，结合原文和出处复用到新页面，减少重新寻找素材的步骤。
- 新增 PPT 页面时可同时填入文字、图形、图片和图表，减少空白页与分步编辑带来的等待。
- 可以直接让 Mona 修改当前思维导图的节点、层级和文字，并检查或导出实际画面。
- 编辑时继续核对当前文档版本，避免 AI 覆盖刚刚手动修改的内容。

### 股票研究与复盘

- 完善选股、策略研究和策略管理流程，支持因子分析、按条件回测、查阅研究报告与原始材料。
- 完善本地模拟账户和成交复盘，便于对照研究结论与后续表现。
- 改善股票页面的筛选区、滚动和暂无数据时的提示；切换工作区后继续保留使用偏好。

### 账户、同步与日常使用

- 在账户页集中查看订阅权益、模型余额、登录设备和个人云空间；充值金额、订单记录与自动续费操作更易找到。
- 已开通 Pro 时避免重复购买；关闭支付窗口后刷新权益，查询暂时失败时保留已确认的状态。
- 多设备同步支持保存的运维主机配置，上传前明确选择；其他设备收到配置后不会自动连接主机。
- 笔记和邮件可在各自模块的设置中管理 AI 搜索范围。
- 主导航按当前显示顺序分配 Alt 数字快捷键，按住 Alt 可查看提示。
- 对话中的思考与操作过程可收起查看，群聊时间更清楚；优化首页快捷提示和窄窗口输入体验。
- 改善个人洞察图表和终端操作失败提示。

## 1.8.1 · 2026-10-16

这一版完善多设备同步、独立模型选择、开发协作与视频创作，并补齐可视化、PPT、系统维护和桌面通知体验。

### 多设备与云同步

- 新增 Pro 设备管理，以及 Work 会话、个人计划、笔记和附件的加密同步。
- 支持云端回收站、过期历史与上传清理，重要清理操作保留明确确认。
- 自动恢复账号密钥；附件暂不可用时仍继续同步，并提供可操作的提醒。
- 修复无标题笔记、远程图片名称和设备登录恢复等同步问题。

### 模型、会话与协作

- Agent 和视频制作会话可独立选择 API 或已连接的原生模型来源，并保留各自的模型与思考强度。
- Work 对话支持流式展示交互图表与可视化内容，在隔离环境中显示和回放。
- 群聊新增角色讨论，改进公开上下文、轮次衔接、排队消息和协作结果反馈。
- 改进会话历史整理与 Windows 原子保存；保存失败保留已有结果并明确提示。

### 开发工作台

- 支持后台命令、持续输出和运行中的补充指令，完善任务队列与执行状态。
- 改进原生来源连接、工具回执、历史恢复和文件内容展示。

### 视频创作

- 重建导演台和视频工作区，支持项目模型选择、自定义风格制作与样片编辑。
- 新增七套 Dashi 风格画廊及 Dashi、Huashu 动画参考，改进分镜导航与真实制作进展。
- 统一旁白、音乐、音效与源素材的声音混合，改进字幕分组、片段试听和整片预览。
- 改进导出进度、超时和取消处理，避免编码过程无限等待。

### PPT 与桌面体验

- 新增 Dashi 原生设计组件和按需素材，改进幻灯片布局、文字测量与打包资源筛选。
- 系统维护整合存储分析与对话，统一文件图标、文件树和预览交互。
- 使用原生桌面通知，完善邮件内嵌附件、预览及通知跳转。
- 修复编辑排队消息后的输入焦点，统一共享控件和多语言文案。

## 1.8.0 · 2026-10-11

这一版新增开发工作台，完善模型来源管理，并改进长任务、浏览器、终端和邮件日程体验。

### 开发工作台

- 新增项目、任务与运行记录，支持 Mona Coding、Codex、Claude Code 和 CodeBuddy 执行来源。
- 支持计划、探索与执行子任务、代码差异审查、文件预览，以及 Git 分支、提交和变更操作。
- 支持询问、自动与完全访问权限；子任务继承主任务边界，结果不明的写入保持待核对状态。
- 原生程序、账号、模型与运行时资源分开管理，支持程序发现、安装和状态检查。

### 模型与长任务

- 统一模型来源和账号界面，补齐思考强度、原生账号用量与模型能力信息。
- 按上下文压力整理长任务，显示已知或估算的上下文占用，并完善中断后的状态恢复。
- 保留长会话分页和历史缓存，完善待发消息、附件回执与会话绑定。

### 浏览器、终端与文件

- 完善浏览器预览、目标页关联和恢复；Windows 浏览器支持本地扩展管理。
- 新增独立 SSH 工作区，改进保存连接、终端会话切换与进程生命周期。
- 增强 PDF 视觉读取和文件编辑记录，完善附件与文件预览体验。

### 邮件、日程与界面

- 邮件提取日程结合账号、收件人和时区信息，完善待办关联和手动提取入口。
- 右侧概览默认收起；会话列表的窄窗口断点改为 768px。
- 统一开发、运维和会话入口，完善输入、导航与反馈状态。

## 1.7.1 · 2026-09-23

这一版新增 macOS 版本，重做电脑操作的观察与动作链路，并补齐笔记、交付物与终端协作体验。

### 长会话加载

- 会话首屏按页读取近期消息，可继续加载更早内容。
- 增加可重建的历史显示缓存；记录未改变时，重新打开和应用重启可复用整理结果。
- 优化流式回复与思考记录的历史重放，附件仅按当前页处理；耗时读取在后台执行。
- 保留完整历史搜索、输入历史与消息分支定位；加载异常可重试。

### 新增 macOS 版本

- 新增 Apple 芯片版 macOS 安装包。
- Mac 包采用免费签名、未经 Apple 公证；首次打开可能需要在系统设置的“隐私与安全性”中允许此应用。

### 电脑操作

- 重建观察与动作链路：坐标统一回到原图空间，窗口身份或尺寸变化会让旧观察失效，点击落点更可控。
- 支持坐标点击与视觉候选，系统元素标识保持权威，Mona 推断的候选不会冒充系统元素。
- 新增可选的快速决策模型，默认关闭；关闭时仍按主模型逐步观察和操作，浏览器同样接入该模型。

### 演示文稿

- 新增原生预设页面体系，覆盖封面、对比、流程、矩阵、图表等常用版式，自动匹配配色与字体。
- 补齐图表样式与自定义路径，导出的 PPTX 保留可继续编辑的对象。
- 新增浅色与深色预设版式、示例素材和设计参考，便于复用不同类型的演示页面。

### 媒体与通道

- WebSocket 收发的图片与文件会落盘保存，并自动清理过期文件。

### Agent 与界面

- 工具边界更明确，长上下文处理更稳定。
- 刷新设置、画布会话与交付预览界面，升级前端构建工具链。

### 笔记、交付物与终端

- 笔记支持 AI 结构化修改建议，可预览、应用或忽略；笔记变化后会重新校验建议。
- 交付物预览新增“今日/全部”筛选，便于快速查看近期交付。
- 终端维护历史支持批量清除已结束任务；AI 对话可在重连后恢复。

### 许可证

- 项目许可证调整为 Mona 专有许可，详见随软件发布的许可条款。

## 1.7.0 · 2026-09-16

这一版让 Mona 的工具边界更清晰、桌面工作台更完整，并补齐数据库、系统维护与音乐、PDF 创作能力。

### 数据库与终端工作台

- 重建 SQL 工作区：连接树、表结构编辑、存储过程与例程、SQL 补全，以及数据库导入导出。
- 终端新增 SSH Docker 管理，可查看和操作容器、镜像与 Compose 项目。

### 系统维护

- 新增软件卸载与残留清理，卸载后可识别并清理遗留文件与注册表项。
- 新增应用商店面板，集中查看与安装可用应用。

### 创作与文档能力

- 新增内置 PDF 工具：读取、表格提取、页面渲染、合并、提取、旋转、表单填写与批注、新建 PDF。
- 新增乐谱与吉他谱生成，交付物可直接预览和试听。
- 文档、表格与演示工作台补齐运行时与审阅流程，保留保存与导出反馈。

### Agent 能力与工具边界

- 工具按能力暴露，Agent 工具权限更明确；动态能力需显式授权后才可调用。
- 会话历史支持关键词检索，方便找回此前对话中的信息。

### 性能与稳定性

- 精简系统提示词与技能目录，降低上下文开销，并支持配置自动压缩阈值。
- 收敛 Gateway 路由与 WebSocket 通道处理，减少无效请求面。
- 专家包改为不可变发布，避免更新时被就地改写。

### 桌面体验

- 刷新外壳、会话列表、笔记与交付预览界面，工件列表更易浏览。
- 升级前端构建工具链。

## 1.6.0 · 2026-09-10

这一版把 Mona 从单一对话工具扩展为可持续协作的桌面工作台：文档、知识、自动化、研究和内容创作可以在同一处完成，并持续保留上下文与成果。

### 更会协作的 AI 工作台

- 支持多个专业 Agent 协同完成复杂任务，能够分配工作、汇总进度并保留可追溯的执行结果。
- 新增任务计划、交付物概览和更完整的会话恢复机制，长任务中断后可以继续推进。
- 扩展 Agent 知识与个人偏好能力，让回答和交付更贴合已有资料、工作习惯与当前任务。

### 文档、表格和演示协作

- 文档工作台支持直接新建、打开和编辑 Word、Excel、PowerPoint 文件。
- 表格、图表、幻灯片和文档修改使用统一的实时协作流程，保留版本、保存和导出反馈。
- 新增面向专业文档创作的 Agent、技能和模板，支持从提纲到成品的连续制作。

### 知识与个人洞察

- 资料库支持导入、检索、结构化整理和视觉内容理解，搜索结果可回到原始证据。
- 新增个人画像、工作规律和 AI 建议视图，帮助用户了解常用工作方式与可自动化的环节。
- 优化资料访问边界，区分不同 Agent、会话和用户级信息，减少无关内容混入任务。

### 创作与可视化能力

- 增强图片、视频、流程图和画布创作能力，支持从需求、素材、分镜到交付物的连续流程。
- 新增视频系列模板、风格管理和项目化制作能力，方便复用视觉语言。
- 优化 AI 流程图的排版、连接线、预览和编辑体验。

### 桌面体验与生产可靠性

- 浏览器、邮件、终端、系统工具和文件交付能力进一步整合到桌面工作台。
- 改进更新提醒：默认隐藏，确认有更高版本才显示；旧清单不会再触发降级提示。
- 改进热更新：Gateway 与 Services 不会再并发覆盖同一份运行资源；更新失败会保留或恢复旧文件。
- 发布流程现在同步更新官网更新日志，并在下载内容、官网页面和更新清单全部验证后才完成发布。
