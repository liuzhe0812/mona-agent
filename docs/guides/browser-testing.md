# 浏览器模块验证指南

浏览器生命周期、事件、布局、菜单、下载或权限发生变化时，至少检查：

| 场景 | 操作 | 通过标准 |
|---|---|---|
| Dev 启动 | 连续启动两次 | 不自动打开上次网页；无额外白窗 |
| 地址栏 | 新标签输入 URL 回车 | 页面显示；历史建议仍可显示 |
| 普通导航 | 同标签连续访问多个页面 | 地址、标题、前进和后退正确 |
| 新标签链接 | 点击 `target=_blank` 和 `window.open` | 每次只创建一个新标签并加载 |
| 下载 | 从真实公开页面发起测试下载 | 只产生一条记录和一个目标文件；不执行下载文件 |
| 标签压力 | 打开、操作、关闭标签 20 轮 | 无孤儿 WebView；窗口 IPC 不阻塞 |
| 窗口操作 | 压力测试前后拖动、最小化、还原和最大化 | 每次均生效 |
| 主模块切换 | 浏览器与聊天、笔记、终端往返 | 网页不悬浮在其他模块上 |
| 菜单和浮层 | 地址建议、书签菜单、设置和下载面板 | 网页不闪烁、不挤压、不遮挡菜单 |
| 工具栏 | 后退、前进、刷新、缩放、打印和开发者工具 | 不阻塞窗口操作 |
| 安全 | 检查远程页上下文 | 不暴露 Mona/Tauri 特权 API |

自动化压力测试每轮探测一个只读窗口命令和 `browser_list_tabs` 响应。异常时保存当前标签、CDP target 和进程快照，不通过重复创建 WebView 恢复。

修改流程：

1. 标出涉及的所有权层和事件入口。
2. 搜索入口的全部调用者及同类原生 handler。
3. 增加能复现问题的最小测试或压力脚本。
4. 优先删除重复路径，再修改唯一入口。
5. 执行目标测试、前端构建、Rust 检查和本指南回归矩阵。
6. 对比最终 diff，确认没有为单点问题增加第二套实现。
