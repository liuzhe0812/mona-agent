# AI 文档模块开发计划

> 目标:将孤立的 PPT 模块泛化为"AI 文档"聚合模块,下设 PPT / 视频 / 流程图三个子类型
> 原则:渐进式改造,每个 Phase 可编译可验证,Phase 1 必须保证 PPT 现有功能零回归
> 设计文档:[2026-07-08-AI文档模块设计方案.md](./2026-07-08-AI文档模块设计方案.md)

## 现状基线

**已具备**:
- PPT 完整工作流:mona-ppt skill + svg_to_pptx.py + PptMakerView 前端
- agent_kind 路由机制:`"ppt"` 经 WS 传入 → 写入 session.metadata → loop.py 委派
- PPTAgentLoop + PPTContextBuilder(工具白名单 + ppt_soul.md + mona-ppt skill)
- WebView2 已内置(Tauri)

**核心短板**:
1. agent_kind 路由硬编码只支持 `"ppt"`,无法扩展
2. PPTAgentLoop / PPTContextBuilder 硬编码 soul 和 skill,无法复用
3. 视频、流程图无任何实现
4. 前端 PPT 孤立入口,无聚合容器
