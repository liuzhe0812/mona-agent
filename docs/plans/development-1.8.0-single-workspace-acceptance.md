## 当前工作台

左侧按项目展示对应会话，中央始终一个主会话，右侧默认概览；工具按需打开工作标签，Git 作为悬浮入口。旧多屏入口和布局已不在当前界面中；旧本地视图数据只恢复此前选中的会话，不重新启动任何任务。

概览展示当前执行者、实际运行状态、结构化计划、项目规则和子智能体配置入口。子智能体有独立配置与运行记录，配置保存本身不启动任务。右侧查看子会话时不替换主会话。

本轮在既有单主会话工作区上完成：

- 工具调用与结果按 runId + toolCallId 精确配对，显示为单条可展开操作。无明确关联的历史结果独立保留，绝不按相邻位置或工具名称猜测归属。
- 后端公共消息新增 toolCallId；不增加推理内容、原生私有数据或凭据字段。
- 原生命令的开始、流式输出和完成按原生 item identity 合并。相同事件不重复追加输出；最终完整输出替换增量。结果未知或非零退出不能画成测试通过。
- 会话滚动仅控制自己的内容容器。用户阅读历史时不强制追到最后；回到最新后才自动跟随。Markdown 高度变化通过 ResizeObserver 同步，不拉动整个应用窗口。
- 相同快照中的已完成消息复用引用，流式更新不反复重渲染历史 Markdown。旧版本、旧事件游标或较短的迟到快照不会回滚新状态。
- 项目会话行展示真实更新时间。全局导航没有重建或修改。
- 子智能体编辑草稿按项目保存，关闭配置标签仍保留。遇到版本冲突，重新读取保留当前草稿，使用最新版本再次保存，并保留其他子智能体的修改。
- 辅助会话恢复核对项目、父会话和只读属性，错误绑定不会显示或默默替换。子会话读取错误可见。
- Git 浮层支持 Escape 关闭并恢复焦点；显示旧计划时标识其所属轮次。

主要源码：`webui/src/components/development/DevelopmentTranscript.tsx`、`DevelopmentActivity.tsx`、`DevelopmentPane.tsx`、`DevelopmentSidebar.tsx`、`DevelopmentSubagents.tsx`、`DevelopmentProjectSidebar.tsx`、`DevelopmentGitTools.tsx`、`store.ts`，以及后端 `mona/development/runtime.py` 的公共结果标识。

## 尚未宣称完成的范围

- Git 浮层目前能读取真实分支和变更、打开差异，以及将提交方案要求加入草稿；它没有静默执行 commit 或 push，也没有虚构提交进度。完整的提交/推送确认交互仍需补齐。
- 原生终端和浏览器已接现有宿主，但本轮浏览器自动化不替代 Windows 桌面实际面板布局与进程生命周期验收。
- Codex、Claude 的连接改造由另一个任务处理；本轮不修改其认证路径，也不使用普通模型调用冒充原生引擎验收。
