# Office 编辑效率与 PPT 混合排版

状态：功能实现完成，已通过原生编辑器验收。

## 本次目标

- 局部编辑一次读取所选元素、属性和版本；按页/元素过滤先于构建详细数据。
- 按需发现操作参数，缩短三种文档共用工具的常驻描述。
- 图片通过工作区资产路径由工具安全读取，Agent 不输出位图 base64。
- 增加静态 SVG 矢量图片与原生网格混排；文字、形状、照片和图标保持独立对象。
- 修改回执包含新建/更新元素与局部布局警告；视觉审核支持区域裁切。
- 局部刷新与持久化合并减少重复全量工作，维持版本检查、Undo 和精确 checkpoint。

## 验收

1. 真实模型/保存重开测试，拒绝未知目标、危险 SVG、工作区外素材和过期版本。
2. 验证混排几何、原生文字/形状可编辑、位图/SVG 分别保留、未目标元素不变。
3. 通过真实编辑器桥逐批创建一页图标/照片/文字/SVG 混排，并检查即时画面和重开画面。
4. 运行相关 Python、TypeScript、编辑器测试与构建；记录可复现的局部效率指标。

本次不把命令链测试表述成自然语言模型效果提升百分比，不覆盖用户正在编辑的原文件。

## 实现与结果

- `selection` 直接返回选中元素属性和页面尺寸；`slides` 支持稳定元素 ID 筛选与 `includeData: false` 样式读取。图表数据读取保持原有默认行为。
- `capabilities` 按当前文档/元素类型返回字段；图片 `assetPath` 在 Gateway 校验工作区范围后转为图片数据。
- `slide_compose` 将正权重网格、跨行跨列和层叠项转为原生添加操作；SVG 静态子集保留为矢量图片，拒绝活动内容与外部引用。
- 回执返回创建/更新的元素、所属页面与布局警告。空形状不误报文字溢出。
- 常见局部事务只深拷贝相关页面，历史资源共享不可变字节；原子执行器仍有其完整回滚快照，跨页操作仍保留全量路径。未受影响页面复用渲染树，媒体字节未变时复用编码。
- 提交时冻结精确版本，收到 checkpoint 请求时才压缩；多次请求复用同一结果。旧版本测试在后续编辑后仍恢复原内容。
- 浏览器以实际字体宽度布局文字，非浏览器测试继续使用现有确定性估算；垂直行高仍使用既有度量策略，不能外推为所有字体的 Office 保真保证。
