## 已实现

- 风格选择使用“内置 / 我的”图卡，支持从内置风格开始、描述或参考图创建、编辑、复制、重命名、删除和未完成草稿恢复。
- 新风格编辑页以真实样片为主体，右侧共用“对话 / 样式”面板。首次仅生成，样片可用后保存；表单只展示有实际源码绑定的字段。参考图选择、粘贴、拖入复用既有图片编码与上传通道。
- 用户通过自然语言继续修改同一风格样片，活动样片上下文随请求进入 Agent，但用户消息仍显示原话。样片有独立原会话，主列表可以回到该编辑页；可见与已读规则共用既有会话记录。
- 草稿按修订保存，已保存风格包含实际源码、规则、素材、旁白缓存和采样产生的预览。保存前拒绝未完成、过期、缺失或损坏的样片；不可变快照供新项目使用，原项目不会被后续编辑改写。
- 已保存自定义风格与内置风格同样进入 Agent 可选目录；用户固定选择或版本保持，自动选择不能悄悄覆盖。
- 样片生成保持明确的短样片授权，正式视频保留导演确认。画幅、颜色和字体修改有真实后端更新与重新采样路径，不靠拉伸画布或更换选择器文字冒充生效。
- 历史恢复、复制使用保存版本的快照，清除旧实时项目绑定；文件路径、素材与快照哈希经过校验。
- 参考图恢复通过受鉴权的草稿索引读取，限制在工作区上传目录、通过图片验证；读取失败保留文件名，离开页面清理缩略图资源。Services 与桌面 HTTP 桥使用同一鉴权范围。
- 删除被替代的 `SeriesStyleEditor`、`CreateVideoSeriesView`、`VideoSeriesSelector`，其测试由当前真实入口与业务行为的回归替代；旧风格数据读取与必要的旧视频编译支持保留。

## 联调发现并修正的问题

- 样片 `plan` 曾被普通导演流程重新设为需要确认；已区分短样片授权，普通视频继续确认，并保留样片修订检查。
- 完整样片播放器外壳曾使用不匹配的沙盒，改为与现有整片播放器一致的受控外壳边界；用户动画代码仍在内层 opaque iframe。
- 样片画幅曾调用仅支持配音的设置入口，现后端只对样片显式接受画幅，正式视频仍走导演流程；画幅变更保留声音。
- 草稿旧保存响应可能覆盖新的颜色，改为保存队列、最新服务端修订、仅提交本地字段和待提交视觉字段保护。纯名称变更不使风格视觉输入失效，视觉变更仍检查冲突。
- 保存成功不再误提示样片过期；没有新修改时禁用重复保存。短暂保存、读取和上传期间不显示无法取消的“停止”，停止只对应实际运行的制作任务。
- 页签隐藏的对话内容继续挂载，但外壳退出布局，不再把样式表单挤到半栏以下。竖屏截图发现播放控件遮挡字幕，现共用预览播放器在播放 1.5 秒后淡出控件，移动、触摸或键盘操作可唤回，暂停后保持可见；播放按钮文字不换行。该修复另经真实浏览器行为回归验证，旧截图仍保留为问题证据。
