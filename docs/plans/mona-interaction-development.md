# Mona 独立交互模块实施与验收

更新：2026-11-10。架构约束见 [独立交互模块](../architecture/mona-interaction.md)，完整目标见 [连续交互技术方案](../design/mona-realtime-interaction.md)。

用户已明确要求随对话持续生成表现，不接受少数固定动画按场景切换。现有演示只保留为通信验证工具；以下按完整目标推进，分批交付不等于将成品降为演示能力。

当前优先级（2026-11-10）：用户确认了工作姿态方向，并要求休息、工作、对话三种状态，休息保持自然 idle，墙钟及窗外昼夜跟随设备本地时间，进一步接通本地语音唤醒和可打断双工对话。美术和交互可并行推进；[美术制作与审核计划](mona-live2d-art-production.md)记录具体素材及未通过的问题。语音识别、回声与打断必须在实际设备验证，不能把演示或待确认文字输入视为全双工成品。

当前设备进展：Windows 本机已使用用户提供的 Core 验证三姿态 WebGL 加载及切换；Ubuntu 本机演示已启动并能读取三套模型资源，合成唤醒音与公开样本已走通本地 Sherpa 识别事件。两处均尚未证明自然眨眼、口型、真实麦克风回声消除或双工。CosyVoice 3 模型已在 Ubuntu 统一资源库中校验入库，推理依赖和实机试听仍在准备。目标设备上默认的 Mona Gateway 尚未发现，同机真实会话仍需接入验证。

2026-11-10 用户明确：Windows 为开发环境，Ubuntu 为最终生产环境；Mona 主程序与形象同机运行，语音识别和语音生成均使用本地模型。目前 Ubuntu 的单独演示不等于已部署生产，也未连接真实 Mona。

本地语音试听：CosyVoice3 的技术样音被用户评价为机械、音色不合适，不作为正式音色。按用户“清亮活泼的女声”偏好，已在 Ubuntu 上生成 Qwen3-TTS 0.6B Vivian 技术样音；RTX 2060 上 FP16 失败后使用 FP32，4.48 秒语音生成耗时 6.87 秒，为整段输出，并非实时流式结果。音色待用户试听，速度与双工打断尚需解决。

## 交付顺序

1. **完整契约与美术规格**：明确语义意图、连续参数、语音时间线、任务/对话/话语标识及插件能力；同步推进可绑定的正式 Mona 模型。现有独立基线不作为最终界面和动画验收。
2. **实时角色与媒体验证**：验证本地参数混合、口型时序、双向音频、语义停顿、真/误打断及恢复。可先使用有授权的可控模型校验程序，不以状态图冒充模型。
3. **Mona 渠道插件**：显式配置、配对鉴权、会话绑定、持久准入与结果核对、流式回复及权威任务事件；播音打断和任务取消分开处理。
4. **连续语义表演**：表演导演、注意力与情绪连续值、声音表达、语义手势、耳发尾的次级运动；用数分钟真实交谈样片验收，不能仅验证几种动作能播放。
5. **正式资源与 Ubuntu 交付**：完成正式模型调校和运行包，实机验证声音、回声、1080P 渲染、恢复和启动生命周期。

## 必要验收

- [x] 交互程序在没有安装 Mona 的独立环境中启动。
- [x] 模拟输入只执行一次，完整回复与片段结束含义明确。
- [x] 模拟会话断线只同步状态，不自动重新发送输入；真实接入的持久准入另行验收。
- [x] 本机开发服务拒绝异源写入、非本机 Host 和资源路径逃逸。
- [x] 已实现可选 Mona 渠道和独立客户端，默认未配置时不生成模拟回复。
- [x] 已实现正文与表演字段分离、有限参数校验、本地连续数值控制器及前端消费事件。
- [x] 接入固定版本的官方 Cubism Web Framework，构建本地渲染器、实际模型参数映射、资源范围校验；已在 Windows 本机验证三姿态模型渲染及切换。
- [x] 连续控制增加自然眨眼、注意力、头身微动与语气参数；口型时间线以真实播放位置采样，旧话语代次失效后不会复活，音频链路尚未接入。
- [x] 已实现消息持久准入、去重、明确轮次结束、结果未知后的人工核对及继续；通过隔离外部模型的真实 AgentLoop 链路测试。
- [ ] 渠道插件安装、禁用和退出不阻断 Mona 普通会话。
- [ ] 真实消息准入、会话权限及进程重启后的去重经过验证。
- [ ] 全双工语音区分句中停顿、附和、真正插话和误打断，且声音不会回灌成用户输入。
- [ ] viseme 嘴型、表情和手势跟随真实音频播放时钟；旧话语片段不会在插话后复活。
- [ ] 任务取消与播音打断分别有明确语义和权威回执。
- [ ] 连续参数与语义编排通过多分钟自然交谈验收，角色无突然复位和明显固定循环。
- [ ] 麦克风、声音提供商和连接失败有明确反馈；降级不伪装成已经成功。
- [ ] 原画、动画、音频与真实会话分别注明实际完成程度。
- [ ] Ubuntu 实机显示、音频和启动验证通过。

## 当前验证记录

- Windows 独立虚拟环境安装和启动成功；从 Mona 仓库外运行时确认未安装 `mona`。
- 新增结构化表演字段解析、本地控制器，以及 Mona 通道与独立终端的真实 AgentLoop/ChannelManager 链路测试；外部模型响应在测试中隔离，不表示用户的实际模型请求已经验证。
- Python 静态检查、JavaScript 语法检查及部署脚本静态检查通过。
- 浏览器实际发送模拟消息、完成回复、刷新恢复显示通过；按 1920×1080 检查了原画和输入布局。
- 尚未在用户当前运行实例启用渠道并验证实际模型请求；Ubuntu 已验证本地合成音频的唤醒与识别事件，但真实麦克风、回声、音频播放及自然语音仍未验收。Windows 端已验证三姿态 Core/WebGL 模型显示和切换，模型最终美术审核及 Ubuntu 桌面实时渲染仍待完成。
