# Mona Terminal - 页面布局说明

> 终端模块的范围仅限于 SSH Tab 被点击后显示的内容区域。
> 不修改 AppTitleBar、Sidebar、AgentWorkbench 等任何外部组件。
> 所有会话标签在终端模块页面内部。
> UI 风格与现有应用保持一致：Radix UI + Tailwind CSS + Lucide icons + HSL 主题变量。

## 9. SSH/SFTP 完全替换

Mona 完全替换系统自带的 `ssh` 和 `sftp` 命令：

| 命令 | Mona 行为 |
|------|----------|
| `ssh user@host` | 直接进入 Mona SSH 会话 (xterm.js 渲染) |
| `sftp user@host` | 直接打开 Mona SFTP 文件管理器 |

### 快捷命令

| 命令 | 行为 |
|------|------|
| `mona-ssh myserver` | 快速连接已保存的服务器 |
| `mona-sftp myserver` | 快速打开 SFTP 文件管理器 |
| `mona-connect list` | 列出所有已保存的连接 |

## 10. 主题适配

终端模块使用现有 HSL CSS 变量主题系统，不单独定义颜色：

| 元素 | 使用变量 |
|------|---------|
| 工具栏背景 | `bg-sidebar` |
| 标签栏背景 | `bg-sidebar` |
| 活跃标签 | `bg-background text-foreground` |
| 非活跃标签 | `text-muted-foreground hover:bg-sidebar-accent` |
| 终端区域 | xterm.js 使用主题变量动态适配 |
| 状态栏 | `bg-sidebar text-muted-foreground` |
| 连接指示灯 | `bg-emerald-500` (已连接) / `bg-amber-500` (连接中) / `bg-muted` (断开) |
