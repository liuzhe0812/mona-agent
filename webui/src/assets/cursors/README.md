# Resize cursors

Derived from Chromium's Windows [column](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/ui/resources/cursors/col_resize.cur) and [row](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/ui/resources/cursors/row_resize.cur) resize cursors, under the included BSD license.

The original monochrome resources invert 68 visible pixels against the background. These files encode those same pixels as opaque black, with all other pixels transparent. The 32×32 canvas, exact pixel coordinates and original hotspots (column: 10,8; row: 9,10) are unchanged. No drawing or scaling was applied.
