📌 关键发现

Mona 的独特优势

  • Dream两阶段手术式编辑：不是重写整个文件，而是用AgentRunner + edit_file做最小化精准修改
  • Git版本控制：唯一具备完整记忆版本管理的系统，可审计、可回退
  • SOUL.md独立人格文件：将Agent人格与事实记忆分离，更优雅
  • 行龄标注：通过Git blame自动标注过期行，辅助LLM判断记忆时效

OpenClaw 的独特优势

  • 混合检索：向量(0.7) + BM25(0.3) + MMR重排 + 时间衰减，开箱即用最强
  • 插件生态：5种记忆后端 + Memory Wiki知识库 + ContextEngine钩子
  • Commitments：短期随访记忆 + 心跳自动提醒，独有功能
  • 每日日志：按天自然分隔，结合时间衰减更符合人类记忆规律

Hermes 的独特优势

  • 四层记忆架构：唯一显式区分工作/情景/语义/程序性记忆
  • Nudge机制：Agent主动提示沉淀知识，减少信息流失
  • 安全扫描：最完善的注入防护、凭证检测、不可见字符过滤
  • Skill自我改进：程序性记忆可随使用自动优化

💡 Mona 改进建议（基于对比）

  • 补齐语义检索：这是Mona最大的短板，建议引入向量检索（可参考OpenClaw的混合检索方案）
  • 增加时间衰减：history.jsonl中的条目可加入检索权重衰减，避免陈旧信息干扰
  • 增加写入安全扫描：参考Hermes，对进入SOUL.md/USER.md/MEMORY.md的内容做注入和凭证检测
  • 考虑Nudge机制：在关键决策点主动提示用户确认是否沉淀为长期记忆
  • 插件化记忆后端：允许接入Honcho/Mem0等外部Provider增强语义理解
