设计要点

🔲 扁平侧边栏
• 默认收起（56px），仅图标
• 点击 ◸ 展开显示文字标签（180px）
• 无二级菜单，5 个顶级入口：
  💬 AI助手  💻 终端  📚 知识库  🔧 维护  ⚙️ 设置
• 子功能在各模块内部切换
🏠 首页 = AI 对话 + 快捷栏
• 首页即 AI 对话界面
• 顶部快捷按钮栏：新终端、RDP、上传文档、系统体检、SFTP
• AI 可直接触发操作（如连接 SSH、执行命令）
• 操作结果内联展示在对话中
📑 统一 TabBar
• 标题栏下方统一标签栏
• AI 对话、终端会话、笔记、文档共享
• 当前激活 Tab 高亮 + 蓝色顶边
• 连接状态指示灯（绿色=在线）
• 支持 Ctrl+Tab / Ctrl+W 切换关闭
🎨 深色主题优先
• 桌面工具类应用默认深色
• 终端/代码场景深色更舒适
• 后续可支持浅色主题切换
• 基于 Tailwind CSS slate 色板
