┌─────────────────────────────────────────────────┐ │ Title Bar (自定义, 全宽) │ ├──────┬──────────────────────────────────────────┤ │ │ TabBar (仅右侧主区域, 仅显示打开的内容) │ │ S ├──────────┬───────────────────────────────┤ │ i │ │ │ │ d │ 模块 │ 主内容区 │ │ e │ 面板 │ (对话/终端/文档/维护) │ │ b │ (可折叠)│ │ │ a │ │ │ │ r │ │ │ │ │ │ │ ├──────┼──────────┴───────────────────────────────┤ │ │ Composer (仅 AI 模块) │ └──────┴──────────────────────────────────────────┘ • Sidebar 顶到标题栏，不与 TabBar 同行 • TabBar 只在右侧主区域，只显示打开的内容 Tab • 点击 Sidebar 图标切换模块（= 首页），不需要首页 Tab • 模块面板（会话列表/连接列表/文档树）可折叠
