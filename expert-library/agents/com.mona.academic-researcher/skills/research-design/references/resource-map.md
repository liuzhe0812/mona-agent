# Research design resource map

Use the Nature proposal resources only for a proposal, opening report, research plan, or evidence-grounded review design:

- Read `upstream/nature-proposal-writer/upstream-skill.md`, then select one mode: `upstream/nature-proposal-writer/references/compose-mode.md`, `upstream/nature-proposal-writer/references/revise-mode.md`, or `upstream/nature-proposal-writer/references/hybrid-mode.md`.
- Initialize only the required foundation templates: `upstream/nature-proposal-writer/templates/00_scope.md`, `upstream/nature-proposal-writer/templates/01_research_canon.md`, `upstream/nature-proposal-writer/templates/02_evidence_table.md`, `upstream/nature-proposal-writer/templates/03_argument_map.md`, `upstream/nature-proposal-writer/templates/04_section_contracts.md`, and `upstream/nature-proposal-writer/templates/05_style_guide.md`.
- Use `upstream/nature-proposal-writer/references/stopping-rules.md` when evidence or feasibility is insufficient; use `upstream/nature-proposal-writer/references/降承诺提案模式.md` to narrow claims rather than invent support.
- Use `upstream/nature-proposal-writer/references/validation-checklist.md` and `upstream/nature-proposal-writer/references/evaluation-rubric.md` for proposal QA.

The upstream document's relative scripts path describes its original package. In Mona, run the integrated `build_proposal_docx.py` only through `skill_script_run` with skill `research-design`.

For research-idea generation, read `upstream/nature-paper-card/references/research-idea-gates.md`. Statistical resources include `upstream/nature-statistics/references/statistical-reporting.md`, `upstream/nature-statistics/references/common-failure-modes.md`, and `upstream/nature-statistics/references/reviewer-checklist.md`.

`build_proposal_docx.py` is available through `skill_script_run` when the user explicitly requests a DOCX export and its Python dependency is available.
