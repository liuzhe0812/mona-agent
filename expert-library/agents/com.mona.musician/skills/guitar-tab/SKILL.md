# 吉他六线谱

本 Skill 负责整首吉他编配。指弹独奏由一把吉他承担旋律、低音和必要的内声；弹唱编配在唱段提供伴奏，在器乐段承担旋律。交付使用 AlphaTex `.atex`，指法说明不能替代实际谱面。

## 资源路由

- 每次生成或修改前读取 `references/tab-syntax.md`。
- 需要定弦、把位、和弦按法或难度判断时读取 `references/fingering.md`。
- 需要扫弦、分解和弦或右手节奏时读取 `references/strumming.md`。
- 制作指弹或弹唱谱时读取 `references/arrangement.md` 和 `references/complete-examples.md` 的对应模式。短技法练习才参考 `references/examples.md`。

资源只能通过 `skill_reference_read` 读取。

## 工作步骤

1. 先选择指弹独奏或弹唱编配，再区分原创、已有作品改编和局部修改。用户只说“指弹”时按旋律独奏处理，只有明确要伴奏/分解练习时才只写伴奏。确定定弦、实际调、变调夹、速度、长度与难度；无其它线索时采用标准定弦、无变调夹、4/4、90 BPM并说明。
2. 指弹：先写可单独唱出的完整旋律句（音高、起音、时值、休止），再配强拍低音，最后填内声。弹唱：先列段落及小节范围，唱段写伴奏，前奏/间奏/solo/尾奏写有动机、有发展、有收束的旋律。按作品需要选择段落，不机械套用例谱长度。
3. 把音乐落到弦品。先保证旋律的节奏和走向，再选和弦手型与低音位置。旋律延续而其它弦起音时用 `t` 延音，不能把同音反复拨响冒充长音。按 `tab-syntax.md` 写出每小节，使用 `\section` 标出段落。写谱时可用注释标记旋律线和角色，不能只在交付说明中声称有旋律。
4. 分开检查音乐内容和演奏动作：旋律/低音是否保留，和弦音是否正确，是否有足够的手指按住持续音，下一拍能否在当前速度下换把。编配应按真实乐器品数限制，验证器的 0–36 是格式上限，不是所有吉他的可用音域。
5. 必须调用 `guitar_tab` 校验最终文件，用户明确长度时传入 `expected_bars`；逐条读取 issues，修订后对最终文件重新校验。不能用自己口算的“每小节正确”代替工具结果；末尾收束改成长音后尤其要重新合计该小节。
6. 用 `deliver_file` 交付 `.atex`。简短说明定弦、难度、演奏方式和关键换把位置。

## 输出边界

支持范围以 `tab-syntax.md` 的已验证子集为准。当前使用单轨共享节拍网格，逐弦延音可保留旋律与伴奏的不同结束点；不输出未支持的独立声部语法。复杂打板、特殊泛音和非标准节奏分组应说明限制。只在用户要求改编已有作品时做原谱旋律对照；原创按动机、乐句和段落关系评审。

## 验收

1. 交付物是 UTF-8 `.atex` 文件，包含 `\staff {tabs}` 和六弦定弦。
2. 预览只有六线谱，不出现五线谱；谱面按窗口宽度排成多行。
3. 品位数字、拍号、小节号、和弦名和节奏杆清晰可见。
4. 每小节时值正确，用户指定的小节数正确，`guitar_tab` 返回 `ok: true`。
5. 未要求修改五线谱时，不创建或改写 `.abc` 文件。
6. 格式通过不等于指法可行或音乐好听；交付说明区分工具检查、编配判断和需要演奏者复核的难点。未实际试听时不声称听过。
7. 指弹必须指出每个乐句的旋律位置，拿掉伴奏后仍形成有节奏、有方向的旋律。弹唱必须指出器乐段的小节范围，器乐段包含实际旋律音符，唱段不靠通篇加倍人声来冒充编配。任何必要简化都不应悄悄把独奏改成伴奏。
