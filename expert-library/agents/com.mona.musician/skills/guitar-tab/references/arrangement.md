# 吉他编配与修订

## 先确定吉他的角色

- 弹唱伴奏：人声是主线，选适合歌手的实际调，再找开放和弦/变调夹方案；填句放在人声空隙，副歌通过节奏密度、音区或重音变化形成对比。
- 指弹独奏：先落旋律与强拍低音，再填内声。旋律通常处于上方音区，也可有明确的低音旋律段；不能简单地把每拍最高音都当成旋律。为保住旋律可省略五音或重复根音，不强塞每拍六音和弦。同弦同品的持续音用 `t` 连接，独立起音的伴奏放在其它弦。
- 电吉他 riff：失真时低音区优先五度、八度和较稀疏的和弦排列；用休止、掌根闷音和重音塑造节奏。不要直接搬钢琴密集和弦。
- 两把吉他：分配节奏与旋律/回应角色，或错开音区与变调夹位置；不要仅复制同一声部。

## 指弹独奏：旋律先成立，再织入伴奏

1. 以2–4小节乐句为单位，先写能哼唱的音高与节奏草稿。旋律应有停顿、长短音和方向，动机在后句重复、移位或变奏；不要先循环拨弦型，再给高弦音贴“旋律”标签。
2. 在和声变化处或有节拍功能的位置放根音、五音或转位低音。拇指低音可以稳定，旋律不必跟着每拍重复。低音过低超音域时移八度或换转位，不牵连整条旋律乱跳八度。
3. 旋律间隙可加入内声或分解和弦，密度服从旋律。旋律与低音同拍时捏弦，持续旋律下面有内声起音时使用同弦同品延音。重复出现的品位数字若是重新拨弦，会改变音乐节奏；它不等价于延音。
4. 以乐句为单位选择把位，优先旋律连贯、共同指和空弦换把。不要为了全在0–3品而改变每个音的八度；高弦唱旋律有时需要5–9品。降难度优先删内声、减少低音更换，再讨论旋律简化。
5. 用 `ac` 对需要突出的旋律起音适量强调，`dy` 表示全拍/乐句力度；两者不能代替演奏时的声部平衡。小节中每个音都加重音会抹掉主次。右手说明写出拇指低音和食/中/无名指的分工，左手只在关键换把、横按处说明。

例如完整例谱的主题回归应认得出来，B段可以换音区、动机节奏或和声张力，尾声通过终止音与节奏放宽收束，不仅改段落标题。

## 弹唱：唱段让位，器乐段说话

先给各段安排角色与进入点。已有歌曲使用其实际结构；原创短示例可采用“前奏—主歌—副歌—间奏—副歌回归—尾奏”，用户只要某段时只完成那一段。

| 段落 | 吉他写作任务 | 衔接要求 |
| --- | --- | --- |
| 前奏 | 提示主旋律动机或独立hook，可用单音、双音和稀疏低音 | 最后一拍/小节给出人声起句空间与调性感 |
| 主歌 | 扫弦或分解伴奏，人声为主；歌词句尾才适量填句 | 低音与重音稳定，避免持续高音solo盖住人声 |
| 副歌 | 通过和弦音区、重音或织体厚度提高能量 | 不以所有位置都扫满作为唯一变化 |
| 间奏/solo | 引用前奏或副歌动机，发展为问答、经过音、滑音等实际旋律句 | 清楚标明起止小节，末句导回下一和弦/人声起句 |
| 尾奏 | 回扣hook，缩短、重复或变奏后解决到终止音 | 写清最终延音和休止，不突然截断循环 |

器乐段不要求每拍单音：单音、和弦旋律和分解织体均可，但听者应能跟踪一条主线。只有一把吉他时，solo里需要的低音/和声应可由同一人弹出，不能暗中依赖第二把吉他持续伴奏。

交付弹唱谱时说明这是吉他声部，唱段人声由演唱者承担；若未提供人声旋律，不编造“已与人声逐拍对齐”。歌词只在用户需要且有可用内容时处理，不能因没有歌词而省掉器乐段。

## 从音乐到弦品

先按实际音高确定候选位置，再沿乐句选择一条动作连贯的路线。标准定弦下，实际音高 = 空弦 MIDI 音高 + 变调夹品数 + 相对品位。开放弦有利于延响和换把，但转调后可能失去这一优势，不能只把所有品位整体平移。

同一旋律试比较两种把位：优先保留旋律、低音与指定技法，再减少不必要的大幅换把、跨弦和横按。跨度、手指数、连续速度与持续音互相影响，不能用一个“难度分数”保证可演奏。

## 交付前的音乐复核

1. 原创检查动机、问答、高潮和收束；已有作品改编才按小节比对原旋律、节奏与和弦，并明确省略、移八度或重配。两类任务不要混为“钢琴转吉他”。
2. 对最难的换和弦/换把处，写出前后弦品、目标速度和可选简化。休止、空弦或共同指可以提供换把机会，不固定要求“留一个八分音符”。
3. 局部修改保留其它小节的音乐内容。降低难度优先简化内声、减少横按与换把，保住主旋律和节奏辨识度。
4. 分开检查结构/时值、吉他动作和试听效果。程序校验只能证明其实际检查的规则。
