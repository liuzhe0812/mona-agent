# 扫弦、分解与节奏

所有右手模式都必须落到 AlphaTex 的真实节拍中。

## 扫弦

一次扫弦是同一时点的弦品组合，例如 C 和弦四分下扫：

```text
(0.1 1.2 0.3 2.4 3.5).4 {ch "C" sd}
```

八分扫弦一小节占八个八分位置，可组合实扫、休止和延长，不能为了凑拍每格都触发。用 `{sd}`、`{su}` 标记上下拨；右手保持稳定运动，未击弦的回程不用额外生成音符。十六分切分先写节奏网格，再分配实扫与制音。

掌根闷音用 `{pm}` 保留音高；刮弦死音用 `x.弦号.时值`，不弹弦直接省略。方向标记不会自动把一个同时发声的和弦变成逐弦琶音；要分解时显式写各次起音。

## 分解和弦

分解和弦每拍只写实际弹响的弦。常见八分型是“低音—三弦—二弦—一弦—二弦—三弦—二弦—一弦”，每项 `.8`。三拍子可用六个八分音符或三个四分音符。

拇指通常负责低音，食中无名指负责高弦；交替低音选择根音与五音或符合转位的低音。旋律优先，伴奏不要淹没旋律重音。让弦延响只用于和声与手型允许的地方。

## 检查

1. 每小节各拍合计与拍号相等。
2. 强拍、弱拍和上下拨方向符合说明。
3. 连续换弦和换把可实际完成，入门谱不放入十六分高速跨弦。
4. 和弦名只标在和声变化处，避免每拍重复造成谱面拥挤。

编配方法和来源署名见 `arrangement.md`。
