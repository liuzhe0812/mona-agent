# 受限 ABC 输出规范

目标是让 Mona 右侧乐谱预览器稳定显示，并让用户拿到可编辑的文本文件。生成前读取本文件；不确定语法时退回最小子集，不自行扩展语法。

## 文件结构

文件使用 UTF-8，扩展名为 `.abc`。推荐顺序如下：

```abc
X:1
T:作品标题
C:Mona Musician
M:4/4
L:1/8
Q:1/4=96
%%staves {RH LH}
V:RH clef=treble name="右手"
V:LH clef=bass name="左手"
K:Cm
V:RH
"Cm" C2 D2 | Eb2 G2 | F2 Eb2 | D4 |]
V:LH
C,2 G,,2 | C,2 G,,2 | Ab,,2 Eb,2 | G,,4 |]
```

允许的头部字段是 `X:`、`T:`、可选的 `C:`、`M:`、`L:`、`Q:`、`K:` 和 `V:`。`K:` 必须是头部最后一个字段，之后立即开始正文。ABC 用空行表示一首乐曲结束，因此从 `X:` 到最终 `|]` 之间禁止出现空行；段落只用 `%` 注释分隔。

钢琴双手使用 `V:RH` 与 `V:LH`；单旋律只使用一个声部。`%%staves {RH LH}` 可用于将两个声部分组为大谱表。双声部正文必须按相同长度的片段交替书写，例如先写右手 1–4 小节，再写左手 1–4 小节，然后写右手 5–8 小节、左手 5–8 小节。禁止先写完整右手再写完整左手。

## 允许的音符与标记

- 音名：`A`–`G`、`a`–`g`；大写为低/中音区，小写为高音区。
- 临时记号：`^`、`^^`、`_`、`__`、`=`，置于音名前。
- 八度：音符后用 `,` 降低、`'` 升高，默认最多两级；超出时先调整调性或标记难度。
- 时值：整数倍、`/2`、`/4` 和 `3/2` 等简单比例；优先让 `L:` 成为统一的最小单位。
- 休止：`z` 加同样的时值写法。
- 小节线：`|` 与最终小节线 `|]`。每个声部都必须以 `|]` 结束。
- 和弦符号：双引号包围的简短文本，例如 `"Am"`、`"G7"`、`"F#dim"`；只作为显示标注，不能替代实际和声音符。
- 连线与延音：简单的 `( ... )` 连线和 `-` 延音；不嵌套复杂装饰。
- 动态：`!pp!`、`!p!`、`!mp!`、`!mf!`、`!f!`、`!ff!`，只在确有段落意义时使用。

## 必须检查

1. `X:` 只出现一次，`T:`、`M:`、`L:`、`K:` 存在且值明确；`Q:` 若存在必须写出可读的拍值和 BPM。
2. 每个声部的每小节时值等于 `M:` 的拍数；若使用弱起，必须明确标注并确保后续小节对齐。首版默认不使用弱起。
3. 声部之间小节数一致，钢琴右手和左手的结构边界一致；休止填足空拍。
4. 调号、临时记号、音域和谱号与创作说明一致；不要用大量临时记号代替清楚的调性。
5. 行长度适中，每行放 1–4 小节，方便右侧预览器重排与定位；不要把整首曲子写成一行。
6. 从 `X:` 到最终 `|]` 之间没有空行；双声部按等长片段交替书写。
7. 文件交付前再次读取并检查实际写入内容；不能只报告“已生成”。

## 明确不支持

首版不输出歌词、六线谱/tablature（需要吉他六线谱时改用 `guitar-tab` Skill，它有独立的 TAB 语法与渲染标记）、鼓谱专用映射、微分音、复杂连音线、倚音/装饰音、三连音和其它 tuplets、broken rhythm、复杂 repeat/宏、内联字段、`%%MIDI` 音色指令、外部 include、HTML/脚本或自定义渲染指令。需要这些能力时，交付受限 ABC 骨架，并在说明中写明待转换项。

## 失败处理

如果无法保证拍子、声部对齐或语法合法，先输出结构化诊断和修正方案，不要交付看似完整但无法预览的文件。修复后保留同一作品编号并更新标题或版本说明，避免把失败草稿冒充成最终乐谱。
