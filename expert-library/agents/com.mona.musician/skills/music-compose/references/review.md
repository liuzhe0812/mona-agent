# 音乐草稿评审与修改

评审对象是创作简报、ABC 文本和可见的结构信息。除非系统明确提供音频输入和试听结果，否则不评价已经听到的音色、混音、演唱或声场。

## 评审顺序

1. 先做硬约束检查：ABC 可解析性、拍号时值、小节边界、调号、声部对齐、音域和明显不可演奏的跨度。
2. 再做音乐结构检查：动机是否可识别，段落是否有功能差异，张力是否积累并释放，结尾是否完成或有意保留悬念。
3. 最后做风格与审美检查：节奏、和声、旋律句法、织体、音区和配器是否共同支持目标风格与情绪。
4. 给出最少但有效的修改：优先修复会破坏可读性或主次关系的问题，再处理个性、色彩和装饰。

## 评审维度

每项使用“充分 / 部分成立 / 待确认”，并引用可见证据：

- **核心动机**：是否有可复述的节奏或音程轮廓，变化是否有来源。
- **旋律句法**：呼吸、落点、重复与对比是否清楚；强拍与和声是否相容。
- **和声逻辑**：调性中心、功能路径、低音线和色彩和弦是否服务段落。
- **节奏与推进**：脉冲、重音、留白和密度变化是否支持能量曲线。
- **织体与层次**：主次声部、音区、活动密度和进入/退出是否清楚。
- **曲式与叙事**：段落是否各司其职，高潮是否有铺垫，回归是否有意义。
- **演奏性**：音域、跨度、呼吸、换把、重复音和技巧要求是否符合目标难度。
- **风格一致性**：所选风格特征是否具体且不过度堆叠，参考对象是否仅作为高层约束。

## 修改格式

输出三列信息：

| 证据 | 判断 | 修改 |
| --- | --- | --- |
| 第 5–8 小节旋律重复节奏细胞，句尾落在属音 | 动机成立，但段落仍缺少能量变化 | 保留动机，将第 7–8 小节移高并增加属功能，副歌前减少左手活动 |

修改后重新执行硬约束检查。不要用“更好听”“更专业”作为唯一理由；把它拆成可见的节奏、音程、和声、密度或曲式变化。

## 音频边界

可以说“从乐谱结构看，副歌的音区和密度形成更强对比”；不能说“我听到副歌更有冲击力”。可以把用户的试听反馈作为证据继续修改，但要注明该反馈来自用户，不是 Agent 自己试听所得。
