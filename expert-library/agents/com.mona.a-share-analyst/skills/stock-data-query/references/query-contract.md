# 股票数据查询口径

在多标的、历史区间或财务指标查询中使用本参考；简单当前报价不需要加载。

## 先区分四类时间

1. **即时行情时间**：当前报价的采集时间，只能说明该时刻的价格、涨跌幅和成交量。
2. **市场数据时间**：K 线、指标或市场快照的有效时间，不能用回答生成时间代替。
3. **财务报告期**：财务指标所属季度、半年度或年度，不能用公告日期代替。
4. **公开时间**：公告、新闻或材料对市场可见的时间；分析历史问题时不得引入之后公开的信息。

## 分区与典型请求

| 用户需求 | 优先数据分区 | 注意事项 |
| --- | --- | --- |
| 当前价、涨跌幅、成交量 | `stock_quote` | 只覆盖一个标的的即时快照 |
| 一段时间的价格和成交量 | `kline` | 说明实际返回的起止范围和周期 |
| 营收、利润、现金流、负债、估值 | `fundamentals` | 每个数字标注报告期和工具提供的口径 |
| 公告、新闻和事件 | `news` | 事件时间、公开时间和来源分开 |
| 用户确认纳入的财报或材料 | `materials` | 只使用本次明确绑定的材料 |

上下文可能同时返回系统派生字段。只有用户明确询问且字段已经由工具提供时才展示；不要在模型中重算或反推。

## 多标的同口径比较

- 先固定证券类型、指标集合、单位、财务报告期或市场时间窗。
- 多公司查询“最近一期”时，优先采用所有目标公司均已公开的最新共同报告期，并明确写出该报告期。若无法从返回数据识别共同报告期，就分别标注“各自最新期”且不做横向结论，或请用户指定报告期；不能把不同报告期伪装成同口径比较。
- 每个标的只使用自身 context 的来源；不得把甲公司的 `source_id` 用于乙公司。
- 某标的缺少字段时保留“暂无可比数据”，不要补零、均值或行业常识。
- 股票与 ETF 的公司财务指标通常不可直接比较；ETF 应优先使用其实际返回的规模、流动性、跟踪或费率字段。
- 不同报告期、TTM/静态口径、币种或复权口径不能放在同一排名中，除非工具已经提供统一口径结果。

## 输出最小字段

每个结果至少保留：

- 标的名称和代码；
- 指标名称、原始数值和单位；
- `as_of` 或报告期；
- `source_id`；
- 缺失或可比性说明。

数据查询回答应到此为止。只有用户要求“如何理解、为什么、怎么看”时才进入分析。
