# 市场简报模板

根据用户范围选择一种结构，不需要输出空栏目。模板中的说明文字不是事实，不能直接复制为结论。

## 市场或板块简报

```text
结论摘要
- 用 1—3 条说明本时间窗最重要的已确认变化及结论强度。

时间与覆盖范围
- 覆盖对象：
- 数据窗口：
- 截止时间：

市场/板块变化（事实）
- 指标或事件｜原始数值/状态｜as_of｜source_id

重要催化与风险
- 已核验事件：事实、公开时间、source_id
- 待核验线索：为什么尚不能确认

可能影响（条件化分析）
- 影响对象、时间窗口、依据、主要反证

待观察与数据缺口
- 下一步观察项、失效条件、missing_fields 的业务影响
```

## 单股或自选股简报

```text
结论摘要
- 只概括本时间窗内已确认的主要变化，不给买卖建议。

标的概览
| 标的 | 主要变化 | 数据时间 | 来源 |

逐标的动态
- 发生了什么：
- 可能影响什么：
- 最重要反证/风险：
- 还需要确认什么：

共性观察
- 只写同口径、同时间窗下可比较的变化。
```

## 质量检查

- 每个数值、事件和事实是否有 `source_id` 与 `as_of`；
- 是否把新闻、价格变化和经营事实分开；
- 是否给出至少一项风险或反证；
- 是否保留数据缺口而没有补零或猜测；
- 是否删除了没有内容的模板栏目。
