# 股票综合分析

明确用户关注的对象和问题，使用 `stock_vibe_task` 开始新研究，或继续当前聊天已绑定的研究。用 `read_research` 读取真实状态与结果，尚未完成时先说明进度。

按返回证据区分事实、分析和未知项。根据问题选择相关维度，说明来源、时间、主要风险和反证。证据不足时明确指出，不用新闻标题代替公司经营事实，也不编造走势和收益。

按需要使用 `skill_reference_read` 读取对应参考：

- 技术面：`technical-analysis.md`。
- 基本面和估值：`fundamental-valuation.md`。
- 资讯和事件：`news-and-events.md`。
- 综合判断和风险：`synthesis-and-risk.md`。
