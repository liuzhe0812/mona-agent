# 资讯、政策与事件分析指南

用户询问新闻真假、公告影响、政策、行业事件或主题传导时使用。新闻只提供催化和风险线索，不能替代经营与行业事实。

## 核验顺序

1. 检查公开时间是否早于分析截止时间，并与行情 `as_of` 分开记录。
2. 来源优先级通常为监管/交易所/公司披露，其次是可追溯的主流财经媒体；自媒体、论坛和搜索摘要只能作为待核验线索。
3. 同一事件的多来源应合并陈述并保留各自 `source_id`；来源冲突时分别列出，不替用户选择一个未经证实的版本。
4. 分开写事件事实、来源原文可直接支持的影响，以及仍需验证的推断。

## 事件传导链

只有证据足够时才逐层分析：

1. 事件事实和公开时间；
2. 直接影响；
3. 受影响的行业或产业链环节；
4. 目标公司的实际业务敞口；
5. 收入、利润或现金流的验证路径；
6. 可能的影响窗口、反证和失效条件。

任一环节缺少证据时停在上一层，标记为待核验。事件标题或主题关联不等于公司受益，公司业务涉及也不等于收入或利润已经受益。

## 市场背景

- 行业、政策和周期结论只能使用 context 实际返回的供需、产品价格、产业链或周期证据。
- 事件对短期情绪、中期经营和长期逻辑的影响窗口分别说明，不跨周期平移。
- 单一新闻不能决定正负立场，也不能用“没有新闻”证明没有风险。

输出至少包含：已核验事实、来源等级、条件化影响、最重要反证、验证窗口和数据缺口。
