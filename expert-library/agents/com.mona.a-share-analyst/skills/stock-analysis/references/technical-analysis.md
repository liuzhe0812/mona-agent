# 技术分析指南

用户询问走势、量价、指标、关键位或短期风险时使用。本指南服务普通会话，不提交内部 Artifact。

## 证据对象不可混用

- `quote`：当前或冻结报价，只说明对应 `as_of` 时点。
- `kline`：历史价格和成交量序列，必须说明实际周期与时间范围。
- `indicators`：工具已经计算的基础技术指标；不能由模型重新计算。
- 市场环境、资金状态和可交易性：只在 context 实际返回相应证据时使用。
- 系统派生交易计划：与基础 K 线、指标分开；派生字段缺失不代表基础技术数据缺失。

## 分析顺序

1. **趋势**：使用工具提供的均线、阶段高低点或趋势状态，判断上升、下降或震荡；没有对应字段就不自行构造。
2. **量价**：检查价格变化与成交量是否相互确认，区分放量、缩量和单日异常；不要把单日表现外推为长期趋势。
3. **指标**：组合解释工具已提供的 MACD、RSI、动量、波动等指标；单一指标不能独立证明反转。
4. **关键位**：只引用工具提供或 K 线中明确标记的可复核高低点、支撑和压力，并说明周期/日期；不得自行计算新价位。
5. **市场与执行风险**：若有相应证据，说明市场背景、流动性、停复牌、涨跌停或其他可交易性约束。

## 输出重点

- 当前结构及数据时间；
- 支持当前判断的量价和指标事实；
- 与判断冲突的信号；
- 后续观察项和失效条件；
- 缺失或过期的数据。

只谈证据支持的技术状态，不评价估值和公司经营，不输出买卖点、目标价、止盈止损或仓位。
