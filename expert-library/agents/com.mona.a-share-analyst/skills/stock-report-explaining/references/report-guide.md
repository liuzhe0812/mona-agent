# 股票研究报告解释指南

用于解释当前 Decision Report V6、三周期差异、研究/交易门禁、分歧矩阵和历史报告。只解释报告实际存在的字段。

## 先建立时间边界

- **研究截止时间**：本轮研究允许纳入信息的最晚公开时间。
- **市场数据时间**：报告中行情和市场快照的有效时间。
- **报告生成时间**：系统完成报告的时间，不代表所有底层数据都更新到该时刻。

解释追问时明确用户看到的是哪一个时间。当前补充查询晚于报告时，不得回写或悄悄改变原报告结论。

## Decision Report V6

V6 的核心是把研究是否足够和交易计划是否可生成分开：

- `research_ready` 表示相应周期是否有足够证据形成定性研究判断。
- `trade_ready` 表示确定性系统是否有足够条件生成交易计划或执行相关字段。
- 研究可用但交易计划不可用时，仍可解释研究结论；不能说成“所有数据都缺失”。
- 交易计划、仓位、执行和量化字段由确定性系统生成，不能归因于某个分析角色或由解释者重新计算。

## 三周期

- 短期：市场环境、量价、事件窗口和可交易性。
- 中期：行业、政策、周期、盈利变化、估值和事件兑现。
- 长期：公司质量、现金流、资本配置、行业生命周期和估值约束。

每个周期分别解释方向、核心依据、主要风险、可执行动作或受限状态，以及改变结论的条件。某一周期不可用不等于整份报告失败。

## 分歧与角色来源

`disagreement_matrix` 用于说明：

- 多空或不同分析维度争议什么；
- 双方各自依据；
- 主审采信了什么；
- 哪些反方风险仍被保留；
- 什么事实会改变当前裁决。

解释技术、基本面、资讯、多头、空头和主审观点时保留角色来源。上游观点是带来源的研究判断，不自动等于原始事实。

## 数据质量和不可用状态

- 将内部状态翻译为用户语言，同时保留具体缺失字段及其业务影响。
- 基础行情、财务、研究结论、派生计划和执行资格分层解释。
- 不从 provider、URL、日志或错误码推测数据为什么缺失。
- 报告明确部分覆盖、过期或证据不足时，相应降低结论强度。

## 历史报告

旧版报告只读解释：

- 先识别报告实际版本和字段，不用 V6 字段强行补齐旧报告。
- 旧报告中已有维度、周期、多空裁决和风险可以按原结构解释。
- 旧报告缺少 V6 门禁或分歧字段时，明确说明“该版本未包含”，不要推断其值。

## 推荐解释顺序

1. 一句话结论及适用周期；
2. 研究截止和市场数据时间；
3. 三周期结论；
4. 最强支持证据与主要反证；
5. 研究与交易状态差异；
6. 数据缺口和仍待确认问题；
7. 当前补充信息与原报告的分界。
