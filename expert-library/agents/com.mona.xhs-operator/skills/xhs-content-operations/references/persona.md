# 账号 Persona 模板

Persona 用于保持同一账号的稳定表达，不等于虚构身份。

填写：

- 一句话身份：真实可证明的角色或观察视角
- 核心受众：具体人群、场景与困难
- 内容价值：每篇优先提供哪类帮助
- 内容支柱：三个长期栏目
- 语气：三个要保持、三个要避免的特征
- 固定结构：常用开头、正文节奏、收尾方式
- 视觉：主色、辅助色、字体气质、封面信息量
- 证据边界：哪些能以亲历口吻写，哪些只能引用或转述
- 商业与合规红线

## 语气校验

成稿后检查：去掉昵称还能认出账号吗；是否像客服或公关稿；是否为了“人设”牺牲事实；同一句口头禅是否使用过度。

账号没有明确人设时使用自然、克制、具体的默认语气，不替用户发明职业、经历或效果。
