# 发布检查、评论话术与复盘

本参考提供文本和检查模板，不授权自动发布或自动回复。

## 发布前检查

- 封面、标题、正文说的是同一件事
- 标题优先不超过 20 字，封面主文案优先不超过 10 字
- 事实、价格、时间、地址和规则已标来源与核验时间
- 图片、音乐、字体和案例有使用权限
- 不含绝对化效果、虚构见证、诱导或敏感承诺
- 标签与内容相关
- 用户已看过最终版本

## 评论回复矩阵

- 追问：先给直接答案，再补一个条件；需要长解释时引导查看正文，不承诺未来一定更新。
- 赞同：接住具体观点，再问一个可继续讨论的问题。
- 反对：复述分歧点，给证据或适用边界，不攻击动机。
- 纠错：核验后明确更正；尚未核验时说明正在确认，不硬辩。
- 售后或敏感信息：转到合适渠道，不在公开区索取隐私。
- 辱骂、钓鱼、外链诱导：不升级冲突，必要时不回复并提示用户人工处理。

## 复盘

同口径比较曝光、阅读/播放、点赞、收藏、评论、主页访问和涨粉。先写数据变化，再提出最多两个解释，最后设计下一篇只改变一个主要变量的验证动作。

复制 `templates/performance-review.md` 交付复盘。发布或回复动作必须另行获得用户明确授权。
