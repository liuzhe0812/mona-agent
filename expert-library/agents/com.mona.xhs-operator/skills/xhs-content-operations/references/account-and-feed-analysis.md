# 账号与推荐流分析

## 账号采样

优先使用用户后台导出数据；其次使用主页链接或清晰截图。默认观察最近 9-15 篇，账号正在转型时按转型前后分组。

每篇只记录可见字段：发布日期、内容类型、标题、封面主文案、主题、点赞、收藏、评论、涨粉或转化。不可见字段写“缺失”，不要用 0 代替。

先计算中位数，再标记高于中位数 2 倍的高信号内容。只有曝光、主页访问、涨粉等后台字段齐全时才计算转化率：

- 点击率 = 阅读或播放 ÷ 曝光
- 互动率 =（点赞 + 收藏 + 评论）÷ 阅读或播放
- 关注转化率 = 新增关注 ÷ 主页访问或阅读

不同时间窗口、投流状态或内容类型不可直接横比。

## 五维诊断

每项 1-5 分，必须附证据编号：

1. 定位清晰：主页信息与近帖是否指向同一人群和价值。
2. 内容结构：标题、封面、开头和正文是否稳定兑现同一承诺。
3. 互动转化：评论是否产生追问，收藏是否对应可复用价值。
4. 账号辨识：语气、视觉、栏目和选题角度是否可识别。
5. 增长持续：高表现是否来自可重复结构，而非单个热点。

输出顺序固定为：数据现象 → 可能解释 → 验证动作。观察数据不能证明推荐机制或因果关系。

## 推荐流采样

默认采样 10-20 条同主题内容，记录：标题、封面字、内容类型、目标人群、停留理由、互动机制和可见互动数。保留重复主题，它们可能说明当前内容偏好；但不能据此声称平台整体趋势。

最后只沉淀三类结果：值得复用的结构、与本账号不匹配的结构、下一轮可验证选题。

复制 `templates/account-audit.md`，填完所有占位符后交付。样本不足时，在结论第一行明确样本数和不可验证字段。
