# 小红书内容运营

先判断任务类型，再只执行对应流程。涉及实时趋势、账号页面或规则时先检索；普通创作不为“找热点”强行联网。

## 本地资源

本 skill 自带可读取的操作参考、可复制的空白模板和 3:4 原创封面底图。不要只读本文件后凭印象输出。

- 账号或推荐流分析：用 `skill_reference_read` 读取 `account-and-feed-analysis.md`。
- 标题、正文、选题：读取 `title-copy.md`。
- 视频脚本：读取 `video-script.md`。
- 封面设计：读取 `cover-design.md`。
- 对标拆解与结构复刻：读取 `remix.md`。
- 人设、发布检查、评论话术或复盘：分别读取 `persona.md`、`publish-comment-review.md`。
- 需要完整示例时读取 `example-package.md`。

用户要可编辑交付物时，用 `skill_asset_copy` 从 `assets/templates/` 复制对应模板到工作区；用户要封面底图时，从 `assets/covers/` 复制合适的 PNG。不得把模板占位符原样交付。

## 账号分析

优先读取用户提供的主页链接、截图和后台数据。链接需要登录时可使用 Mona 浏览器读取用户已登录可见页面，不进行点赞、关注、评论或发布。

执行前读取 `account-and-feed-analysis.md`，需要文件交付时复制 `templates/account-audit.md`。

1. 记录主页定位、简介、内容支柱，以及最近 9-15 篇可见笔记的标题、封面文案、内容类型、发布时间和互动数据。
2. 页面字段不可见就留空；样本不足 9 篇时标注样本量，不外推总体结论。
3. 从定位清晰度、内容结构、互动转化、账号辨识度、增长可持续性五项各评 1-5 分。每一分都要指向已记录的证据。
4. 输出账号快照、五维评分、最大优势、最大短板和三条按优先级排序的动作。

仅凭点赞等观察数据不能断言平台推荐原因或因果关系。用“数据现象”“可能解释”“验证动作”分开表达。

## 选题策划

1. 先问账号定位：目标人群、内容领域、变现路径。不清晰的定位先补齐再谈选题。
2. 选题四来源：热点榜单（平台热点 + 领域热点）、对标账号爆款（拆解结构而非照抄内容）、用户评论区高频问题、自家产品/服务的独特卖点。
3. 每个选题用一句话写出「目标用户 + 具体痛点 + 可交付价值」，写不出来就放弃该选题。
4. 用户要求长期运营时才建立选题库；单次创作直接交付，不额外建表。

## 视频脚本

缺少约束时默认按 30-60 秒、9:16 竖屏、单人可拍执行，并明确默认值。先确定一个核心信息，不把图文正文直接切成镜头。

执行前读取 `video-script.md`；需要文件交付时复制 `templates/video-script.md`。

用户明确要求视频成品、且 `generate_video` 可用时，生成一个 3-18 秒片段；默认沿用用户指定比例，没有指定时使用 9:16。长视频先交付脚本和素材清单，不把单个生成片段说成完整剪辑成片。

交付一张分镜表，至少包含：

- 时间码与累计时长
- 景别/机位和画面动作
- 口播或字幕原文
- 转场、音效或素材要求
- 该镜头承担的目的

前三秒必须出现人群、痛点或结果之一；中段每 5-10 秒给一次信息变化；结尾只放一个互动动作。另给封面帧、标题候选和拍摄素材清单。事实型口播先核验来源，不能把未验证效果写成亲身体验。

## 封面设计

默认画布为 3:4。先交付主文案（优先不超过 10 字）、副文案、视觉主体、层级、配色和安全区，再决定是否生图。

执行前读取 `cover-design.md`；优先复用 `covers/` 中的原创底图，不能满足主题时再调用 `generate_image`。

- 用户只要方案：给 2 个差异明确的方向和可直接使用的生图提示词。
- 用户要成品且 `generate_image` 可用：生成 1 张 3:4 封面。中文短字直接生图；如出现错字，改为无字底图并交付准确的叠字排版稿，不反复盲抽。
- `generate_image` 不可用：明确只完成设计稿和提示词，不声称已经生成图片。
- 若返回 provider、模型或 HTTP 配置错误，保留原始错误并停止重试；不要仅改提示词后重复调用。

封面信息只表达一个点击理由，不堆标签，不照搬对标笔记的具体人物、图标和版式位置。

## 笔记撰写

执行前读取 `title-copy.md`；完整内容包使用 `templates/note-package.md`。

- 标题：默认给 3 个，分别偏搜索、共鸣、反差；优先控制在 20 字以内并标注字数，不含夸张误导词汇。
- 正文结构：开头一句话钩子（共鸣或痛点）→ 分点展开（每点一段，口语化）→ 结尾互动引导（提问或征集经验）。
- 口吻对齐真实用户分享，避免广告腔和官方话术；专业概念用生活化比喻解释。
- 关键词自然埋入标题和前三行，覆盖搜索场景；标签 5-8 个，组合领域词、精准词和长尾词。
- 多图内容每张只承担一个信息点，并给出首图到尾图的阅读顺序。

标题、正文与封面必须承诺同一件事。参考爆款时只拆“人群—问题—信息层级—节奏—互动机制”，重新写具体表达和视觉元素。

## 发布与复盘

1. 发布时间参考目标人群活跃时段（通勤、午休、晚间），发布后 1 小时内回复全部评论。
2. 复盘指标：曝光→点击（封面标题）、点击→互动（内容质量）、互动→涨粉（人设价值），按漏斗定位问题环节。
3. 小数据笔记不做大改重发；连续 3 篇同方向数据不佳则回到选题环节重新校准定位。
4. 复盘结论写入账号记忆时，只保留有数据支持且能复用的模式，并记录样本和时间窗口。

## 边界

- 不编造使用效果、不伪造用户见证、不使用绝对化用语。
- 涉及医疗、金融、教育等敏感领域时提示合规风险，给出保守表达建议。
- 数据引用注明来源和时间，平台规则以官方最新说明为准。
- 浏览与分析不等于授权发布；本 skill 不执行发布、评论、点赞或关注。
