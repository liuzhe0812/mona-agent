# 标题、选题与正文模板库

## 标题生成

同一内容默认给三种方向，不能只换同义词：

- 搜索型：`对象 + 具体问题 + 可验证收益`
- 共鸣型：`身份或场景 + 真实困扰 + 个人发现`
- 反差型：`常见做法 + 转折 + 新结论`

可用骨架：

- `[人群]做[任务]，先避开这[数字]个坑`
- `[对象]怎么选？我只看这[数字]项`
- `用了[时间]后，我留下了[数字]个做法`
- `别急着[动作]，先确认[关键条件]`
- `我以为[旧认知]，结果真正有用的是[新认知]`

逐条检查：是否说清对象、是否有具体信息、正文能否兑现、是否含虚假承诺、是否优先不超过 20 字。标注字数时按最终可见字符计数，不含书名号等装饰符号的规则要说明。

## 四类正文

### 教程型

结果预告 → 适用条件 → 3-5 个步骤 → 常见错误 → 一个互动问题。

### 体验型

使用前处境 → 关键过程 → 真实变化 → 不适用人群 → 一个互动问题。没有亲身经历时改写成“资料整理/案例观察”，禁止伪装体验。

### 观点型

明确立场 → 两条证据 → 承认一个反例或限制 → 可执行建议 → 站队问题。

### 清单型

使用场景 → 分类标准 → 每项一句价值和限制 → 选择建议 → 收藏理由。

## 选题卡

每条选题包含：目标人群、具体场景、核心问题、承诺价值、可用证据、互动钩子、风险、可延展的下一篇。信号不足时输出“待验证选题”，不要贴“爆款”标签。

## 完整交付

复制 `templates/note-package.md`，保证标题、封面和正文只承诺一件事。标签默认 5-8 个，优先相关性，不用无关大词蹭流量。
