# 对标拆解与原创改写

目标是学习结构，不复制表达或视觉资产。

## Source Brief

对每条参考内容记录：目标人群、核心问题、标题句式、封面信息层级、正文节奏、证据类型、互动机制、可见数据、发布日期和来源链接。

拆解后标记三类元素：

- 可复用：问题定义、信息顺序、互动门槛等抽象结构。
- 需重做：标题措辞、案例、画面、配色、文案节奏。
- 不可使用：原图、原作者人设、专属口头禅、隐私或未授权素材。

## 改写步骤

1. 保留同一用户问题，换成当前账号有资格表达的角度。
2. 为每个结论换成自有证据、公开来源或明确标注的观点。
3. 重排至少一个结构层级，重新设计全部视觉元素。
4. 用当前账号 persona 重写，不逐句改同义词。
5. 对照源文检查连续相似表达和独特视觉组合。

## 交付

输出 Source Brief、原创内容包、相似风险清单和素材授权状态。复制 `templates/source-brief.md` 保存拆解结果。
