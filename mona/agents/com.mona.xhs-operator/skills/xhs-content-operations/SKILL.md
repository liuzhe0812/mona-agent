# 小红书内容运营

围绕「选题 → 笔记 → 打磨 → 复盘」四步循环组织工作，每一步都先对齐目标，再产出内容。

## 选题策划

1. 先问账号定位：目标人群、内容领域、变现路径。不清晰的定位先补齐再谈选题。
2. 选题四来源：热点榜单（平台热点 + 领域热点）、对标账号爆款（拆解结构而非照抄内容）、用户评论区高频问题、自家产品/服务的独特卖点。
3. 每个选题用一句话写出「目标用户 + 具体痛点 + 可交付价值」，写不出来就放弃该选题。
4. 建立选题库并标注状态（待写 / 已发 / 已复盘），避免重复选题。

## 笔记撰写

- 标题：控制在 20 字以内，优先使用数字、悬念、身份共鸣三种结构；不含夸张误导词汇。
- 正文结构：开头一句话钩子（共鸣或痛点）→ 分点展开（每点一段，口语化）→ 结尾互动引导（提问或征集经验）。
- 口吻对齐真实用户分享，避免广告腔和官方话术；专业概念用生活化比喻解释。
- 关键词自然埋入标题和前三行，覆盖搜索场景；标签 3-6 个，含 1 个领域大词 + 2 个精准长尾词。
- 图片/视频脚本：封面决定点击率，首图文字不超过 10 个字；多图内容每张一个信息点。

## 发布与复盘

1. 发布时间参考目标人群活跃时段（通勤、午休、晚间），发布后 1 小时内回复全部评论。
2. 复盘指标：曝光→点击（封面标题）、点击→互动（内容质量）、互动→涨粉（人设价值），按漏斗定位问题环节。
3. 小数据笔记不做大改重发；连续 3 篇同方向数据不佳则回到选题环节重新校准定位。
4. 复盘结论写回选题库，形成「什么选题在什么表达下有效」的账号知识。

## 边界

- 不编造使用效果、不伪造用户见证、不使用绝对化用语。
- 涉及医疗、金融、教育等敏感领域时提示合规风险，给出保守表达建议。
- 数据引用注明来源和时间，平台规则以官方最新说明为准。
