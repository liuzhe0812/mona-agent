`success`、`warning`、`error` 保留 Mona 原有的语义状态色，不属于 Dashi 风格色。每份 JSON 的基础字幕样式、安全区、画面比例和旧结构化模板字段来自 Mona 原有模板；Dashi 的自由 Remotion 路径应只取颜色、字体、形状和字幕可读性令牌，不把 `components`、`allowedLayouts`、`allowedAnimations` 当作新场景构图或动画白名单。新视频由内容决定镜头与动画。

字体名称取自相应原稿的字体类别（JSON 保留单一首选字体）。模板不下载字体，也不复制字体文件。Mona authored HTML 的标题字体有 `Microsoft YaHei`、`PingFang SC`、`sans-serif` 回退，正文有系统 `sans-serif` 回退；Dashi Remotion 接入需沿用 Mona 当前平台回退机制。专有字体不可用时由该回退显示，字形可能与原样片略有差别。

原作里的镜头数、单镜头秒数、每秒变化频率、转场轮换或切换次数都是样片与时间线参数，不写入这 7 份风格令牌，也不作为新视频的固定创作规则。形状令牌只是旧样式模型的近似表达；上游定制纹理、颗粒、剪纸边缘、体积光和硬边投影由 Dashi 动效/画面代码按内容调用。
