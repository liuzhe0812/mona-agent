# Video Shared Standards — 共享标准

## Color Palette

默认配色方案(可在 storyboard 中覆盖):

| 用途 | 色值 |
|------|------|
| 背景 | #0f0f0f(深色)/ #ffffff(浅色) |
| 主文字 | #ffffff(深色)/ #1a1a1a(浅色) |
| 次文字 | #a0a0a0(深色)/ #666666(浅色) |
| 强调色 | #3b82f6 |
| 辅助色 | #10b981 / #f59e0b / #ef4444 |

## Typography

- 标题: 48-72px, font-weight: 700
- 副标题: 32-40px, font-weight: 600
- 正文: 24-28px, font-weight: 400
- 旁白: 20-24px, font-weight: 400

## Timing Standards

- 场景最小时长: 2s
- 场景最大时长: 15s
- 文字入场动画: 0.3-0.5s
- 场景过渡: 0.5-1s
- 帧率: 30fps(默认) / 60fps(高质量)

## Resolution

| 类型 | 分辨率 | 用途 |
|------|--------|------|
| landscape | 1920×1080 | 演示 / YouTube |
| portrait | 1080×1920 | 社交媒体(抖音/快手) |
| square | 1080×1080 | Instagram / 朋友圈 |
