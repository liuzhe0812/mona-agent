# 镜头语言：让镜头服务观众的注意力

镜头运动是一种解释和叙事手段。镜头可以静止；运动应帮助观众找到重点、理解空间关系、跟随动作或感受到情绪变化。上游表格中的时长和幅度来自特定片段，只是可参考的起点。

## 先判断是否要动

- 观众已经看清当前主体，画面本身正在变化，或台词需要片刻消化时，停住镜头通常更清楚。
- 要把视线从主体带到证据、从局部带回整体时，可考虑缓推、横移或拉远。
- 揭晓、反转、笑点和重点数字可以用较快的运动强化，但应让内容本身值得这一下。
- 进入下一个空间时，可硬切、匹配形状、跟随物体，或用风格中的材料过程完成转场。
- 连续重复同一种推进方式，即使速度很快，也容易让镜头显得机械。设计动作前看前后镜头，按叙事节奏安排呼吸和方向变化。

## 常用动作参考

| 动作 | 适合的内容 | 设计提示 |
|---|---|---|
| 停留 | 读文字、观察图形、笑点停顿、画面本身有动作 | 停留多久由口播和信息理解决定 |
| 缓推 | 引导观众看细节、建立情绪 | 让被关注的内容变得足够清楚；上游样片常用约 0.6–1.5 秒作过渡起点 |
| 拉远 | 展示全貌、交代空间、总结关系 | 可先揭开整体，再留时间理解各元素如何关联 |
| 横移 | 沿桌面、图表或大画布依次观察内容 | 保持主体和阅读顺序稳定，避免越过观众尚未看完的内容 |
| 快推或快移 | 强调一个重要瞬间、突然把视线带向新信息 | 留给值得强调的事件；上游某些样片约 0.25–0.35 秒，但没有固定次数 |
| 跟随 | 追踪行进中的角色、物体或变化过程 | 让镜头速度服务主体动作，转弯处注意画面余量 |
| 匹配切换 | 前后场景共享形状、位置、方向或动作 | 让观众看出两段的联系，不必总加装饰性转场 |

## 按内容类型调整

- **解释图表和屏幕内容**：先保证数据、标注和单位可读；镜头只在需要看另一处数据时移动。
- **推理和关系图**：可先停在当前关系上，再移动到下一步；视野变化本身可以承担转场。
- **故事和情绪**：反应、沉默和停顿都可以成为镜头事件，不需要用持续漂移填满时间。
- **艺术风格动画**：运动可以来自笔触、纸片、光线、液体、纹理或角色表演，镜头保持安静也能让画面有生命。
- **真实素材**：先保留素材内容和比例，再设计裁切和焦点；运镜不要遮住关键文字或操作细节。

## 回看时检查

用实际口播、正常播放速度看整片，留意视线是否被带到正确位置，是否有足够时间读懂重点，运动是否重复，以及镜头变化是否打断声画关系。帧差和运动量只能提醒你哪里可能有问题，不能单独决定镜头好坏。

历史案例：每镜匀速推近会像翻页；把它改成每镜快速推近仍会显得重复。两者的共同问题是镜头没有随内容变化。具体案例记录在 [正面经验](../methods/07-正面经验.md)。
