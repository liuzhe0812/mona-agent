# 09 · 讲解动画语法：让口播中的意思成为画面变化

动画形式应从内容出发。下表是九种表达方式的速查，不是固定模板库，详见 [语法索引](../narration-grammars/index.md)及每张卡片。

| 表达方式 | 适合的内容 | 关键视觉机制 |
|---|---|---|
| 扁平科普 | 系统、科学、尺度和内部结构 | 具体世界、尺度穿行和清晰的主体变化 |
| 资料拼贴 | 证据、历史和观点 | 原始材料、截图、照片、文件之间的关系 |
| 白板推导 | 步骤和因果链 | 线条逐步画出，保留画布上的位置关系 |
| Storytime | 故事、感受和笑点 | 人物表演、反应、景别和有意停顿 |
| 动态文字 | 关键词、章节和数字 | 文字作为主体，在口播重音时出现或变形 |
| 概念可视化 | 数学、机制和抽象关系 | 对象之间连续变形，帮助观众建立映射 |
| 产品表达 | 产品能力和真实操作 | 真实界面、操作过程、关键局部和结果 |
| 数据图表 | 趋势、比例、比较 | 先让观众理解尺度，再呈现数值和重点 |
| 讲解员 | 需要人来解释、指向或互动 | 讲述者与证据、图表和空间共同组织信息 |

## 设计上的共同点

- 选表现方式时，从“观众要理解什么”出发，不按主题类别机械套模板。
- 一个抽象概念可以用物体、空间、图形、动作或真实证据表达；选择最清晰且适合风格的方式。
- 运动服务于解释：图形建立关系、对象展示因果、镜头引导视线、停顿留出阅读时间。
- 视觉构图可在全片中变化，同时通过风格语言保持连贯。固定场景、统一构图或单一媒介只适合确实需要它们的作品。
- 数字、来源、单位和口播内容保持一致；画面中的比喻要避免让观众误当成真实数据。
- 允许混合表达方式。切换时让材料、动作或叙事关系把段落连起来。
