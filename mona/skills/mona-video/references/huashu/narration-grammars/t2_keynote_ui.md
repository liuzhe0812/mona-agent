# t2_keynote_ui · 发布会式界面与渐变动效

> 适配说明：本卡描述一种可借鉴的视觉表达，不是固定模板。画幅、文字量、颜色、镜头和动画速度均按当前口播与风格决定；出现的数值来自上游样片，只作例子。卡内旧引擎函数和规格不是 Mona 接口，代码读物见文件末尾。实现请遵循 [Mona 动画运行时](../../runtime.md)。


> 表现思路：让产品界面、操作过程或实物承担主要信息，动画在讲解相应功能时突出变化。渐变、毛玻璃、光效和卡片属于可选风格元素，除非能解释产品或主题，不应自动叠加。
>

## ① 适用场景

- **用**：产品/功能发布、版本更新、「三个新功能」、价格与参数公布、开场品牌片、视频里的「这个产品是什么」段落。口播是**名词＋数字**（「Plover 2」「延迟 320 毫秒」「100 万 tokens」）时最合适：一句一屏，名词出现时字浮出，数字说到时落定。
- **用**：需要把界面截图讲清楚——截图满幅，推近到要讲的那一块；放进玻璃卡、在 3D 里转正是可选包装，慎用。
- **别用**：讲机制原理（玻璃和光斑不承载逻辑，用 t1）；讲数据走势（用 t3）；严肃事故/财报坏消息（这套语言自带「好消息」的情绪）；内容本身没有一个能放大的「主角」时（只剩空镜光斑）；科普、故事、新闻这类非发布题材，别拿这套底当通用模板。

## ② 画面构成

画面围绕当前要解释的一个产品状态、操作或结果组织。产品截图和录屏可作为主体，也可以用场景、手部动作、图形或文字呈现。

- 先确保真实界面和关键信息能看清；是否满幅、局部放大或在场景中呈现，按内容和画幅决定。
- 文字层级根据观众需要理解的内容建立，不强制使用标题、副标题、标签和数字卡片组合。
- 渐变背景、玻璃卡、光斑、漂浮和3D倾斜是可选手法。克制使用；当画面已有清楚主体时可以全部省略。
- 配色优先采用产品本身或视频整体的视觉语言，不要求固定深色底或默认蓝紫光效。
## ③ 运动轨迹

- **弹簧（主力）**：SwiftUI duration＋bounce 参数化，`MO.spring(t,{duration,bounce})`：mass=1、stiffness=(2π/d)²、damping=4π(1−bounce)/d → 阻尼比 ζ=1−bounce。**默认 bounce 0**（最通用）；0.15 利落几乎不弹（本片卡片入场 d=0.75、气泡 d=0.5）；0.3 明显弹；>0.4 对 UI 夸张。`.smooth/.snappy/.bouncy` 都是 d=0.5。
- **曲线（非弹簧）**：apple.com 导航 `.32s cubic-bezier(.4,0,.6,1)`；本片字的浮现用 CSS `ease`=`(.25,.1,.25,1)`（`MO.appleOut`）；Linear 主力 ease-out-quad `(.25,.46,.45,.94)` .16s；Stripe 建议 <500ms、`(.2,1,.2,1)`。`MO.bezier(x1,y1,x2,y2)` 通吃。
- **字的入场**（居中模糊浮现是可选做法，慎用；全片每屏都这样浮出就成了模板）：模糊 18–26px → 0、上移 16–40px → 0、透明 → 1，0.7–1.0s（`TY.blurIn`）。眉题 → 产品名 → 副标题依次错开 0.2–0.4s。
- **卡片入场**：从下方 170px、绕 Y 轴 ±0.55rad（≈31°，两侧卡朝外）、缩放 0.9 → 弹簧落位；三张错开 0.1s。3D 用 `UI.persp`（竖条切片透视，persp 1800px；Stripe 用 600、Linear 用 1000）。
- **镜头与停顿**：落定后停住，不加装饰漂浮，不用匀速慢推填停顿。镜头只在口播讲到截图上看不清的那块时动：默认缓推约 0.9 秒推到那块、0.7 秒移到下一块；揭晓结果、两个数对比时才快推 0.28 秒；数字或大字砸入 0.17 秒（1.55→0.94→1.0）；停多久按口播。推进去之后拉回整张截图或移到下一块，不一镜接一镜只往里推。示范片里的卡片漂浮 7px（`MO.float`）和相机匀速推 1→1.045 是旧做法，新片不照抄。
- **计数**：卡片落定后 0.25s 起 0.9s（同一个数只数一次——展开成全屏后沿用「100万」，不再从 0 重数）；`easeOutExpo`（CountUp.js 默认缓动）——最后一位慢慢落定；数字**等宽排布**（`TY.tabular`，Canvas 不能开 tnum，不排会抖）。
- **光扫过**：斜 −20°、宽 110–140px 的亮带 0.8–0.9s 扫过；在文字离屏上用 `source-atop`（只亮在字上），在卡片上用 `lighter`；三张卡按各自屏幕位置算进度 = 同一道光。

## ④ 转场（常用 5 种）

1. **模糊推进（blurPush）**：旧画面缩到 0.92＋模糊 24px＋淡出，新画面从 1.06 带模糊落到 1.0 清晰，0.55s，`ease`。**底下先垫一层放大 1.08 的重模糊旧画面**，缩小的画面四周才不露黑边。本片镜头 1→2。
2. **共享元素展开（expandRect）**：（新画面第一帧就**不透明**装进卡片——卡片是半透明的，任何溶接都会看到新旧两层字叠在一起）被选中的卡片（先放大到 1.06、两侧卡后退变暗到 45%）从自己的屏幕矩形展开成全屏，圆角 38→0，弹簧 d=0.55 bounce 0；新画面一开始就按卡片大小缩放装在卡里。**选中卡在展开前停止漂浮**，转场才从一个稳定矩形起跳。本片镜头 2→3。
3. **匹配剪辑**：前后两镜同一物体同一位置（产品名 → 卡片标题位置）。
4. **遮罩擦除/光扫切**：一道光扫过时在光带后面换画面。
5. **折射代替淡入淡出**（Liquid Glass）：元素出场时逐渐改变折射/模糊强度，而不是直接降透明度（本片字的模糊浮现即此思路）。

## ⑤ 节奏与文字

让产品状态、功能名和数字与口播含义对上。文字出现时应留出阅读时间；需要展示多项信息时，可选择分步呈现、对比或停留，不以缩小字号硬塞。

音乐节拍可以辅助组织动画，语速、画面复杂度和主题氛围也可以决定节奏。上游示范使用了有限的卡片页和固定配色节拍，这是一次实验，不是每支产品视频的页面模板。

## ⑧ 最容易做错的 3 件事

1. **玻璃后面没东西。** 毛玻璃只模糊它后面的内容；深色纯底上的「玻璃」就是一块灰矩形。先画有色彩、有起伏的光斑，再按卡片屏幕位置取样模糊。
2. **弹簧太弹、动作太多。** bounce 默认 0，入场最多 0.15–0.3；>0.4 立刻廉价。一次只动一组东西。
3. **大字没收紧字距、光斑颜色发脏。** 64px 以上 −0.015～−0.03em；光斑每团颜色各占一块（screen 叠加＋大模糊），别把多色线性平均成灰紫泥。
