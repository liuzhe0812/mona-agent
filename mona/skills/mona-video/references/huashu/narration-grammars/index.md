# 讲解动画语法索引

动画语法描述“内容如何变成可看的变化”。它们是创意参考，不是用户必须挑选的模板，也不规定一支视频只用一种表达。可以按口播内容混用或提出新的表达方式。

| 语法参考 | 擅长表达 | 画面如何帮助理解 |
|---|---|---|
| [Kurzgesagt 式扁平科普](y1_kurzgesagt.md) | 科学、系统、尺度与内部结构 | 将抽象概念变成一个具体世界，通过放大、缩小或空间穿行展示关系 |
| [Vox 式资料拼贴](y2_vox.md) | 事实、历史、证据和观点 | 把照片、文件、地图和标注组织成可阅读的资料现场 |
| [白板推导](y3_whiteboard.md) | 步骤、因果和概念之间的关系 | 随讲解逐步绘制线条和结构，镜头在同一画布中移动 |
| [Storytime 故事叙述](y4_storytime.md) | 个人经历、情绪、包袱和反应 | 用人物姿态、表情、景别和停顿表现叙事变化 |
| [动态文字](y5_kinetic_type.md) | 金句、关键词、章节和数字 | 让文字参与动作；需要视觉证据或场景时与其他表达交替 |
| [3Blue1Brown 式概念可视化](t1_3b1b.md) | 数学、机制、抽象关系和推导 | 让一个图形或对象连续变形为下一个，减少无意义切页 |
| [发布会式产品表达](t2_keynote_ui.md) | 产品、功能和真实界面 | 让真实产品素材和操作过程成为主角，文字仅突出重点 |
| [财经图表](t3_finance_chart.md) | 数量变化、比较、趋势和因果 | 按理解顺序呈现坐标、数据和重点，同时保证数字口径准确 |
| [讲解员式解释视频](y6_presenter_explainer.md) | 需要人物讲述、指引或互动的内容 | 由讲述者与证据物、图表或场景配合，避免人物只是装饰 |

名称来自上游创作者用于描述的参考频道或类型，不代表要复制其品牌画面。选择时先看内容需要观众理解什么，再决定使用人物、图表、实景素材、形变、空间移动、文字或组合方式。

## 共通经验

- 一项重要的视觉变化对应一个清楚的口播意图；不要求每个词都动。
- 主体变化和环境变化可以分层，避免所有元素同时运动。
- 动画有开始、发展、落点和停留，读图时间要算在设计里。
- 让转场从前后场景的共同元素或视觉材料中生长出来，必要时直接切换也很合适。
- 静止并不等于失效；每镜重复推近、漂浮或弹跳同样会变成机械翻页。
- 事实与数字应单独核对。审美、理解和节奏要通过正常速度的整片观看来判断。

上游卡片里的尺寸、速度、镜头数和文字长度记录的是局部示例，不是通用规则。动画实现方式见 [Mona 动画运行时](../../runtime.md)。
