# 视频创作参考：视觉风格与讲解动画

这组资料为 Mona 的视频 Agent 提供可组合的美术与动画经验。它不是用户要逐项选择的模板目录，也不要求每个项目只能选一种风格或一种讲解语法。Agent 应先理解题材、口播要点和希望观众看懂的内容，再从这些资料中挑合适的方法，重新构图并编排动画。

实现以 [Mona 动画运行时说明](../runtime.md) 为准。上游出现的引擎函数名、文件路径和渲染命令是历史实现记录，不是 Mona 可调用的 API 或执行步骤。

## 使用原则

- 把风格卡当成色彩、笔触、材质、光线和母题动作的参考。保留能识别风格的特征，为当前主题重新安排主体、构图和动作；不要搬用上游样片的房间、叙事、人物或角色设定。
- 把讲解语法当成“内容怎样变成画面”的思路。例如用空间尺度解释机制、用图形关系展示推导、用证据素材支撑观点、用动态文字强调关键词。语法可按段落混合，也可另创表达。
- 卡片中的时长、速度、字号、颜色和数量来自特定样片或一次修订，只有在相似语境下才可作为起点。它们不是每镜字数、镜头数、镜头动作、动画密度或配色的硬性配额。
- 固定机位、静止画面和留白都可以是有意设计。镜头和物体在口播中的含义需要变化时再动；连续重复同一种推镜、浮动或装饰效果容易形成演示文稿感。
- 线条、网格、光斑、颗粒、相框、标签、渐变和粒子都不是必选项。只有在解释关系、建立空间、突出重点或体现材料时才加入。
- 口播是时间线索，不是要求每个词都触发一个动作。让重要概念、关系变化、证据出现和结论落点拥有清楚的视觉对应，其余时候可以让观众读、看或停顿。
- 参考卡片中的作者自评和审片结论是特定作品的观察，不代表已通过 Mona 的质量认证。技术指标不能替代按正常速度观看整片并检查口播、画面和节奏是否一致。

没有规定三方案比选、模型档位、逐场景审批、固定镜头表字段或固定文字配额。产品的创作交互由 Mona 自身设计；这里提供的是视觉和叙事经验。
