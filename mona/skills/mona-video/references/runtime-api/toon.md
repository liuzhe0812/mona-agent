# TOON: toon

Methods are available from createMotionToolkit / MotionCanvas kit. These are signatures from the adapted source, not executable code. P means PAINT; R means RIG. Use shared theme and actual speech timing.

```js
TOON.flat = (c, path, base, sh, hi, v = [10, 12], w = [4, 5]) => ...
TOON.glow = (c, x, y, r, col, a = 1) => ...
TOON.vgrad = (c, y0, y1, cols) => ...
TOON.circle = (x, y, r) => ...
TOON.ellipse = (x, y, rx, ry, a = 0) => ...
TOON.env = t => ...
TOON.mouth = (t, fps = 12) => ...
TOON.look = ch => ...
TOON.bean = (c, o) => ...
TOON.poseAt = (keys, t, poses = TOON.POSES) => ...
TOON.blinkAt = (t, times, dur = 0.083) => ...
TOON.alive = (t, R) => ...
TOON.sweat = (c, x, y, r, p) => ...
TOON.mark = (c, ch, x, y, p, size = 160, color = LINE) => ...
```

Source: [upstream MIT library](https://github.com/alchaincyf/huashu-art-motion/blob/64cb27271ee0ad3375298e2890b33cbec36d4051/scripts/engine/lib/toon.js). Mona uses isolated instances; omit external engine globals, author presets and external resource loaders. Font binaries/stroke-order data are not bundled.
