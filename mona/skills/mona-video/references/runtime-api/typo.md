# TY: typo

Methods are available from createMotionToolkit / MotionCanvas kit. These are signatures from the adapted source, not executable code. P means PAINT; R means RIG. Use shared theme and actual speech timing.

```js
TY.font = (size, fam = 'PuHui-Black') => ...
TY.text = (c, s, x, y, { size = 120, fam = 'PuHui-Black', color = '#111', align = 'center', base = 'alphabetic', alpha = 1, scale = 1, rot = 0, track = 0, stroke, strokeW = 0, ox = x, oy = y } = {}) => ...
TY.width = (c, s, size, fam = 'PuHui-Black', track = 0) => ...
TY.wrap = (c, text, maxW, font) => ...
TY.fit = (c, text, maxW, size, fam, { maxLines = 2, min = 0.45, weight = '', soft = false, balance = false } = {}) => ...
TY.charsIn = (c, str, x, y, lt, { font, color, dur = 0.35, stagger = 0.04, dy = 24, scale0 = 1, align = 'left', ease = MO.cubicOut, shadow, spacing = 0 } = {}) => ...
TY.rise = (c, s, x, y, p, o = {}) => ...
TY.pop = (c, s, x, y, p, o = {}) => ...
TY.blurIn = (c, text, x, y, p, { blur = 18, dy = 28, scale = 0 } = {}) => ...
TY.typed = (s, p) => ...
TY.typedCount = (t, t0, rate, fps = 0) => ...

TY.fmt = (v, dec = 0, sep = true) => ...

```

Source: [upstream MIT library](https://github.com/alchaincyf/huashu-art-motion/blob/64cb27271ee0ad3375298e2890b33cbec36d4051/scripts/engine/lib/typo.js). Mona uses isolated instances; omit external engine globals, author presets and external resource loaders. Font binaries/stroke-order data are not bundled.
