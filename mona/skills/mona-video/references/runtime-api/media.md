# MD: media

Methods are available from createMotionToolkit / MotionCanvas kit. These are signatures from the adapted source, not executable code. P means PAINT; R means RIG. Use shared theme and actual speech timing.

```js
MD.size = src => ...
MD.cover = (c, src, o = {}) => ...
MD.toScreen = (geo, r) => ...
MD.focusFor = r => ...
MD.zoomFor = (rect, iw, ih, bw = W, bh = H, fill = 0.6, fit = 'cover') => ...
MD.print = (c, src, w, h, o = {}) => ...
MD.label = (c, text, x, y, o = {}) => ...
MD.frameAt = (frames, lt, fps = 30, loop = false) => ...
```

Source: [upstream MIT library](https://github.com/alchaincyf/huashu-art-motion/blob/64cb27271ee0ad3375298e2890b33cbec36d4051/scripts/engine/lib/media.js). Mona uses isolated instances; omit external engine globals, author presets and external resource loaders. Font binaries/stroke-order data are not bundled.
