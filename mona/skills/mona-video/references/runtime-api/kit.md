# KIT: kit

Methods are available from createMotionToolkit / MotionCanvas kit. These are signatures from the adapted source, not executable code. P means PAINT; R means RIG. Use shared theme and actual speech timing.

```js
KIT.densify = (pts, per = 6) => ...
KIT.resample = (pts, step = 4) => ...
KIT.ribbon = (pts, w) => ...
KIT.warpRows = (dst, src, fx, band = 6, margin = 0) => ...
KIT.warpCols = (dst, src, fy, band = 6, margin = 0) => ...
KIT.star = (cx, cy, r0, r1, n, rot = 0) => ...
KIT.blob = (c, x, y, r, seed, wob = 0.08, n = 14) => ...
KIT.choreo = (lt, t) => ...
KIT.nearArm = (c, G, { fill, line = '#111', lw = 3, skin, cuff, cupBody, cupRim, pattern } = {}) => ...
KIT.label = (c, { title, sub, tFont, sFont, tCol, sCol, x = 1866, y = 128, sy = 182, shadow, before, after, spacing = 0 }) => ...
```

Source: [upstream MIT library](https://github.com/alchaincyf/huashu-art-motion/blob/64cb27271ee0ad3375298e2890b33cbec36d4051/scripts/engine/lib/kit.js). Mona uses isolated instances; omit external engine globals, author presets and external resource loaders. Font binaries/stroke-order data are not bundled.
