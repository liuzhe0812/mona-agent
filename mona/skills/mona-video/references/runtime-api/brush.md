# PAINT: brush

Methods are available from createMotionToolkit / MotionCanvas kit. These are signatures from the adapted source, not executable code. P means PAINT; R means RIG. Use shared theme and actual speech timing.

```js
PAINT.brush = (c, pts, { w = 10, tone = 0.85, dry = 0.45, seed = 1, reveal = 1, bristles = 8, col = [16, 14, 12], head = 0.12, tail = 0.4, per = 5 } = {}) => ...
PAINT.leaf = (c, x, y, ang, L, wmax, tone = 0.88, col = [16, 14, 12]) => ...
PAINT.inkWash = (c, key, grow, fn, { blur = 2, halo = 10, haloA = 0.22, alpha = 1 } = {}) => ...
PAINT.flowSeeds = (cell = 24, seed = 5) => ...
PAINT.flowLines = (c, seeds, { t = 0, region, angle, color, params, extraSteps = 8 }) => ...
PAINT.deform = (pts, depth, amp, r) => ...
PAINT.watercolor = (g, pts, color, { layers = 7, alpha = 0.13, amp = 10, seed = 1, edge = 0.1, blend = 'multiply', fill } = {}) => ...
PAINT.rectPts = (x, y, w, h) => ...
PAINT.ellipsePts = (cx, cy, rx, ry, n = 18) => ...
PAINT.impasto = (c, pts, w, col, hi) => ...
PAINT.cut = (pts, seed, step = 18, amp = 2.5) => ...
```

Source: [upstream MIT library](https://github.com/alchaincyf/huashu-art-motion/blob/64cb27271ee0ad3375298e2890b33cbec36d4051/scripts/engine/lib/brush.js). Mona uses isolated instances; omit external engine globals, author presets and external resource loaders. Font binaries/stroke-order data are not bundled.
