# CAM: camera

Methods are available from createMotionToolkit / MotionCanvas kit. These are signatures from the adapted source, not executable code. P means PAINT; R means RIG. Use shared theme and actual speech timing.

```js
CAM.apply = (c, cam) => ...
CAM.with = (c, cam, fn) => ...
CAM.toScreen = (cam, x, y) => ...
CAM.toWorld = (cam, sx, sy) => ...
CAM.zlerp = (z0, z1, e) => ...
CAM.coverZoom = (r, cx = W / 2, cy = H / 2) => ...
CAM.anchor = (wx, wy, z, sx, sy) => ...
CAM.pushTo = (base, wx, wy, Z, e, k = e, to = [W / 2, H / 2]) => ...
CAM.at = (keys, t) => ...
CAM.track = (base, events, t) => ...
CAM.layer = (c, cam, d, fn) => ...
CAM.velocity = (camFn, t, dt = 1 / 60) => ...
CAM.motionBlur = (c, src, vx, vy, k = 7) => ...
CAM.drift = (t, amp = 6, seed = 0) => ...
```

Source: [upstream MIT library](https://github.com/alchaincyf/huashu-art-motion/blob/64cb27271ee0ad3375298e2890b33cbec36d4051/scripts/engine/lib/camera.js). Mona uses isolated instances; omit external engine globals, author presets and external resource loaders. Font binaries/stroke-order data are not bundled.
