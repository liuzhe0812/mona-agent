# 手绘笔记（S22）

米白纸上的墨蓝钢笔线稿 + 一种橙色，像一页竖长的研究笔记：线一笔笔描出来、字一个个写出来，镜头从上往下「读」。适合讲概念拆解、实验/观察记录、「我发现了什么」这类娓娓道来的知识；不太适合大量数字和图表、强节奏的快剪、需要真实照片质感的内容。

## 看起来什么样

- 参考的是一张竖长的手绘研究笔记信息图（讲德国商品）：米白纸面，墨蓝钢笔线稿画实物，暗部用一组组斜排线，物体底下几道横向短线当地面。
- 只有墨蓝和橙两种颜色压在纸上，其余全是纸色和铅笔灰。
- 标题区是虚线矩形框（转角出头），上沿压着「※ 英文 ※」圆头字（实心字后面错开一层细描边，像描了两遍），框里是带颗粒、像橡皮章的粗圆中文。
- 说明都写成「@标签：」：墨蓝实心小方块里写白色手写字，下面跟手写正文，再拖几道波浪线、虚线当没写完的字；细引线末端有实心小圆点。
- 说明框是手绘矩形（线出头、不闭合），有的错开叠两三层像一摞纸；版式左图右文、左文右图交错往下排，底部一条橙色横幅。

字幕关键词标法：A、B 词画手绘实心色块（四角略歪，高 80）写白字；其余强调词墨蓝字下面画一道橙色波浪下划线（6 像素粗，在字下 44 像素）。

**挑哪两个词当 A / B**（v1.1）：这段话的两个核心名词——观众看完要记住的那两个概念，最好在字幕里出现 2 次以上、画面里会反复露面；两个最好是一对，A 给先出场、更重要的那个（Token 例子：成都 / 旅行；观众实测：窗口 / 模态）。字幕里按字面精确匹配，「多模态」这类包含关系怎么标见下面「字幕区」。

## 构图和版式

- 整片是一张竖长的笔记纸（世界坐标宽 1920，往下 3400 像素），镜头从标题往下读；画面焦点 (960, 455)，`SUB_TOP = 908` 以下是字幕区。
- 版式左右交错：A 段（y 0–950）标题框 + 电脑在左、笔记在右 → B 段（y 1080–1780）笔记和剪刀在左、机器人在右 → C 段（y 1900–2800）笔记本在左、书和叠纸框在右 → D 段（y 2860–3400）从左往右「两片 → 箭头 → 结论框」。
- 没有固定页眉：标题框是 A 段的一部分，镜头往下走就出画。
- v1.3 起分三层：页边铅笔涂鸦（远景，跟镜头走 0.4 倍）→ 笔记本身（中景）→ 笔、浮起来的纸片（前景）；最上面盖一层很淡的纸页光影。

## 动效和节奏

- 线稿描出 0.3–0.75 秒；@标签从左往右刷出 0.25 秒；手写字每字 0.07–0.13 秒；弹出用 outBack 0.2–0.45 秒。
- 镜头 inOutCubic 0.6–0.7 秒换段；停住讲时 `'sine'` 慢推（例如 1.15 → 1.2 倍）；打字时推近到 1.48 倍。
- 动作卡在 `TL.mark()` 上，提前 0.03–0.1 秒；逐字写用 `TL.chars`；页面里不写死秒数。
- 挑静帧的秒数：取关键词开始说之后约 0.3 秒（v1.1，观众实测：逐字出现的字要这么久才写完；4.95 秒只写出「失」，5.15 秒才是「失忆」）。v1.3 有笔尖后，再看一眼笔杆有没有压住要读的字（笔杆朝右上，会盖住刚写完那行上方的东西），压住了就挪 0.1–0.3 秒。
- v1.3：盖章、砸下那一下震屏（`动效.shake`，0.18–0.2 秒、7–8 像素）；停住的东西轻轻动（机器人以地面为轴呼吸 1%、小卡 `动效.sway` 摇 ±1 度）。

## 默认动效（v1.3）

`模板.html` 开头的 `const FX_DEFAULT = true;` 是总开关，换任何时间线都自动生效；设成 `false`，画面和 v1.2 模板逐字节一样（我们用通用时间线、Token 时间线各 6 个时刻比过 PNG 的 md5）。你自己在 `fxBefore` / `fxAfter` 里加的调用照常生效。

**加了什么**

| 东西 | 做法 | 在哪 |
|---|---|---|
| 背景层 1：页边铅笔涂鸦（远景） | 铅笔灰小涂鸦（星星、螺旋、弯箭头、云、灯泡、方块、太阳、勾选框、纸飞机、波浪）只在画面四周的页边，一笔笔画出 → 停几秒 → 淡掉 → 旁边再画一个；跟镜头走 0.4 倍（视差）；镜头推近时变淡；换页时平滑滑过去不跳 | `drawDoodles`，`DOODLE_ALPHA`（默认 0.6，0 = 不画） |
| 背景层 2：纸页起伏的光影 | 两组很淡的斜向暖灰明暗带（最深约 4%）往两个方向慢慢漂，像纸页轻轻起伏、窗外的光在动；每帧在 192×108 小画布上算一遍再放大，不逐帧画满屏渐变 | `drawLight` |
| 笔尖跟着写（次要动作） | 手写字（`writeText`）、开了 `penOn()` 的线稿、给了开始时刻的 `underline`：写到哪笔尖就在哪；墨蓝线用钢笔、橙线用橙色马克笔；写前从右上方落下、写完抬走；一帧里正在写的优先、同级取最近开始的那个；字幕区里不画 | `penCand` / `drawPenTool` |
| 每个镜头慢推 | 短镜头每秒 +1.2%（5 秒封顶，1.00 → 1.06）；长于 6.5 秒的先推近到 1.06、后半段慢慢拉开到 1.02；镜头交界处平滑接上 | `shotPush` / `fxCam` |
| 镜头交界自动转场 | 按 `TL.shots` 在每个交界轮换 `FX_KINDS = ['scroll', 'curl', 'zoom', 'erase']`：往下读（镜头移到下一段）→ 卷角翻页 → 推近穿过去 → 橡皮擦掉。前后有一个镜头短于 1.6 秒的交界，大转场（卷角、橡皮擦）自动换成推近穿过去；同一种不连用 3 次 | `FX_CUTS` / `fxTransitions` |
| `--no-subtitle` | 页面地址带 `?nosub=1` 时字幕和底部纸色字幕带整块不画（v1.2 底带还在） | `render` 最后一行 |
| 骨架 | 每段左右交错（手绘框 + 一张信息小卡 + 引线）、框里关键词下面一行行写出灰色波浪占位线、关键词写完离下一个词还有 2 秒以上就推近它再拉开 | `SECS` / `drawSections`（换成自己的分段时整块删掉） |

**这套适合的转场**：镜头往下读（滚动到下一段）、翻到新一页（卷角，`pageCurl`）、橡皮擦掉（`eraseWipe`，白橡皮 + 橙纸套 + 橡皮屑）、推近某个小图再拉开（`zoom`，或自己在 CAM 里写推近 / 拉开两段）。次要动作：笔尖跟着写、纸页轻微起伏、剪纸屑 / 橡皮屑、橙色马克笔高亮扫过。只用一种橙，别加别的颜色的光效、故障、粒子。

**写自己的分段时**
- 卷角、橡皮擦会盖住切点前 0.12–0.2 秒、切点后 0.3 秒左右，这段时间镜头停在原处，盖成空白纸的那一刻（`FX_CUTS[k].tj`）才跳到新位置：这种交界的镜头移动写成 `[cu.t0, cu.tj, x, y, 缩放, 'cut']`（`'cut'` 是 v1.3 新加的缓动：到「止」那一刻跳过去），新一段的东西从 `fxStart(镜头序号)` 之后再画（骨架就是这么写的）。不改也能用：镜头会在盖成空白纸那一刻跳到你 CAM 里那一刻的位置。
- 要换转场顺序改 `FX_KINDS`；单独指定某个交界：`FX_CUTS[k].kind = 'curl'`（k 从 0 数，第 k 个交界在第 k+1、k+2 个镜头之间），改完调一次 `fxPlan()`，要放在 `SECS` / `CAM` 定义之前。
- 想让某个东西浮在翻页 / 橡皮擦上面留下来（Token 例子里 8 片 Token 就是这样），把它画在 `fxTransitions(t, cam)` 那一行之后，并按镜头跳的那一刻换算位置（示例 `pieceLater` 里的 `remap`）。
- 线稿想要笔尖跟着：建的时候 `.penOn()`，画的时候用 `.at(t, t0, d)`（直接 `.draw(p)` 要传第二个参数 `t0`）。东一笔西一笔的大线稿（电脑、机器人、笔记本）别开，笔会满屏跳。

**代价**：Token 时间线模板 84 → 97 毫秒/帧（+15%），通用时间线 84 → 96（+14%）；示例页 90 → 101（+12%）。

**实测**（v1.3 自检，`pipeline/丰富度检查.mjs`）：模板 + Token 时间线 相邻格平均 5.4（不过、最长静止 2.9 秒）→ 12.0（过、0.1 秒）；模板 + 一段 33.6 秒的别的口播 2.6（不过、9 对几乎没变、最长静止 5.4 秒）→ 13.3（过、0.7 秒）；示例页 22.3 → 28.5（最长静止 0.57 → 0.03 秒）。三个页面「先 seek 别的时刻再 seek 回来」和「单独 seek」出的 PNG 逐字节一样。

## 字幕区

- 底部 172 像素（y 908 起）是固定字幕带：纸色底 + 纸纹盖住镜头内容，上沿一道铅笔虚线，底边 14 像素橙色细条。
- 字：手札体 Bold 64 像素墨蓝，中心 y=990，0.08 秒淡入；A/B 词色块白字（左右各留 12 像素），其余强调词橙色波浪下划线。
- 不自动换行，一条最多约 25 个字。画面避让：主体放在焦点上下，镜头 y 要让东西落在 908 以上；`?nosub=1`（`--no-subtitle`）时字幕和字幕带整块不画（v1.3；以前带还在），底部露出的是纸，画面东西本来就不进这块。
- 字幕关键词：一张表、长的优先、整词替换——`字幕强调` 里写「多模态」，就整个画波浪下划线，里面的「模态」不再是色块。
- 紧接着上一条的字幕直接换字（`subIn`），只有第一条、和上一条中间有空档时才淡入——以前每条都从透明淡入 0.08 秒，换条那一帧字幕是空的或很淡（「眨一下」）。v1.1 起模板这样，v1.3 起示例页也这样。

## 质感和渲染速度

- 纸纹：256×256 小块（淡墨点 + 纤维）只生成一次，做成 pattern 跟着镜头铺满（模板 323 行 `PAPER`），不逐帧算。
- 用默认 png；Token 成片约 18 MB（v1.3 背景一直在动，比 v1.2 的 13 MB 大）。没测过 jpeg。
- 实测（v1.3，本机同时有别的渲染、负载 5–8）：示例页 101 毫秒/帧（v1.2 同条件 90），21 秒 636 帧约 65 秒；模板 96–97 毫秒/帧。更早一次（负载 38–63）v1.2 示例页 119 毫秒/帧；10 帧/秒 960×540 预览 69 毫秒/帧。

## 踩过的坑

1. 剪开时 8 片的边一下子全出现：改成剪到哪断到哪，没剪到的部分保持一整条（`drawRemainder`，示例 912）。（做样片时自检）
2. 上色时颜色从灰过渡、看着脏：改成马克笔从左往右涂（斜边擦出）。（做样片时自检）
3. 飞行的纸条压住 @标签：纸条改画在标签下面；镜头 3 纸条飞过仍会压住「收到 Prompt！」约 0.3 秒。（做样片时自检）
4. 说明小字 38–40 像素在手机上只有约 10 像素，吃力；关键词标签放大到 52 像素才读得清。（做样片时看 480 宽检查图发现）
5. 早先的说明写手札体、圆体「随系统安装」，其实是按需下载字体：做样片的电脑验证「逐字节一样」是因为已经下载过；新 Mac 要先在字体册下载。
6. 颗粒字 `dens` 太小读不清：标题 80、结论章 120 都糊，改成 140 / 200。（观众实测）
7. 静帧挑在关键词开始那一刻，手写字还没写完（4.95 秒只有「失」）：取关键词开始 + 0.3 秒。（观众实测）
8. 每换一条字幕都从透明淡入 0.08 秒，换条那一帧字幕是空的（「眨一下」）：改成紧接着的直接换字（`subIn`）；v1.3 示例页也改了。（观众实测）
9. 换镜头的镜头运动比关键词早 0.25 秒就走、字刚写完就被带走；结论章盖下后 0.35 秒镜头就移开，读不完：换段镜头在镜头开始时才走，盖章后至少停 1 秒。（观众实测，扫片发现）
10. （v1.3）翻页先做成「整页对折」（把掀起的部分整块翻过去），翻到一半折过来的纸就把剩下的旧页全盖住了，而且白纸背和米白纸面分不清，看不出在翻页：改成卷筒带——只画折痕旁卷起来的一截（宽 140–330 像素）+ 折痕两边的斜排线 + 投在新页上的影子。
11. （v1.3）模板骨架每段都是同一个居中的框，镜头之间 2.5 秒前后的画面几乎一样，Token 时间线丰富度只有 9.5：改成左右交错（框 + 信息小卡 + 引线）后 12.0。「每段一个模子换字」丰富度检查是会抓出来的。
12. （v1.3）笔杆朝右上，会盖住刚写完那行上方的东西（例如写「提示词」时压住「@这句话：」）；灰色占位线也跟笔时，7.6 秒的静帧里笔压住了「Prompt」：占位线不跟笔，挑静帧时看一眼笔的位置。
13. （v1.3）页边涂鸦在镜头推近 1.4 倍时跑进了电脑屏幕里：涂鸦按镜头倍数变淡（1.06 倍以上开始淡，1.36 倍剩 35%）。
14. （v1.3）画布状态（`lineCap`、`font`、`textAlign` 等）原来跨帧沿用上一帧留下的，换个 seek 顺序就可能不一样：`render` 开头 `resetCtx()` 全部复位，再测「先 seek 20 秒再 seek 5 秒」和「单独 seek 5 秒」逐字节一样。
