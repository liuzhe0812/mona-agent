# 超现实拼贴（S44）

米灰纸海报上的超现实概念拼贴：特粗高反差衬线大标题（一个字填桃橙渐变、下面压橙色干笔刷）、手写批注 + 手绘箭头，主体是一个开了顶的石头人头，Token 变成头里的多米诺骨牌。适合讲思维方式、心理和认知、「一件小事引出一串后果」这类需要一个大比喻的概念；不太适合步骤很多的操作教程、密集数据、没有好比喻可用的内容。

## 看起来什么样

- 参考的是一张超现实概念拼贴海报（讲二阶思维和多米诺骨牌）：米灰纸底，细颗粒、淡斑驳，留白多。
- 标题是特粗高反差衬线字，近黑带一点墨绿；其中一个字母填桃橙渐变，第二行下面压一道橙色干笔刷（毛边、拖尾、后半段飞白）。
- 宽字距几何无衬线小标签；侧栏小字左边一条朱橙竖条；马克笔手写批注 + 手绘弧形箭头指向画面里的东西。
- 主体：深炭色石雕人头侧面，头顶切开，里面一条浅色石阶站着一排多米诺骨牌；旁边站一个很小的背包小人。
- 拼贴纸片：芥末黄大圆（太阳）、青色竖长条、撕边方格纸；骨牌五颜六色，露出侧面和顶面厚度，地上拖长长的硬边灰影子。

## 构图和版式

- 一张会动的拼贴海报：左边特粗衬线大标题（上面一行宽字距小标签，下面一道干笔刷），右边主体拼贴；左上罗盘星标志 + 两行粗体品牌名、右上宽字距小字 + 细线常驻（`drawHeader`）。
- 主体是石头人头（头像贴图范围世界坐标 x 96–762、y 266–904）。镜头系统有两套坐标：普通海报坐标（`setCam`）和「钻进头顶开口」的头里坐标（`toDive`，推到 2.4 倍）；镜头 4–5 在头里，镜头 6 回到全景看整个人头。
- 解释用手写批注 + 手绘箭头，不用说明框。底部 170 像素留给字幕；顶上约 120 像素是页眉带，部件别放进去、运动路线也别经过（太阳、小人、纸条弧线 v1.3 都挪开了）。

## 动效和节奏

- 纸片、标题都是「拍上去」0.3 秒；重要的词、勾章是「砸下」0.13 秒 + 震屏；手写字 0.3–0.5 秒写完，箭头 0.25–0.45 秒画完；剪刀 0.07 秒一刀；骨牌翻面落下 0.42 秒、落地压扁一下。
- 镜头 inOutCubic 0.4–0.7 秒；每个镜头都在慢推，或推近看刚出现的那块、到关键词再拉开。太阳每场挪个位置（`SUNP`），镜头 8 是被拿起来再砸下去。
- 动作卡 `TL.mark()` 提前 0.02–0.06 秒；打字用 `TL.chars`。
- 挑静帧的秒数：取关键词开始说之后约 0.3 秒（观众实测：逐字出现的字要这么久才写完；4.95 秒只写出「失」，5.15 秒才是「失忆」）。

## 默认动效（v1.3）

**示例页**（`示例_Token.html`）照「动效和画面变化」重做过：

- 背景四层一直在动：纸面光影（1/8 分辨率缓存的暖光、冷影斑驳，很淡，慢慢漂、明暗起伏，视差 0.3）；太阳呼吸缩放 ±1.2%、上下漂、纹理慢转；青条、方格纸各自轻轻摇；12 片远处小纸屑往右上飘、自转（视差 0.45，不进页眉带和字幕带）。开场 0.6 秒里太阳、青条、方格纸、标题依次拍上。
- 转场 4 种：撕海报（镜头 2 → 3，左半张带着标题被撕走、露出升起的人头）、钻进人头（3 → 4）、纸条斜扫（5 → 6，4 条撕边长纸条从下往上交错扫过盖满，盖满时镜头切回全景）、大物件砸下 + 震屏（7 → 8，太阳被拿起再砸到新位置，纸条被震飞）。另有发出消息时纸条拍进对话框 + 轻震、镜头 7 推近数据区。
- 手写批注和箭头约 3 秒一条（聊天框 → 这句话 → 提示词指回纸条 → 飞行虚线 → 咔嚓 → 8 块 → 碎片 → Token 箭头 → 翻找 → 常常一起出现 → 推断）。

**模板**（`模板.html`）加了换任何时间线都自动生效的默认动效：

- **开关**：脚本开头 `const FX_DEFAULT = true;`。设成 `false` 回到 v1.2（逐像素一样，实测两条时间线各 5 个时刻 md5 相同）。自己在 `fxBefore` / `fxAfter` 里写的调用两种情况都照常生效。
- **背景**：同示例页的四层（纸面光影、太阳、青条和方格纸、小纸屑）一直轻轻动，开场依次拍上；太阳的三个位置都在页眉带下面（`SUNP_FX`）。页眉字描一圈纸色边，深色东西从后面经过也读得清。
- **转场**：按 `TL.shots` 在每个镜头交界自动加，轮流用 `FX_KINDS = ['撕海报', '纸条斜扫', '钻进去']`。撕海报 = 上一镜头最后一帧（`paint` 画进离屏画布）沿中间撕成两半、往左右飞出（0.45 秒）；纸条斜扫 = 4 条长纸条交错扫过、盖满那一刻换镜头（切点前 0.32 秒到后 0.4 秒）；钻进去 = 镜头猛推进画面中间、最深处盖一层纸色、换镜头后从里面拉出来（切点前后各约 0.3–0.45 秒）。想指定某个交界：`FX_PLAN = { 2: '钻进去', 5: '无' }`（交界从 1 数，'无' = 硬切）。
- **镜头**：每个镜头慢推（`动效.zoom`，每秒 1.2%，5 秒封顶，略往右上漂）；镜头里每条字幕开头一个「推近再拉开」节拍（轮流推近 1.08 倍偏左上 → 拉开 → 推近偏右下 → 拉开），两个节拍隔 2.8 秒以上就在中间补，长镜头里也每 2–3 秒有一次看得见的变化。推近时连慢推最多约 1.14 倍，画面四边各约 7% 会被裁掉：场景里的东西别贴边（留在 5% 安全区里就没事）；不想要节拍就把 `BEAT_POSE` 的 z 都改成 1。
- **骨架**：开了默认动效时，换镜头不再淡出（交给转场），新标题晚 0.3 秒拍上；关键词纸条落定后轻轻摇。
- 实测（Token 时间线、通用测试时间线 33.6 秒 4 个镜头）：丰富度相邻格平均 18.0、14.5，都判「过」；jpeg 截图 53–56 毫秒/帧。

**这套适合的转场**：撕开海报露出下一张、镜头钻进比喻物里、纸条斜扫、大物件砸下（配震屏）。不适合故障撕裂、CRT 关机这类屏幕类转场；白闪别用（纸的世界里没有闪光，钻进去用的是纸色）。

## 字幕区

- 每条字幕印在一条撕边米白纸条上：宽 = 字宽 + 100、高 104，中心 y=994，略歪（±0.35°），右下 (4, 6) 硬投影，纸上叠 0.4 的颗粒；第一条、和上一条中间有空档时 0.08 秒淡入，紧接着上一条的直接换字（`subIn`，不「眨」）。
- 字：特粗衬线 64 像素（`fHead(64)`）墨色；关键词的干笔刷在**被念到的那一刻**刷出（按 `TL.chars` 算，0.28 秒）。
- 不自动换行，一条最多约 25 个字；纸条压在深色石头上也清楚。`?nosub=1`（`render.mjs --no-subtitle`）时整条纸条和字都不画，没有底带。
- 字幕关键词：两层叠着标——`高亮` 改字的颜色（红 / 蓝），`字幕强调` 是念到时刷出的橙色干笔刷（长的优先、不重叠）；`字幕强调` 写「多模态」时，三个字都刷笔刷、「模态」同时是红 / 蓝字。

## 质感和渲染速度

- 纸底（斑驳 + 1100 根纤维 + 暗角）、颗粒（256×256，3×3 一块）、太阳、青条、方格纸、笔刷、石头人头（2.4 倍分辨率）、卡片投影、纸面光影、小纸屑、斜扫纸条，全在开场生成一次缓存。
- 颗粒让 PNG 很大：同一段 jpeg 99、png 248 毫秒/帧。**用 `--format jpeg`**（新建作品.mjs 已写进 作品.json）。
- v1.3 示例页实测（jpeg，同一台机器背靠背、负载约 8–10）：v1.2 示例页 52 毫秒/帧，v1.3 示例页 59 毫秒/帧（21 秒 636 帧约 38 秒）。多出来的主要是满屏纸面光影那一次放大绘制（约 5 毫秒）；撕海报、纸条斜扫的那十几帧每帧多 10 毫秒左右。

- 589–637 行是骨架：`hasMark` / `MS`（595–596 行，删骨架时留下这两行）、`SECS` + `drawPoster`（每个镜头一张海报：大标题 + 干笔刷 + 撕边纸条关键词 + 纸胶带 + 箭头 + 手写「#N」）。
- 638 行起：`fxBefore` / `fxAfter`（640–641 行，自己的转场、次要动作写这里）、默认转场（642–680 行：`tearCut` 撕海报、`sweepCut` 纸条斜扫、`diveCut` 钻进去、`fxDefault`）、`paint`（681 行起）、`render`（691 行起）。
- **`paint(t)` 里第 687 行 `drawPoster` 那句是场景入口**，换成自己的绘制函数，骨架删掉。场景只能写在 `paint` 里：撕海报要再调一次 `paint(切点前一刻)` 把上一镜头最后一帧画进离屏画布；场景函数里用 `g` 画（不要自己存 `MAIN`），就会画到对的画布上。
- 自己的场景里已经有转场（例如照示例页钻进人头）的那个交界，用 `FX_PLAN` 把它设成 `'无'`，免得两个转场叠在一起；全不要就把 `FX_DEFAULT` 设成 `false`。
- 这套是 B 级：先想一个新的超现实比喻（Token 例子：AI = 开顶石头人头、Token = 头里的骨牌），再用底座部件排主体和镜头。

**估时**：一次观众实测（手绘笔记，23 秒口播、9 个镜头，从模板改）全流程约 30 分钟，其中写页面约 18 分钟（含想构图约 10 分钟）；只测过这一次。这套没单独测；按代码量推算是「20–30 秒新口播，想比喻和排版约 15 分钟，写场景约 50–70 分钟，再加 15 分钟出静帧」，同样推算的手绘笔记是 60–80 分钟、实测 18 分钟，可以按推算的一半左右准备（B 级另加重排版式 / 想比喻的时间）。
