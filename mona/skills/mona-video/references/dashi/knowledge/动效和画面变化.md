# 动效和画面变化（v1.2）

> 管「变换、视觉、动效丰不丰富」。`讲解动画通用规则.md` 管看得清、卡得准，这份管画面一直有新东西。写分镜时照第一节给每个镜头写变化清单，挑转场查第三节，写页面时调 `pipeline/动效部件.js`（第八节），出片后照第七节自查。
>
> 来由：2026-10-09 我们做了一次盲测：剪纸、粉笔、霓虹三种风格，同一段口播各做「用 skill / 不用 skill」两版，让作者猜哪版用了 skill，猜中 2 组。他挑剪纸组的理由：那版「变换更丰富，视觉更丰富，动效也更丰富」。霓虹组他挑的是不用 skill 的那版（雨夜城市、流动网格、故障撕裂、灯管字逐字通电）。v1.1 只要求看得清、卡得准，对丰富没要求；赢的剪纸、粉笔是 skill 里有实测配方的风格，霓虹当时只有词典条目。
>
> 标注：【标准】有公开出处（文末）；【飓风】我们统计的影视飓风 6 期视频的镜头切换（出处第 2 条）；【盲测】这次 6 版；【经验】做 11 套和几次实测的经验，没单独验证。

## 一、每个镜头写清四件事：进场 → 主动作 → 次要动作 → 出场或转场

| 环节 | 是什么 | 时长、幅度 |
|---|---|---|
| 进场 | 怎么来：弹出、掉落、滑入、描出、通电、拍上 | 0.2–0.5 秒，比关键词早 0.03–0.1 秒 |
| 主动作 | 这个镜头要讲的那件事怎么演：变形、移动、填色、打勾、盖章、数字滚动 | 跟口播走，卡在关键词上 |
| 次要动作 | 讲的时候一直在动的小东西：呼吸、飘动、闪烁、粒子、光标、慢推 | 整个镜头；位移 2–6 像素、缩放 1–3%、旋转 1–2 度，周期 1.5–4 秒 |
| 出场 / 转场 | 怎么走、怎么换到下一个：撕走、擦掉、推走、故障、翻页 | 0.3–0.7 秒 |

例（盲测口播「它可能就会编造一首李白根本没有写过的词」那个镜头）：

- 进场：卷轴从上往下展开（纵向 0.03 → 1，0.45 秒，略过冲）。
- 主动作：说到「编造」时假词一个字一个字写出；说到「根本没有」时红印章「查无此词」砸下、震屏一下。
- 次要动作：卷轴轻轻摆；旁边的机器人眨眼；背景的光点慢慢飘。
- 出场：卷轴缩小飞到右上角，下一镜接着用（不消失 = 前后有联系）。

写法和要求：

- 写进 `分镜.json` 每个镜头的 `变化` 字段（`{"进场": "…", "主动作": "…", "次要动作": "…", "转场": "…"}`，不进时间线），`分镜.md` 镜头表加一列「变化」。写不出主动作的镜头就是只有字的镜头，要重想画面。
- 次要动作不抢戏：一屏同时最多 2 种，幅度小、周期慢，离正在讲的东西远一点。【标准 ①：secondary action 是补充主动作，不能盖过它】
- 讲完停住的那几秒最容易「死」：给主体一个呼吸（缩放 1±1%，周期 2–3 秒）或慢推（第四节）。【盲测：不用 skill 的剪纸版，每片纸停住后都轻轻摇，旋转约 ±1 度、上下 3 像素】
- 东西能留就留：上一镜的主角缩小挪到角上陪着下一镜，比清空重来更连贯，也多一次变化。【盲测：不用 skill 的剪纸版把「大模型幻觉」纸块缩到顶上当页眉，陪到第 5 场】

## 二、多久要有一次看得见的新变化

| 多久 | 要什么 | 依据 |
|---|---|---|
| 每 2–3 秒 | 一个看得见的新变化：新东西进场，东西变形、换色、挪到新位置，镜头推近或拉开 | 【飓风】口播和举例约 3 秒一切，6 期镜头中位数 2.8–3.4 秒；【盲测】下表 |
| 每 3–5 秒 | 一次大变化：换镜头、换板、换版面（不一定换背景） | 【飓风】平均每镜 3.1–4.5 秒（录屏多的两期除外） |
| 一直 | 至少一样东西在动（次要动作），静止不超过 2 秒 | 【盲测】作者觉得更丰富的霓虹版 98% 的帧在动，最长静止 0.57 秒；【经验】 |
| 开头 3 秒 | 最密：1–1.5 秒一个变化 | 【飓风】达芬奇那期第 1 分钟切 44 次，黄白开场 2.4 秒一镜 |
| 讲原理 | 可以一张图撑 10–20 秒，但图里每 2–3 秒亮起新的一步 | 【飓风】V1：频闪那期一张动效图撑 34 秒，滑块一直在走 |

「看得见」指缩到手机上也看得出：小于 10% 画面面积的变化（一个小图标闪一下）不算新变化，只算次要动作。【经验】

**盲测 6 版量出来的**（`node pipeline/丰富度检查.mjs <成片.mp4>`：每 2.5 秒一格，算相邻两格每像素平均差 0–255；「在动」= 和 0.1 秒前比差 > 0.3；底部 170 像素字幕带不算）：

| 组 | 版 | 相邻格平均 | 几乎没变（< 4） | 在动的帧 | 最长静止 | 作者觉得 |
|---|---|---|---|---|---|---|
| 剪纸 | 用 skill | 14.1 | 0 / 10 | 58% | 2.00 秒 | 更丰富 |
| 剪纸 | 不用 | 11.1 | 0 / 10 | 74% | 0.80 秒 | |
| 粉笔 | 用 skill | 11.9 | 0 / 10 | 64% | 1.37 秒 | 更丰富 |
| 粉笔 | 不用 | 6.1 | 3 / 10 | 69% | 1.17 秒 | |
| 霓虹 | 用 skill | 9.4 | 1 / 10 | 85% | 0.67 秒 | |
| 霓虹 | 不用 | 16.7 | 0 / 10 | 98% | 0.57 秒 | 更丰富 |

- 三组里，相邻格平均分高的那版都是他觉得更丰富的那版；「在动的帧」「最长静止」对不上（剪纸、粉笔的 skill 版在动的帧更少，照样赢）。所以**先保证每 2–3 秒有看得见的新东西，再加一直在动的小东西**。
- 脚本判「过」的底线：相邻格平均 ≥ 10，且没有「几乎没变」的对；静止超过 2 秒另外提醒。只有 3 组、一个人看，是方向不是定论；同一段做两版时比分数比绝对值可靠。

## 三、转场要换着用

- 全片至少 3 种转场，同一种别连着用 3 次。换话题（大段落）用大转场：擦除、翻页、撕裂、整屏推走；段内换镜头用小转场：推移、叠化、硬切加一下冲击（震屏、闪一下）。【经验；派单要求。盲测里不用 skill 的霓虹版 5 次换场全是故障撕裂（开头另有 CRT 开机），照样被认为更丰富——它靠背景一直在动、镜头里变化多；转场种类不是这次的决定因素，换着用是防腻】
- 转场 0.3–0.7 秒，卡在句界（上一句说完、下一句开口前后 0.1 秒），画面被盖住的那一刻正好换内容。白闪、强故障一秒内不超过 3 次（通用规则第六节）。
- 转场要像这套风格的材料会发生的事：纸会掉、会撕、会翻；黑板会被擦；屏幕会故障、会关机；报纸会翻版、会推移。

| 风格 | 适合的转场 |
|---|---|
| 复古剪纸、手工纸、手账 | 纸片掉落盖满再撕走、翻页、旧纸片撕走新纸片拍上、彩纸条横扫、定格里硬切 + 抖一下 |
| 粉笔黑板、白板 | 黑板擦擦掉、横移到下一块板、粉笔灰散开、推近一处再拉开到新板、白色宽线 Z 字擦掉（白板） |
| 手绘笔记 | 镜头往下读（滚动）、卷角翻到新一页、橡皮擦掉、推近某个小图再拉开、推近穿过去（短镜头用）；黑板擦（`动效.erase`）是木背黑板擦，放在纸上不对 |
| 霓虹赛博、蓝图 | 故障撕裂、CRT 关机（压成一条亮线再展开）、扫描线扫过换画面、灯管断电再通电、光速推移 |
| 黑底科技 | CRT 开机 / 关机、扫描线扫过、光速推移、金线一笔描出下一幅图、由虚到实；故障撕裂要克制（0.2 秒以内、一片最多一次），这套要的是高级感 |
| 复古报刊、日系杂志 | 版面推移（整版左移露出下一版）、翻报纸、栏框伸缩、印章盖下后切版、推近一栏再拉开、剪刀沿裁切线剪下剪报带走 |
| 扁平流程图、扁平插画 | 沿流程横移到下一站、形状变成下一个形状、圆形遮罩放大、色块横扫 |
| 超现实拼贴 | 撕开海报露出下一张、镜头钻进比喻物里、纸条斜扫、大物件砸下 |
| 立体卡通、黏土 | 物件滚出画面、镜头拉远换景、圆形遮罩缩放、光面块翻转 |

纸片掉落、翻页、擦除、推移、故障撕裂、逐字通电、圆形遮罩、色块横扫有现成代码（第八节）。v1.3 起 7 套模板自带各自的默认转场（按 `TL.shots` 自动轮换），写法见各套风格卡「默认动效（v1.3）」。

## 四、前后景分层和镜头推拉

- 分三层：背景（底纹、远处的城市、光斑，只慢慢动）、中景（讲的东西）、前景（雨丝、粒子、偶尔经过的大东西）。至少两层，层和层动的速度不一样（视差）：背景 0.2–0.4 倍、前景 1.2–1.5 倍。【经验；盲测：不用 skill 的霓虹版城市剪影每秒左移 14 像素，雨丝每秒落 900–1500 像素，一直在动】
- 讲的时候慢推：每个镜头开始后缩放每秒加 1–1.5%，最多推 5 秒（1.00 → 1.06）。【盲测：不用 skill 的霓虹版每镜头 1.2%/秒、5 秒封顶】
- 推近 → 拉开：先推近 1.15–1.25 倍看刚写出来的那块，到关键词再拉开看全貌——不换镜头也多一次大变化。推近时别露出旁边那块的边。【盲测：用 skill 的粉笔版；推近 1.15 倍露出了隔壁板的卡片，镜头中心右移 140 像素解决】
- 震屏：盖章、砸下、撞击那一下，0.15–0.25 秒、8–16 像素、衰减；一段最多两三次。【盲测：不用 skill 的霓虹版「虚构」印章、「硬凑」撞击】
- 镜头运动用 inOutCubic，不匀速（通用规则第六节）。
- 镜头长、内容少时的保底办法：每句字幕交替一次推近和拉开（带一点横移）。不用新画任何东西，每句都多一次看得见的变化。【v1.3 扁平流程图模板；超现实拼贴模板在通用时间线上只靠慢推和背景动是 9.8、不过，按字幕节拍推近拉开后 14.5、过】
- 震屏要连背景一起动：把偏移加进画背景之前的镜头变换里，背景画布四边多留 40–50 像素。写在 `fxBefore` 里的偏移只作用于场景，背景在它之前已经画完，就只有内容在抖、纸不动。【v1.3 复古剪纸】
- 场景自己用 `setTransform` 设镜头时，会把 `fxBefore` 里设的推移、震屏盖掉：设镜头时先乘上当前变换（`getTransform()`），或者把推移量传进设镜头的函数。【v1.3 立体卡通】
- 浅色东西在浅底上动，丰富度检查几乎不算「在动」：浅底风格要靠镜头推拉，或深色、饱和色的东西移动来出变化。【v1.3 扁平流程图】

## 五、动作的预备、跟随、缓入缓出

出自 Frank Thomas、Ollie Johnston《The Illusion of Life: Disney Animation》（1981）的 12 条动画原则【标准 ①】，挑讲解动画用得上的 6 条：

| 原则 | 意思 | 代码怎么做 |
|---|---|---|
| 预备 anticipation | 大动作之前先往反方向来一点，观众知道要动了 | 飞出、弹起前先缩 5–8% 或后退 10–20 像素，0.08–0.15 秒（`动效.anticipate`） |
| 跟随和重叠 follow through / overlapping action | 停下时冲过头一点再回来；附属的东西（标签、天线、尾巴）晚几帧才停 | 进场用 outBack（s = 1.2–1.7）；附属物的时间减 0.07–0.13 秒再算 |
| 缓入缓出 slow in and slow out | 起步慢、停下慢、中间快 | 进场 outCubic、出场 inCubic、镜头 inOutCubic；不用匀速 |
| 弧线 arcs | 东西沿弧线走，不走直线 | 飞行路径用二次贝塞尔，中间控制点抬高 80–200 像素 |
| 次要动作 secondary action | 主动作之外的小动作，让画面活；不能抢主动作 | 呼吸、眨眼、摇摆、粒子（第一节「次要动作」） |
| 节奏 timing | 用了几帧决定轻重：快 = 轻、慢 = 重 | 轻东西 0.2–0.3 秒到位；重东西（盖章、砸下）0.12 秒砸下 + 震屏 |

- 定格一拍二（每秒 12–15 张）也是节奏：手工、纸、黏土、漫画类整片用，显得是手摆的；屏幕、科技类别用，会显得卡。【实测：复古剪纸每秒 15 张；盲测：用 skill 的剪纸版被认为更丰富，不用 skill 的剪纸版自己说「没做定格抖动」】
- 弹性别过头：outBack 的 s 超过 2 就像果冻，讲解动画里只给轻的小东西用。【经验】

## 六、这次盲测里好用的手法

6 版的代码不随 skill 发，下表「出自」一列只记来源。带「→ 动效.xxx」的有现成部件（第八节）。

**纸类（剪纸、拼贴、手账）**

| 手法 | 出自 | 怎么做 | 适合 |
|---|---|---|---|
| 定格抖动 → 动效.jitter | 用 skill 剪纸（复古剪纸模板 `stepT`） | 时间先量化到 1/15 秒再算位置；每一格按格号带种子抖 ±1.5 像素、±0.6 度 | 剪纸、拼贴、黏土、漫画 |
| 撕边纸片 + 纸纹投影 | 不用 skill 剪纸 `piece.py`、`shapes.py`；用 skill 剪纸 `tornPoly`、`colorCut` | 纸纹 = 一次生成的噪声乘底色；切边 = 形状往里缩 2 像素的那圈提亮 30%；投影 = 同形状偏右下 (5, 8)、模糊 6、暖棕 40%（不用灰黑）；手剪边 = 直边细分后每点抖 1–2 像素 | 剪纸、拼贴、手账、报刊 |
| 纸片依次掉落拼出标题 → 动效.paperDrop | 不用 skill 剪纸（「大模型幻觉」五个纸块） | 每块从上方约 750 像素掉下，outBack(1.2)，落地前转 8 度回正；一块比一块晚 0.08–0.12 秒 | 剪纸、手账、立体卡通 |
| 停住后轻轻摇 → 动效.sway | 不用 skill 剪纸 `el.py` | 旋转 `sin(1.7t + ph)` 度、上下 `3·sin(2.3t + ph)` 像素，每片 ph 不同 | 剪纸、手账、卡通 |
| 拍上 / 撕走 | 用 skill 剪纸（复古剪纸模板 `slap` / `peel`） | 拍上 = 0.2 秒内从 1.22 倍、投影离得远、斜一点落到原位；撕走 = 0.3 秒抬起、放大、转着飞出画面 | 剪纸、拼贴 |
| 卷轴展开、印章盖下 | 剪纸、粉笔、霓虹几版都用 | 展开 = 纵向缩放 0.03 → 1（outBack 0.8）；盖章 = 1.9 倍 → 1 倍、0.12 秒 + 震屏 | 各风格 |

**粉笔、手写类**

| 手法 | 出自 | 怎么做 | 适合 |
|---|---|---|---|
| 粉笔一笔笔写 + 粉笔头 | 不用 skill 粉笔 `tip.py`、`textimg.py` | 线按长度一段段画出；字从左往右软边擦出；正在写的那一笔头上画一支同色粉笔（约 84×18 像素、斜 50 度、带影子） | 粉笔、白板、手绘笔记 |
| 黑板擦换屏 → 动效.erase | 不用 skill 粉笔 `scenes.py`、`frameutil.py`、`ghost.py` | 换屏前 0.1 秒到后 0.3 秒，板擦从左往右，擦过的地方盖回黑板底，擦除边带波浪（`x − 40·sin(y/50)`），留 3–4% 的粉笔灰 | 粉笔、白板 |
| 推近看刚写的、再拉开 | 用 skill 粉笔 | 推近 1.15–1.25 倍，到关键词再拉开（第四节） | 粉笔、手绘笔记、报刊 |
| 黑板报常驻装饰 | 不用 skill 粉笔 | 报头、彩旗、小太阳、角落小花一直留在板上，换屏只擦内容区 | 粉笔、手账 |

**屏幕、霓虹类**（第 3 组不用 skill 那版，代码在 `第3组_霓虹/不用skill/工作/代码/`）

| 手法 | 出自 | 怎么做 | 适合 |
|---|---|---|---|
| 雨夜城市剪影（视差） | `bg.js` | 楼宽 50–160、高 90–420 像素，楼顶一道品红 / 青细边，窗户按哈希亮黄 / 青；整排每秒左移 14 像素循环；140 条斜雨丝每秒落 900–1500 像素 | 霓虹、黑底科技、蒸汽波 |
| 流动网格地面 | `bg.js` | 16 条横线，`u = ((i + 1.1t) % 16) / 16`、`y = 地平线 + (H − 地平线)·u²`，越近越亮；竖线从灭点放射 | 霓虹、蒸汽波、蓝图 |
| 故障撕裂（换场）→ 动效.glitch | `post.js`；用 skill 霓虹版的 `glitchCuts` 也是它（换掉了闪白） | 切点前后 0.14 秒；把当前画面切成 10 条横带各自左右错开（最多 170 像素），screen 叠一层偏 16 像素的重影，再撒几条品红 / 青色块；按帧号带种子 | 霓虹、黑底科技、像素 |
| 灯管字逐字通电 → 动效.neonText | `s3.js`；用 skill 霓虹版的灯管字 | 先画暗的灯管轮廓；每个字从被念到的时刻起 0.25–0.3 秒乱闪（每 1/60 秒按哈希 亮 / 0.12），然后常亮，偶尔再闪一下 | 霓虹、招牌、片头 |
| 泛光 + 扫描线 + 暗角 | `post.js` | 泛光 = 整帧缩到 480×270、模糊 5 像素、lighter 叠 45%；扫描线和暗角画在一张画布上只画一次 | 霓虹、黑底科技 |
| 每镜头慢推 | `main.js` | 缩放 `1 + 0.012·min(镜头内秒数, 5)` | 各风格 |
| CRT 开机、HUD 常驻小动 | `main.js`、`hud.js` | 开头 0.25 秒一条亮线从中间撑开；角上时间码跟着 t 跳、REC 每秒闪一次 | 霓虹、科技 |
| 流式打字 | `s2.js`（聊天窗、假诗） | 显示字数 = floor(进度 × 总字数)，末尾一个闪的光标 | 科技、聊天类内容 |
| 色差错位 | 两个霓虹版的「?」「瞎编」 | 同一个字红 / 青各偏 ±12 像素、低透明度叠，每 1/30 秒抖一下 | 霓虹、蒸汽波 |
| 代码合成音效 | 不用 skill 霓虹版第 7 步 | numpy 合成底噪、故障声、撞击声；skill 不做声音（回剪映加），记在这里备查 | — |

**这次 skill 版缺的**：三版都按骨架「一镜一事」做，镜头切得不少（9–10 个），但背景基本不动、镜头里讲完就停；霓虹 skill 版只有网格地面 + 扫描线 + 灯管字，没有城市、雨、泛光这类一直在动的背景层（它自己的记录也写了）。

## 七、丰富度自查表

**写分镜时**
- [ ] 每个镜头的 `变化` 四项都写了；写不出主动作的镜头重想
- [ ] 转场至少 3 种，同一种没有连着 3 次；大段落用大转场
- [ ] 开头 3 秒至少 2 个变化

**出静帧时**（3 张，每张逐项看）
- [ ] 至少两层：背景有东西（纹理、远景、光斑），不是纯色底上摆字
- [ ] 主体之外有次要动作的东西在场（粒子、雨、光标、摇摆的纸片），但没抢戏：480 宽检查图里字照样一眼能读
- [ ] 这一帧有正在发生的动作（写到一半、正在掉、正在通电），不是全部摆好等着
- [ ] 三张之间版面、主体大小和位置明显不一样，不是同一个模子换字

**扫片时**（出整段之后）
- [ ] `node "$SKILL/pipeline/丰富度检查.mjs" <成片.mp4>` 判「过」：每 2.5 秒一格，相邻格平均 ≥ 10，没有「几乎没变」的对
- [ ] 没有静止超过 2 秒的段（脚本会提醒）
- [ ] 打开 `检查/丰富度_扫片.png` 看相邻格：每格都看得出新东西；标「几乎没变」的那一段补一个变化（新东西进场、推近、换色）
- [ ] 转场在扫片里真的是 3 种以上（`--scan` 的每秒 3 帧图里看镜头交界）
- [ ] 每段不是同一个版式只换字：短镜头多的时间线上，版式不变的骨架丰富度过不了（手绘笔记 v1.2 模板在 Token 时间线上 5.4）

## 八、共用部件 `pipeline/动效部件.js`

`新建作品.mjs` 会把它复制进作品目录；7 套 `模板.html` 已经引了它，并留了两个空函数（空着画面和 v1.1 逐字节一样）：

- `fxBefore(t)`：画场景之前、镜头已经设好。放镜头类：推移 `动效.push` + `动效.shift`、慢推 `动效.zoom`、震屏 `动效.shake`、整体定格抖。
- `fxAfter(t)`：场景画完、页眉和字幕之前，已是屏幕坐标。放盖在画面上的：故障 `glitch`、擦除 `erase`、翻页 `pageTurn`、纸片盖屏 `paperCover`、粒子 `particles`、泛光 `bloom`、扫描线 `scan`。字幕永远在最上面，转场不会盖住字幕。

| 要什么 | 调用 | 说明 |
|---|---|---|
| 故障撕裂 | `动效.glitch(g, t, 换场时刻数组, {colors})` | 切点前后 0.14 秒 |
| 黑板擦擦掉 | `动效.erase(g, t, cuts, {fill: 底色或底图})` | 切点前 0.45 秒擦完，切点时整屏是空底，新镜头接着写（和盲测粉笔版「切点后还在擦」不同：不用存旧画面） |
| 翻页 | `动效.pageTurn(g, t, cuts, {paper})` | 一张纸从右往左扫过，切点时盖满 |
| 纸片掉落盖屏 | `动效.paperCover(g, t, cuts, {colors})` | 12 片撕边纸掉下来盖满、切点后掉走 |
| 推移 | `const p = 动效.push(t, cuts, {dir}); if (p) 动效.shift(g, p)` | 写在 fxBefore；背景画在场景前就不跟着动 |
| 纸片掉落（进场） | `动效.paperDrop(g, t, t0, (x) => { … }, {x, y})` | 拼标题时一片比一片晚 0.08–0.12 秒；`动效.paper` 画撕边纸 |
| 灯管字通电 | `动效.neonText(g, t, '词', cx, cy, 每字时刻或 t0, {size, color})` | 每字时刻取 `TL.chars` |
| 粒子 | `动效.particles(g, t, {kind: '光点' / '雨' / '纸屑' / '粉笔灰'})` | 默认避开底部字幕区 |
| 定格抖动 | `const j = 动效.jitter(t, i)` | 位置用 `j.t` 算，画前 `translate(j.dx, j.dy)`、`rotate(j.r)` |
| 呼吸、闪烁、预备 | `动效.sway(t, ph)`、`动效.blink(t)`、`动效.anticipate(p)` | 返回数，自己乘到位置、透明度上 |
| 复位画布（v1.3） | `动效.resetCtx(g)` | 每帧 render 开头调一次（会清空画布）；每帧重画的离屏画布也要。防「画面跟 seek 先后有关」，验法：`render.mjs <页面> --check-determinism auto` |
| 圆形遮罩（v1.3） | `动效.iris(g, t, cuts, {fill, cx, cy, ring, area})` | 切点前 0.35 秒圆收到 0、切点后 0.35 秒张开；圆外填 `fill`；`area: [x, y, w, h]` 只盖一块 |
| 色块横扫（v1.3） | `动效.sweep(g, t, cuts, {colors, d, area})` | 几条斜色带从左往右扫，切点那一刻最后一条正好盖满 `area`，之后扫出右边；默认 0.66 秒 |

例（黑底科技模板里，前两次换场故障、第三次推移、一直飘光点）：

```js
const CUTS = TL.shots.slice(1).map((s) => s.start);
function fxBefore(t) { const p = 动效.push(t, [CUTS[2]]); if (p) 动效.shift(g, p); }
function fxAfter(t) {
  动效.particles(g, t, { kind: '光点', n: 50, color: '#e5cf95' });
  动效.glitch(g, t, CUTS.slice(0, 2), { colors: ['#e5cf95', '#b1312a'] });
}
```

- 画布变量：复古报刊、立体卡通的模板里 `g` 是 `let`，在 render 里会被换成主画布，照样写 `g`。颜色要写成 `#rrggbb`（粒子的光点贴图要拆色）。
- 模板自己有的换场效果（v1.3 起是各套的默认转场，开关和切点表见风格卡「默认动效（v1.3）」）和你自己加的转场别叠在同一个切点上：先把那个切点的默认转场关掉。
- `pageTurn` 只有切点那一帧整屏盖满；场景要在切点换内容，判断「过没过切点」用 30 帧的真实时间 t，别用定格取样后的时间（复古剪纸的定格每秒 15 张，取样后的 t 会晚半帧，对不齐）。【v1.3 复古剪纸】
- `paperCover` 的纸片退场是往下掉，会穿过字幕带；复古剪纸 v1.3 在页面里自己写了只盖到 y 905、往上撕走的版本（`coverCut`），要用可以照抄。
- 实测（v1.2 自检）：黑底科技、复古剪纸、手绘笔记 3 个模板各叠一段调用，Token 时间线出 21 张静帧都不报错，灯管字、光点、故障、推移、翻页、纸片掉落拼字 + 定格、纸屑、纸片盖屏、擦除、粉笔灰、摇摆和闪烁都看得到；霓虹赛博实测页用了故障、推移、雨、泛光、扫描线、灯管字（`styles/霓虹赛博/风格卡.md`）。
