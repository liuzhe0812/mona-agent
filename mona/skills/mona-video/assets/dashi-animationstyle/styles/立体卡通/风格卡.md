# 立体卡通（S35）

炭黑底 + 右侧点彩钴蓝光晕，物件是带颗粒渐变、光从左上来的「立体卡通」（光面胶囊、小球、管子、戴橡胶手套的手），外面套一层杂志内页的白细线分栏。适合讲科学原理、实验和操作、「拿工具处理某样东西」的过程；不太适合温情故事、需要大段文字的内容、要求明快浅色画面的场合。

## 看起来什么样

- 参考的是一张杂志内页的立体卡通科学插画（戴手套的手拿修枝剪剪 DNA）：炭黑底（不是纯黑），右侧一大团钴蓝光晕，边缘是点彩颗粒，不是平滑渐变。
- 物件都用带颗粒的柔和渐变做体积，光从左上来，暗面边上有一道浅色反光；没有黑描边。
- 颜色少而亮：一堆绿、手套的浅蓝和薄荷绿、刀刃和小球的银、把手的藏青，外加一点黄。
- 叶子沿叶脉一半亮一半暗，草叶细长，有带白色小球的细茎（蒲公英种子）。
- 外面一层杂志版式：1 像素白色细线分栏、左栏白方框里一个细体数字、竖排细体大字母、左边缘黑圆页码、页眉小字、右线旁竖排署名；插画会压到这些线上。
- v1.3 起背景不是死的：光晕慢慢呼吸漂移、光晕里的点彩网点闪、两圈杂志细线轨道上有小球绕着转、远处几颗糊的光面球往上飘、右下蒲公英放种子（见「默认动效（v1.3）」）。

**挑哪两个词当 A / B**（v1.1）：这段话的两个核心名词——观众看完要记住的那两个概念，最好在字幕里出现 2 次以上、画面里会反复露面；两个最好是一对，A 给先出场、更重要的那个（Token 例子：成都 / 旅行；观众实测：窗口 / 模态）。字幕里按字面精确匹配，「多模态」这类包含关系怎么标见下面「字幕区」。

## 构图和版式

- 插画区固定在细线框里：x 232–1856、y 92–905（`ART`），镜头焦点是插画区中心 (1044, 498.5)；物件可以压到线上。
- 左栏（x 64–232）：白方框编号 + 竖排细体大字母，按章节换（Token 例子：1 PROMPT、2 TOKEN、3 DATA、4 INTENT），换章时旧字母依次往上滑走、新字母从下面滑进来。
- 页眉线上左边标题、右边小字；右线旁竖排署名；左边缘黑圆页码。左下、右下两丛草，开场长出来、之后轻轻摆。
- 标注用杂志写法：白色实心圆点 + 兰亭黑特粗大字，旁边一行苹方细体小字，从左往右擦出；要指向时用 2 像素白细线。底部 175 像素是字幕带。
- 层次（v1.3）：底图 → 背景动效（裁在插画区里）→ 杂志框 → 场景 → 默认转场（只盖插画区）→ 草丛 → 字幕带 → 全画面颗粒 → 字幕字。转场不盖杂志框、左栏和草丛，看起来是「插画那一块」在换。

## 动效和节奏

- 物件出现 outBack 弹出 0.38–0.5 秒（`popS` / `popA`）；标注从左往右擦出 0.35–0.45 秒。
- 镜头 inOutCubic 0.5 秒左右；`camTrack` 的缩放按对数插值，推近拉远更匀；「钻进某个东西」用加速推近；慢镜头用正弦推近。
- 动作卡 `TL.mark()` 提前 0.03–0.12 秒；打字用 `TL.chars`；物件停住时轻轻浮动（正弦）。
- 挑静帧的秒数：取关键词开始说之后约 0.3 秒（v1.1，观众实测：逐字出现的字要这么久才写完；4.95 秒只写出「失」，5.15 秒才是「失忆」）。
- v1.3：每个镜头都在慢推或推近再拉开（示例页每段场景有自己的镜头关键帧：`CAM_A` 1263 行起、`CAM_T` 898、`CAM_D` 1060）；停住的东西轻轻浮（Token 块、胶囊、行李箱、横档）；打勾章砸下时震屏一次（`SHAKE`，0.22 秒、10 像素）。
- 这套的转场要像「立体物件会发生的事」：**物件滚出画面、镜头拉远换景、圆形遮罩缩放、光面块翻转**。`动效部件.js` 里的故障撕裂（屏幕类）、纸片掉落 / 翻页（纸类）不像这套的材料，别用；粒子可以用光点，颜色写钴蓝或银（`#rrggbb`）。

## 默认动效（v1.3）

`模板.html` 里加的，换任何时间线都自动生效（按 `TL.shots` 排，不写死秒数）。

- **开关**：第 28 行 `const FX_DEFAULT = true;`。改成 `false` 就回到 v1.2 的样子（实测 Token 时间线 2.5 / 9.4 / 17.0 秒三帧和 v1.2 模板逐字节一致）。写在 `fxBefore` / `fxAfter` 里的调用开不开都照常生效。
- **背景 4 层**（`drawBackFX`，631 行；贴图在 `initDefaultFX`，613 行）：画在杂志框之前、裁在插画区里，不进字幕带。
  1. 钴蓝光晕：底图那团光上再叠一张半分辨率的点彩光团（只算一次），透明度 0.32 ± 0.2 呼吸（约 7 秒一次），中心 ±110 / ±60 像素慢慢漂（13–18 秒一圈）。
  2. 点彩网点：光晕里 90 颗 2–4 像素的钴蓝 / 浅蓝小方点，每秒换 6 次亮暗、往左上慢漂（单点很小，不算闪光）。
  3. 杂志细线：两圈 1 像素虚线轨道（虚线在走），各有一颗小银球 / 小绿球绕着转；页眉线下一排刻度往右慢慢走。
  4. 远景：8 颗糊一点的半透明光面球往上飘（远的小、慢、淡，视差）；右下那棵蒲公英每 2.4 秒放出一颗种子往左上飘，7.5 秒淡掉。
- **镜头交界的转场**（`drawCutFX`，697 行）：`FX_CUTS`（608 行，默认每个镜头的 start；两个交界离得不到 0.8 秒只转第一个）按 `FX_KINDS`（607 行）轮换，每种的前后时长在 609 行。都在切点那一刻把插画区盖满：
  - `圆形遮罩`：插画区里一个圆收成一点再张开，圆外是背景，圈边是银色立体管（切点前 0.3 秒、后 0.35 秒）。
  - `翻板`：一块藏青光面板绕横轴翻进来盖住插画区（翻进来减速），切点后翻过去（背面带一点绿，看得出翻了面）（前 0.28、后 0.3 秒）。
  - `滚球`：大银球（绿色条纹跟着转）从左滚到右，滚过的地方盖回背景，切点后背景淡开露出新镜头（前 0.42、后 0.32 秒）。
  - 只想在大段落转场：把 `FX_CUTS` 改成那几个镜头的 start；只用两种：改 `FX_KINDS`。不闪白，1 秒内不会有 3 次闪光。
- **每个镜头慢推 + 横移**（`fxCamDefault`，669 行）：整个镜头里一直慢慢推近（最多 1.08 倍，约每秒 0.8–1.5%，短镜头推得少）、同时从左往右移最多 80 像素；切点被转场盖住，看不出跳回去。
- **setCam 乘上了 `SCENE_BASE`**（587–588 行）：render 里先做默认慢推、再调 `fxBefore`，然后取当前变换当 `SCENE_BASE`，场景里 `setCam(…)` 都乘上它。所以 `fxBefore` 里的 `动效.push` + `动效.shift`、`动效.shake` 在这套模板里也起作用了（v1.2 时会被场景的 `setCam` 盖掉）。
- 骨架（换内容时会删）也跟着改了两处：开了默认转场的切点，上一屏在切点直接收掉（不再跨过切点淡出）；胶囊弹出停住后轻轻浮。
- **自己写场景时注意**：
  - 上一镜头的东西在下一镜头 start 那一刻就收掉，别跨过切点淡出——转场在切点盖满插画区，跨过去会在转场揭开时和新镜头叠在一起。
  - 用 `setCam` 画的东西自动跟着慢推；直接用屏幕坐标画的（不调 `setCam`）不跟着推，要推就自己乘。
  - 自己在场景里做了更合适的转场（例如示例页的「芯片里开圆洞」「数据墙拉远」），就把那个切点从 `FX_CUTS` 里拿掉，别两种叠在同一个切点上。
  - 镜头拉远换景要知道场景里有什么，模板没法默认做；照示例页的 `CAM_T`（898 行，5→6 拉远）、`CAM_D`（1060 行，数据墙从 1.3 倍拉到 1 倍）写。
- **实测**（v1.3 自检）：通用时间线（33.6 秒、4 个镜头，骨架）出片丰富度 11.1、Token 时间线（21.2 秒、8 个镜头，骨架）13.0，都判「过」、最长静止 0 秒；关掉默认动效时分别约 5.8、7.5（按同样算法用静帧估的，不过）。渲染 86–88 毫秒/帧（jpeg，机器上同时有别的渲染，负载 15–25）。先 seek 后面再 seek 前面、和单独 seek，PNG 的 md5 一致。注意：骨架本身东西很少，丰富度主要靠默认动效撑着，刚过线；写了真正的场景（每 2–3 秒有新东西进场）才会高（示例页 41.6）。

## 字幕区

- 底部 y 905–1080 字幕带（`#262527`），上沿一条 1.5 像素半透明白线（x 64–1856，也是杂志框的下边线）。
- 苹方 Semibold 64 像素白字，中心 y=990；A/B 胶囊高 76、左右各多 8 像素。
- 不自动换行，一条最多约 25 个字。全画面颗粒盖在字幕带之上、字幕字之下，字保持干净。
- `?nosub=1`（`render.mjs --no-subtitle`）时（v1.3）：字幕字和字幕带都整块不画，底部露出背景；杂志框下边线照画（框是闭合的）；画面里的东西（场景、草丛）裁在 905 以上，不会露到底部。画字幕带时不裁（带子盖着；裁了草叶的抗锯齿会和 v1.2 差一点）。
- 字幕关键词：两层叠着标——`字幕强调` 是字下面的绿管，`高亮` 是红 / 蓝胶囊，两个可以同时在一个字上；`字幕强调` 写「多模态」时，三个字下面都有绿管、「模态」同时是胶囊。
- 换条不「眨」：紧接着上一条的字幕直接换字（`subIn`），只有第一条、和上一条中间有空档时才淡入 0.08 秒。模板 v1.1 起这样；`示例_Token.html` v1.3 起也这样（以前为了和原样片逐字节一致没改，换条那一帧字幕是空的或很淡）。

## 质感和渲染速度

- 背景（点彩光晕 + 四角压暗）逐像素算一次；颗粒是 960×540 噪声图，每帧放大到全屏、叠加模式 0.3 盖上；手套、剪刀、图标、芯片、面板、远景小球都是一次画好的贴图；v1.3 动的那层光晕也是一次算好的半分辨率贴图，每帧只挪位置、改透明度。
- 满屏颗粒让 PNG 编码很慢：PNG 281 毫秒/帧，同一段 jpeg 108 毫秒/帧（样片当时的负载）。**一定加 `--format jpeg`**（`新建作品.mjs` 已经写进 `作品.json`）。
- v1.3 实测（背靠背渲，jpeg；机器上同时有别的渲染，负载 10–44）：示例页旧版 83 / 87 毫秒/帧（测了两次），新版 95（带字幕）/ 102（无字幕）毫秒/帧，慢 10–20%；页面多画的背景动效每帧几毫秒。成片因为一直在动，文件从约 20 MB 变成约 47 MB（21 秒、crf 18）。

## 踩过的坑

1. 满屏颗粒让 PNG 截图慢到 281 毫秒/帧，jpeg 只要 108：出片一定加 `--format jpeg`。（我们做样片时实测）
2. 半秒内的叠字：7.7 秒 AI 芯片压在淡出的「提示词 Prompt」上（芯片挪到标注右边，见示例页 738 行注释）；17.95 秒两条标注交叉淡入淡出（改成先收再出）。v1.3 又碰到两处，同一个原因（换场时两层东西同时在画面里）：芯片滚进来时标注还没淡完（改成标注 0.15 秒收完、芯片晚 0.06 秒滚进来）；13.8–14.1 秒立体字「Token」还没淡完数据墙已经上来（改成标注先缩小收完、数据墙晚 0.06 秒上来）。规律：**下一层进画面之前，上一层先收完**。
3. 兰亭黑只有 Extralight / Demibold / Heavy 三档，只给 900 的标题用，正文交给苹方，免得掉到细体。
4. 剪刀 7 刀只有 0.54 秒、握剪刀的手大半在画面上沿外面；新内容里关键动作别太快、手和工具要整体进画面（v1.3 剪刀伸进来时镜头拉开到 0.92，手进了画面）。
5. 数据层前后两层填充太密，手机上看偏「花」；新内容的背景层要少、要暗。
6. 画面和 seek 的先后有关（v1.3 修）：旧示例页先 seek 20.9 秒再 seek 7.6 秒，和单独 seek 7.6 秒画出来不一样（杂志框线头、草叶边差几个像素）。原因是画布的 `lineCap` / `lineJoin` 这些状态会从上一帧带过来，有的线没自己设线头就用了上一帧留下的。改法：`render` 开头 `g.reset()`（再把线头、透明度、混合模式这些显式设一遍）；离屏画布（数据层 `DCX`）每帧也 `reset()`。验法：`--stills 20,5` 和 `--stills 5` 出的 5 秒那张 md5 要一样。
7. 「推断」标注原来在箭头上方，正好在成都、旅行两块飞下来的路上，19.3 秒叠在一起；两块飞的时候旅行先走、成都后走，路线交叉也叠在一起。v1.3：标注挪到箭头下面，飞得远的成都先走。
8. 用 `setCam`（直接 `setTransform`）的场景会把 `fxBefore` 里设的推移、震屏盖掉——v1.2 模板里 `动效.push` + `动效.shift` 在这套不起作用。v1.3 模板让 `setCam` 乘上 `SCENE_BASE`（见「默认动效」）。
9. 只在 `--no-subtitle` 时把画面裁到 905 以上：一直裁的话，裁剪会让草叶的抗锯齿和 v1.2 差 1–4 个色阶（虽然看不出来，但关掉默认动效就不再和 v1.2 逐字节一致）。
