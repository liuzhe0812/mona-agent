# 海报与旅行：从具体案例选择设计方向

这些卡片依据上游实际案例 prompt 提炼；示范均更换主题重新编写。来源用于追溯，不要求运行时访问网站或下载图片。图片案例不能证明相同 prompt 能稳定复现，下面的卡片也未经过同模型出图对照。

| 卡片 | 机制 | 优先用于 |
|---|---|---|
| c511 | 城市名作为承载地标的结构 | 字体与城市品牌同等重要的海报 |
| c497 | 单色水彩、建筑线描、步行视角 | 安静、文艺、有地方感的城市视觉 |
| c464 | 沿水岸展开的生活场景与编辑网格 | 城市生活、旅行叙事、暖色拼贴 |
| c345 | 黑白主体与撕纸色块形成印刷张力 | 文化活动、电影、人物专题 |
| c355 | 字形通过一个隐喻表达标题含义 | 短标题驱动的概念海报 |
| c359 | 识别轮廓内外的双重叙事 | 有人物身份和相关故事的海报 |

比例、颜色、文字和元素数均按当前任务调整。保留机制不等于复制示例的每个装饰。完整案例适合常规读取，不要只取其标题或“高级”之类形容词。

## c511 — 字形承载城市

来源：[case 511：城市名地标排版旅行海报](https://github.com/freestylefly/awesome-gpt-image-2/blob/main/docs/gallery-part-2.md#case-511)。

**适用 / 不适用**：城市名是海报主要信息，文字允许融入画面时使用。纯场景配图、明确无字的 PPT 背景、要求纪实视点时不用。

**构图机制**：文字不是浮在风景上方的标题；字形本身分配城市景观的空间。建筑嵌入笔画或负形，交通与水系跨越字形连接景观，让多个地标读成一幅城市图。

**必须保留的锚点**：大字主导轮廓；地标与字形发生嵌入、穿越或支撑关系；有限色板和一致几何语言；文字可读。中文应保留字的关键识别笔画，不能机械套用拉丁字母窗口结构。

**可替换变量**：城市与标题语言、地标、水岸或山地关系、交通细节、品牌色、横竖排列。用少数地方性细节替代通用城市图标；不能随意把相距遥远的地标描述成真实同一视角。

**原创示范 prompt**：

```text
生成一张竖版武汉城市概念海报，让“武汉”两个汉字成为组织江城的建筑骨架。两字错位上下排列，保留关键笔画和足够字腔；黄鹤楼的屋檐局部嵌入“武”的横向结构，一段长江大桥连接下部空间，细长的江流曲线从字形之间穿过，形成连续阅读路径。仅选黄鹤楼、桥和渡船作为地方识别，不堆叠其他地标。这是概念组合，不表现为真实全景照片。
以平面几何建筑插画描绘主体，深靛蓝作为字形与江水底色，米白作为背景和字腔，砖红只点缀楼柱与船体；统一干净边缘和细小平面阴影。顶部和外围保留纸白，景物不能封死汉字结构。画面唯一可读文字为“武汉”，不得转成英文或拼音。不添加小标语、坐标、樱花边框、晚霞渐变、浮在字外的大段城市剪影或展示板。
```

**失败征兆**：变成“上方武汉标题＋下方黄鹤楼风景”；字形被填满无法识别；每个地标各自一套透视；仅换地名就能复用整张画面。

## c497 — 单色建筑水彩

来源：[case 497：单色水彩城市旅行海报](https://github.com/freestylefly/awesome-gpt-image-2/blob/main/docs/gallery-part-2.md#case-497)。

**适用 / 不适用**：文艺旅行、建筑文化、安静街景；适用于无文字的文档插画。要求强烈多色品牌视觉或刺激商业运动感时不选。

**构图机制**：前景街道的透视线把目光引向建筑；建筑细线与水彩洗染分工，纸白形成天空和呼吸空间。单色的明度变化统一不同材质。

**必须保留的锚点**：一个主色相；步行者高度的可信视角；线描建筑与透明水彩；大面积未着色纸面。可以按品牌把色相换成赭石或墨绿，不能保留“单色”同时堆砌多种彩色晚霞。

**可替换变量**：城市街段、建筑、街灯、人物与交通、题字、纸张色、画幅。远处地标仅在视点合理时加入；不确定就选局部街景。

**原创示范 prompt**：

```text
创作一张竖版武汉旅行海报，采用单色靛蓝水彩与细钢笔建筑线描。画面取汉口老街的步行者视点，雨后石板路从下方宽阔前景向中部街角收拢，两侧近代建筑立面形成透视引导；一位撑伞行人和一辆靠墙自行车提供日常尺度。选择局部街景，不把黄鹤楼或远处楼群硬插进同一街道。
建筑的檐线、门窗与街面由细线定义，水彩只承担体积、树影和湿地倒影；全画使用靛蓝深浅与自然纸白，不增加第二个彩色色相。左上保留完整纸白放置清晰的“武汉”，用细瘦的宋体气质处理标题；树冠洗染在右上边缘渐淡，边界保留自然水痕。除“武汉”外不添加可读文字、印章或水印，不使用饱和晚霞、塑料质感、花卉相框或整齐图标拼贴。
```

**失败征兆**：纸白消失；所有物体涂满同样深色；水彩只是照片上的滤镜；建筑与街道不共享视点。

## c464 — 城市生活与编辑拼贴

来源：[case 464：高雄水彩拼贴旅行海报](https://github.com/freestylefly/awesome-gpt-image-2/blob/main/docs/gallery-part-2.md#case-464)。

**适用 / 不适用**：强调人、交通、滨水生活与氛围的城市传播；无字资产可保留场景与材质机制。简洁标志或只需一件独立物体时不选。

**构图机制**：滨水步道形成斜向引导，近处生活动作连接远处城市；非对称标题区、半透明几何叠层和水彩消隐边缘将画面组织成一张编辑作品。

**必须保留的锚点**：至少一个有意义的生活动作；有空间连续性的主场景；明确的版面阅读区；纸面、色块和水彩有各自层级。不能把“拼贴”误解为许多不相干小图。

**可替换变量**：本地交通、人物动作、海港/江岸、标题、辅助信息、品牌配色。源案例中的年份、坐标、地名不是通用装饰，不要照搬或编造。

**原创示范 prompt**：

```text
设计一张竖版重庆城市生活海报，以傍晚江岸的一次等待为主题。前景是一位推着自行车停下看江的人，沿岸步道从左下斜向中部渡船停靠点，坡地建筑在远处层层上升。人物、岸线和建筑属于连贯的概念场景，用渡船与坡地关系体现山城，不拼贴全城地标。
左上以留白形成编辑标题区，只写“重庆”；右侧用建筑高度与细竖向几何色层回应版式。场景以细建筑线描和柔和水彩描绘，纸面边缘局部露白，半透明浅赭色块连接人物区域与标题区；青灰江面配合暖米白纸底，夕照只作为小面积反光。让骑行者、渡船和脚步方向承担生活叙事，不添加坐标、年份、说明小字、随机印章或画框。作品为一张完整海报，不是多张样机展示。
```

**失败征兆**：只剩一张全幅风景加标题；场景被切成无空间关系的碎块；装饰性的坐标和小字比人物更醒目。

## c345 — 撕纸印刷与黑白主体

来源：[case 345：法新浪潮撕纸电影海报](https://github.com/freestylefly/awesome-gpt-image-2/blob/main/docs/gallery-part-2.md#case-345)。

**适用 / 不适用**：电影、戏剧、音乐、人物专题；要表达先锋、粗粝或文化张力。洁净产品技术图、要求光洁数字视觉时不选。

**构图机制**：一幅显著的黑白人物影像与有限大色块产生张力；撕纸边缘、网点和套印偏移使这些区域成为同一印刷平面。

**必须保留的锚点**：黑白主角；有方向的大面积色块；可见物理拼贴边缘；标题参与裁切与层级；印刷质感覆盖全画而非最后加噪点滤镜。

**可替换变量**：人物动作、主题道具、标题和色板。背景碎片只提供与主题相关的叙事，不默认添加外国街景或无关报纸。

**原创示范 prompt**：

```text
生成一张独立戏剧海报，唯一标题为“停电之后”。主视觉是一位演员在暗处划亮火柴的黑白半身影像，偏上且向右裁切；左侧由一块粗糙撕边的暗红纸面形成压迫，右下保留米白纸底，火柴的短光痕连接人物与标题。标题使用紧缩、有重量的黑色字形，沿红色纸块边缘竖向排列，字与脸保持清楚主次。
所有区域采用模拟印刷质感：粗网点承接明暗、纸纤维出现在裸露边缘、套印仅有轻微偏移；局部煤灰蓝只用于一张断裂灯泡轮廓碎片，避免满版彩纸。人物姿态与道具解释停电时刻，不加入真实新闻剪报或无关街景。除标题外无可读文字，无相框、光滑三维字效、额外海报方案或过度做旧。
```

**失败征兆**：只有人物照加彩框；网点和纸边不可见；装饰碎片没有叙事用途；做旧程度掩盖主体。

## c355 — 标题自身的视觉隐喻

来源：[case 355：概念字体海报 Prompt](https://github.com/freestylefly/awesome-gpt-image-2/blob/main/docs/gallery-part-2.md#case-355)。

**适用 / 不适用**：短词、概念标题或主题需要作为主视觉。无字配图、长篇正文、不可变的品牌标准字不宜强制变形。

**构图机制**：字形、物体与空间通过一个动作表达标题含义；例如托起、穿过、遮挡、开裂、连接。不能用一个抽象名词配一圈装饰图标。

**必须保留的锚点**：准确且占主导的标题；一个能读懂的隐喻；有意设计的字重、间距或负形；物体与字发生真实空间关系。字形实验仍服从可读性。

**可替换变量**：标题、隐喻动作、支持物体、媒介与色彩；不从标题擅自推断人物资料或商业承诺。

**原创示范 prompt**：

```text
制作一张标题为“共振”的横版概念海报，标题就是画面主体。两个字以沉稳的粗笔画形成左右结构，一条薄而连续的铜色金属带从第一个字的内部穿过两字之间，再进入第二个字；细小重复的弧形阴影表现能量在同一条带上的响应。笔画保持清晰，“共”与“振”不能被装饰替代。
让宽阔的深墨绿色字面、暖纸白背景和铜色曲线构成主要层级，金属带只在穿出字面处出现有限高光，文字采用哑光印刷表面。留白集中于两字外侧，间距和弧线决定节奏。唯一可读文字是“共振”，不增加英文、口号、频率数字或图表刻度。避免通用音乐图标、彩虹渐变、悬浮立体字和与标题分离的装饰图片。
```

**失败征兆**：字旁边摆了一个象征物，但没有关系；为隐喻牺牲可读性；所有标题都被套成同一种三维字效。

## c359 — 轮廓内外的双重叙事

来源：[case 359：水墨双重曝光人物海报](https://github.com/freestylefly/awesome-gpt-image-2/blob/main/docs/gallery-part-2.md#case-359)。

**适用 / 不适用**：人物有可识别外形，同时有场景、记忆、行动可讲述。只因为题材是“中国城市”就选择本卡会误路由；单纯想要水墨表面可用其他卡或风格参考。

**构图机制**：上方大轮廓确定身份，内部场景提供故事，下方较小的同一人物把故事带回行动；墨色、雾气和负形连接三个尺度。

**必须保留的锚点**：识别轮廓；轮廓内的相关叙事；内外同一主体；从上到下的连续动线；由墨色渗化而非硬框拼接。

**可替换变量**：人物职业、外形、活动地点、关键道具、题字、色彩。真实人物身份按用户参考，不能从职业自动生成具体相貌。

**原创示范 prompt**：

```text
创作一张竖版人物主题海报，讲述一位虚构护林员巡视山林的故事。上半部用宽檐帽与侧脸构成清楚的大轮廓，轮廓内部不是面部花纹，而是一条穿过林地的巡护小径：细小的脚印与折断枝条引导视线向下。画面中下部出现同一护林员的较小全身背影，手持巡护杖迈向路径，帽形、衣服和背包前后一致。
以墨线确定帽檐和衣褶，淡墨晕染负责山林纵深，雾白连接轮廓内部与下方地面；仅以低饱和松绿区分近处树冠。侧边保留纸白，人物轮廓是第一焦点，森林细节只作为故事层。无标题、可读文字、徽章、水印、硬边拼贴、仙侠光效或额外人物；不把整个背景填满树木。
```

**失败征兆**：只是普通水墨人像；内外人物身份不同；景物在脸上硬贴；多个同等大小的人物抢焦点。
