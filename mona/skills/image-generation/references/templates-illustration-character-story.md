# 插画、角色与叙事模板

按需读取 16–19 项：插画艺术、角色设定表、3D 收藏玩具和场景叙事。它们分别解决媒介笔触、身份一致性、参考图转玩具和可见事件，不要用泛化风格词替代构图与动作。

详细目录见 template-catalog.md；当前文件只包含本组条目，生成时按需读取相关条目即可。

## 16. 插画与艺术风格（illustration-art-style）

**适用场景**  
用于动漫、绘本、水彩、水墨、扁平插画、厚涂、装饰画和材料实验。适合封面、社媒图、叙事插图以及需要明显笔触或媒介感的 PPT 配图。

**视觉结构 / 构图**  
先确定主体、景别、视线和前中后景，再选择笔触与色彩。一个画面应有单一焦点和稳定的构图关系，背景细节服务主题，不要用一串风格名替代空间、动作和视觉层级。

**风格 / 材质**  
用可观察的特征描述风格，例如水彩晕染、厚涂笔触、平涂块面、细线稿、纸张纤维、赛璐珞阴影或柔和光晕。可以参考某类艺术传统，但优先写其色彩、笔触和构图特征，避免直接复制在世艺术家的具体画面。

**文字与标签策略**  
插画默认不放文字；若是封面，标题应少量、准确并与画面留白匹配。参考图任务要写清保留脸型、服装、主色或构图中的哪些特征，不要让模型自行添加说明牌、对话框和长段文字。

**关键约束 / 常见失败**  
常见失败是只写“某某风格”而没有构图、笔触混杂、默认塑料感、主体身份漂移和照搬参考作品构图。先锁画面结构与媒介，再补情绪和细节；同一张图只保留一套主要媒介语言。

**可组合提示词片段**

1. 以 [主体与动作] 置于 [近景、中景或远景]，明确前景、主体和背景的空间层级。
2. 使用 [水彩晕染、厚涂笔触或细线平涂]，让 [纸张、颜料或墨迹] 的可见材质贯穿全画面。
3. 采用 [配色与情绪]，保持单一艺术媒介和清楚焦点，不添加无关文字、图标或第二套风格。

## 17. 角色设定表（character-design-sheet）

**适用场景**  
用于角色概念设定、动作参考、动画/游戏设计和需要同一角色多姿态一致的视觉资料。适合人物设定页、动作分解板和教学参考图。

**视觉结构 / 构图**  
先锁身份锚点：脸型、发型、服装、比例、配件和标志色。若做动作表，明确网格行列与面板数量（例如四乘四），每格固定编号、短标题、完整姿态和方向箭头；若只做角色设定图，给主视图足够空间并避免把动作面板混进来。

**风格 / 材质**  
可选黑白线稿、灰阶 3D、漫画分镜或干净概念图，背景保持纯净，线条、光影和比例在所有面板中一致。服装材料如丝绸、皮革、机能面料或金属配件要明确，否则角色容易变成无质感的通用人形。

**文字与标签策略**  
每格只保留编号、动作名称和少量方向/关键点标签；需要说明时用短句，不把完整动作教程挤进格子。角色名称、服装部件和身份特征可锁定为准确文本，避免随机 lore、长对白和无关注释。

**关键约束 / 常见失败**  
常见失败是不同面板换脸换衣、动作数量过多、格线消失、面板合并、背景抢焦和新增角色。把“同一角色、同一服装、同比例”放在动作序列之前；画面拥挤时减少动作数量而不是缩小人物。

**可组合提示词片段**

1. 以 [角色身份、脸型、发型、服装和标志配件] 建立不可变的身份锚点，所有面板保持同一角色。
2. 用 [网格规格] 排列 [动作数量] 个姿态，每格固定编号、短标题、完整身体和方向轨迹。
3. 采用 [线稿、灰阶或概念图] 的统一线条与纯净背景，拒绝换装、换脸、复杂场景和额外人物。

## 18. 3D 收藏玩具（3d-collectible-toy）

**适用场景**  
用于参考照片转收藏公仔、潮玩角色、头像玩具、包装展示和高端 3D 商品图。适合需要保留人物身份又希望改变比例和材质的视觉任务。

**视觉结构 / 构图**  
主体通常居中、完整入镜，以三分之四角度或正面展示轮廓；大头比例、简化身体和底座/包装应在提示中分开说明。背景保持干净，接触阴影和轮廓光让玩具与地面或包装产生真实关系。

**风格 / 材质**  
使用哑光 vinyl、树脂、细腻涂装或高级收藏品表面，写清皮肤、头发、织物、金属和透明件的差异。光线用柔和棚拍、边缘高光和适度反射塑造设计感，避免廉价亮塑料和过度锐化。

**文字与标签策略**  
包装或底座只放姓名、系列名或一个短标签，确保字面准确。身份锚点应来自脸型、发型、表情气质和服装识别点，而不是依赖包装上的名字；不要要求模型在盒面排完整规格或故事。

**关键约束 / 常见失败**  
常见失败是变成通用玩具、身份相似度下降、脸部过度变形、包装文字乱码、多个角色混入和背景过于复杂。先锁身份与服装，再写玩具比例和材质；只保留一名主体并限制包装信息。

**可组合提示词片段**

1. 保留参考图中 [脸型、发型、表情和服装识别点]，把同一人物转成比例明确的高级收藏玩具。
2. 使用 [哑光 vinyl、树脂或细腻涂装] 表现皮肤、织物和配件差异，配合柔和棚拍光与真实接触阴影。
3. 让主体居中、背景干净、包装标签极少且准确，拒绝廉价塑料、多角色、身份漂移和水印。

## 19. 场景叙事（scene-storytelling）

**适用场景**  
用于故事场景、世界观设定、分镜、直播情境和需要一眼读出事件的情绪画面。适合 PPT 中的案例场景、品牌故事或章节转场图。

**视觉结构 / 构图**  
先写时间、地点、主角、正在发生的动作和冲突，再决定广角建立镜头、中景或特写。前景、中景和背景各放一条与事件相关的线索；如果是分镜，锁定面板数量和顺序，不让模型把多个镜头压成一张混乱场景。

**风格 / 材质**  
氛围、光线和色调应服务叙事：冷暖对比、长阴影、雾气、尘埃、雨水或环境纹理可以加强紧张和时间感。可以选择电影写实或插画概念风，但人物动作、环境状态和关键道具必须处在同一世界。

**文字与标签策略**  
故事图通常不需要大段文字；分镜只用编号、镜头标签和极短动作说明。对白或标题如果必须出现，应给出准确短句并限制数量，让视觉线索先于文字解释。

**关键约束 / 常见失败**  
常见失败是生成没有事件的幻想风景、背景细节与故事无关、冲突不可见和画面过度拥挤。至少写一个明确动词和一个可见后果；用低角度、倾斜镜头或近景等摄影语言强化事件，不靠随机特效制造戏剧性。

**可组合提示词片段**

1. 交代 [时间、地点和主角]，捕捉 [正在发生的动作] 这一瞬间，让冲突和后果在画面中可见。
2. 用 [广角建立、中景或特写] 安排前景线索、主体动作和背景环境，所有细节服务同一故事。
3. 采用 [情绪、光线和色调] 的叙事风格，避免无事件风景、无关道具和随机幻想装饰。
