# 历史、出版与概念研发模板

按需读取 20–22 项：历史古风、文档出版和概念产品研发拆解。它们分别依赖时代证据、版式网格和技术展示板结构；先锁准确性与结构，再增加材质和气氛。

详细目录见 template-catalog.md；当前文件只包含本组条目，生成时按需读取相关条目即可。

## 20. 历史与古风题材（history-classical-themes）

**适用场景**  
用于朝代人物、传统器物、诗词视觉、古风长卷、历史场景和文化主题海报。适合需要明确时代、服饰制度与礼制氛围的教育或叙事图片。

**视觉结构 / 构图**  
先选长卷、册页、单幅海报或电影式场景，再安排人物、建筑、器物和背景层级。人物的身份、动作和服饰是锚点，建筑、纹样、礼制和器物作为时代证据；长卷应有横向阅读路径，单幅画面应有明确主次。

**风格 / 材质**  
明确朝代与美术方式，如工笔、写意、水墨或影视写实，并补丝绸、木、漆、青铜、纸张、墨色等材料。色彩、发式、衣制、建筑和器物需服从同一时代，传统笔触可以和现代电影光结合，但不能变成泛化“东方风”。

**文字与标签策略**  
标题、人物名、地点或诗句只保留必要短文本；确需书法时提供准确原文并减少字数，不让模型自由生成长段古文。卷轴题签、印章或图例应有明确位置和数量，避免随机乱码。

**关键约束 / 常见失败**  
常见失败是唐宋明服饰混搭、现代物件进入古场景、建筑与礼制不符、泛化古风美女和多种文字系统混杂。先锁朝代、地域和身份，再写视觉风格；显式排除现代元素，并把历史准确性与艺术夸张区分开。

**可组合提示词片段**

1. 只采用 [朝代、地域和人物身份] 的服饰、建筑、器物与礼制，所有时代线索保持一致。
2. 让 [人物动作或主题事件] 成为主视觉，使用 [工笔、写意或影视写实] 和 [丝绸、木、金属或宣纸] 材质建立文化气质。
3. 只放置准确的 [标题、人物名或短诗句]，明确排除现代物件、混朝代服饰、随机印章和无关文字。

## 21. 文档与出版物（document-publishing）

**适用场景**  
用于白皮书、手册、杂志跨页、百科图鉴、报告页、菜单、报纸和企业画册的视觉稿。适合需要展示出版结构、页面节奏和图文关系的 PPT 或文档封面配图。

**视觉结构 / 构图**  
先锁页面尺寸、单页/跨页、栏数、页边距和标题层级，再安排封面、正文、图片、图表、表格和脚注。所有内容沿网格对齐，主图与标题有清楚的比例关系；企业画册可增加封面、内页、案例页和全册预览，但每一层都要保持同一系统。

**风格 / 材质**  
可用高端编辑、科学出版、现代商务或艺术化画册语言，建立衬线标题与无衬线正文的角色对比。纸张、印刷、浅色底、单色加一个强调色或克制的图片处理能增加完成度，避免普通 Word/PPT 默认感与过重装饰。

**文字与标签策略**  
只把主标题、章节名、图表标题、表头和短注释列为准确文本；正文用模拟文字块或短段落表示结构，不能承诺模型排出整页无错正文。字号层级、对齐和行距比文案数量重要，长文案放到真正的文档编辑链路。

**关键约束 / 常见失败**  
常见失败是密集小字、栏线不齐、图表与说明错位、随机正文、视觉层级混乱和只生成一张孤立海报。先定义网格、留白和内容模块，再补图片与材质；需要验证整套画册时明确要求封面、内页、案例页和联系方式页的统一预览。

**可组合提示词片段**

1. 以 [页面类型、尺寸和单页或跨页] 为边界，先建立 [栏数、页边距和标题层级] 的出版网格。
2. 让 [主图或图表] 与 [准确标题] 形成明确主次，正文使用轻量模拟文本块，所有说明和表头沿网格对齐。
3. 采用 [编辑、科学或商务出版] 的纸张与印刷质感，保留充足留白，拒绝密集小字、随机长文和普通文档感。

## 22. 概念产品研发拆解（concept-product-breakdown）

**适用场景**  
用于家具、装置、消费电子和其他产品的工业设计提案、研发评审、概念验证和材料展示。适合需要同时讲清灵感来源、形态演化、结构、人体工学和最终产品的技术视觉板。

**视觉结构 / 构图**  
中心放最终产品 hero render；左侧放灵感观察、轮廓提取和受力/纹理分析；中部展示三到五步形态迭代；下方验证尺寸、姿态和使用场景；右侧做结构爆炸、内部骨架和材料分层；底部放表面、颜色和关键规格。每个区域只承担一种说明职责，中心产品保持最大权重。

**风格 / 材质**  
采用工业设计提案板的白色或浅灰背景，结合技术线稿、标注线、产品摄影和真实阴影。材料需要对应制造逻辑，例如外壳、软垫、面料、连接件、金属或透明件；整体可技术化，但不能牺牲产品比例、可制造性与使用感。

**文字与标签策略**  
使用短标题、编号、尺寸、角度、材料名和关键规格，标注线要指向正确部件。每个阶段只保留必要标签，不把设计哲学和研发说明写成长段；精确尺寸、材质和功能词应由用户提供并作为硬文本。

**关键约束 / 常见失败**  
常见失败是只画一张漂亮产品、缺少迭代和结构、标签挤满画面、爆炸关系不可信、人体工学缺失或灵感特征消失。先定义完整板的区域与数量，再添加材质和视觉风格；要求产品看起来可制造、可使用，并保持同一产品跨视图一致。

**可组合提示词片段**

1. 把 [灵感来源] 转译成可制造的 [产品]，中心展示最终形态，周围依次呈现观察、迭代、结构和使用验证。
2. 使用白底工业设计提案板语言，把技术线稿、真实材质、爆炸关系和产品摄影沿清楚网格组织。
3. 每个区域只保留短标题、尺寸和材料标签，确保结构可解释、产品跨视图一致，避免只给成品渲染或文字拥挤。
