# 空间与摄影模板

按需读取 13–15 项：建筑与空间、写实摄影和街头意外瞬间摄影。选择它们时先锁投影或摄影机位、主体状态、光线方向和材质证据，再决定写实程度。

详细目录见 template-catalog.md；当前文件只包含本组条目，生成时按需读取相关条目即可。

## 13. 建筑与空间（architecture-space）

**适用场景**  
用于室内效果图、建筑表现、城市地图、空间规划、环境概念和地产或设计提案。需要区分“可沉浸的空间渲染”和“带地标与标签的地图/规划图”两种输出。

**视觉结构 / 构图**  
空间渲染先锁人眼高度、镜头视角、空间功能和动线，再安排门窗、家具和主要材质。地图或规划图应说明俯视/等距视角、地标相对位置、边框、标签和比例；两者都要有前中后层级，不能让背景吞掉主体。

**风格 / 材质**  
明确木、石、金属、玻璃、混凝土、织物等真实材料，再选择自然光、人工照明、日景或夜景。室内可用冷暖光对比增强空间深度，建筑表现强调真实阴影、反射和尺度，地图则可转向纸张、线稿或低饱和图谱质感。

**文字与标签策略**  
纯空间渲染通常不需要文字；地图和规划图才加入地标、道路、区域名和方向标签。锁定标签语言、数量和相对位置，使用短名词，避免模型自行编造楼层说明、街道名称或图例。

**关键约束 / 常见失败**  
常见失败是广角透视变形、动线不合理、结构悬空、材料混乱、地图标签错位和建筑比例失真。先写视角和空间尺度，再写风格；对地图应明确“示意”或“相对准确”的要求，不把概念效果图误当工程图。

**可组合提示词片段**

1. 以 [空间功能] 为中心，使用人眼高度的 [视角] 展示清楚的入口、动线、尺度和主要空间关系。
2. 让 [木、石、金属、玻璃等材料] 在 [自然或人工光线] 下呈现可信反射、接触阴影和冷暖层次。
3. 若为地图，只保留 [地标与区域标签]，锁定语言、相对位置和等距或俯视视角，避免透视变形与虚构细节。

## 14. 写实摄影（realistic-photography）

**适用场景**  
用于人像、街拍、商品摄影、电影感场景和需要可信摄影参数的 PPT 素材。适合把主体、镜头、光源、景深与真实细节一起交给模型。

**视觉结构 / 构图**  
先写主体与动作，再写地点、机位、镜头焦段、光源方向和景深。35mm、50mm、85mm 等焦段分别服务环境、自然视角和肖像压缩；明确前景、背景虚化、裁切和视线方向，避免只写“真实”。

**风格 / 材质**  
可选纪实、电影感、商业棚拍或胶片质感，但要补肤质、材质、颗粒、反射和空气感。真实人像可以保留毛孔、雀斑、轻微汗水或不完全对称；商品摄影强调表面粗糙度与边缘高光，避免过度磨皮和塑料感。

**文字与标签策略**  
摄影图默认不加入文字、水印或随机品牌；商业商品若必须出现标签，只锁定少量准确字样。把镜头参数、动作和场景写成视觉约束，把长文案交给版式工具，避免让画面同时承担摄影和出版排版。

**关键约束 / 常见失败**  
常见失败是皮肤过度平滑、灯光方向不一致、景深与焦段不匹配、手部和反射异常、背景过于棚拍或画面太完美。用具体参数和可见瑕疵替代泛泛的“高清真实”，并根据用途决定是否加入手部、结构或文字负面约束。

**可组合提示词片段**

1. 以 [主体与动作] 为焦点，使用 [焦段]、[机位] 和 [景深] 建立真实的摄影空间。
2. 用 [光源方向与时间] 描述阴影、轮廓光和背景层次，保留 [皮肤或物体材质] 的微小不完美。
3. 采用 [纪实、电影或胶片] 色彩，不加入随机文字和水印，避免塑料皮肤、假反射与过度棚拍感。

## 15. 街头意外瞬间摄影（street-accident-moment）

**适用场景**  
用于街头抓拍、液体泼洒、物品掉落、短暂碰撞和手机纪实画面。重点是让一个具体事件看起来刚刚发生，而不是摆拍广告或静态风景。

**视觉结构 / 构图**  
先写事件发生的动作和结果，再安排手持手机的略俯拍、低角度或自然偏移视角。前景痕迹、散落物、液体扩散、地面纹理和人物影子共同说明因果关系，背景保留适度街头杂乱以建立尺度。

**风格 / 材质**  
采用 raw phone photo 的自然色彩、轻微运动模糊、真实曝光和不完美取景。粗糙石砖、湿地、皱纸、灰尘、冰块或织物应有具体纹理；拒绝插画、CGI、棚拍光和过度干净的产品图质感。

**文字与标签策略**  
默认不出现品牌文字、水印、海报标题或额外说明。路牌、包装或现场标志只有在叙事必须时才保留，并限制为少量可读字符；让材质痕迹和动作承担信息，不让字幕解释事件。

**关键约束 / 常见失败**  
常见失败是液体像假贴图、物体漂浮、场景过度干净、动作停滞、光线戏剧化或构图像广告。明确事件前后关系、重力方向、接触点和真实影子；避免增加无关品牌与装饰。

**可组合提示词片段**

1. 捕捉 [具体意外事件] 发生后的瞬间，让 [液体、碎片或褶皱] 清楚呈现动作结果与重力方向。
2. 使用略带手持偏移的手机视角，在 [街道环境] 中保留自然杂乱、粗糙表面和符合方向的阴影。
3. 采用未经修饰的纪实色彩与轻微运动模糊，禁止 CGI、棚拍、漂浮物、广告构图和随机水印。
