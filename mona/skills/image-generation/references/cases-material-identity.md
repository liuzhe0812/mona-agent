## c373 · 高端肉类海鲜品牌英雄图

**来源标题：** 高端肉类海鲜品牌英雄图（`cases.json` id 373；来源 @xpg0970）
**来源：** [gallery-part-2.md#case-373](https://github.com/freestylefly/awesome-gpt-image-2/blob/main/docs/gallery-part-2.md#case-373)

**实核主题：** 原始 prompt 是一个可填充的高端食品品牌英雄图 brief，要求先定义品牌名、标语、主色、字体、台面、背景、光线，再定义单一主产品的数量、摆放、展示方式和质感。重点是产品材质与商业主视觉的关系，不是泛化的“美食照片”。

**适用：** 一个商品需要成为广告或电商页面唯一主角，肉质、玻璃、金属、液体、纸盒等材质本身是卖点。
**不适用：** 需要同时展示多个品牌触点、复杂菜单或完整信息图的任务；也不适合用户要求自然抓拍的纪实照片。

**具体视觉机制：** 让单一产品占据最大视觉权重，使用有质感的台面建立接触关系，用一套明确的主光和轮廓光区分材质；品牌短标签只做识别，不与产品争夺焦点。背景、道具和留白都服务产品轮廓与包装正面。

**必须保留的设计锚点：**

- 一个明确的主产品、明确的展示角度和真实接触阴影；
- 可观察的材质差异，以及同一方向的主光、反光和暗部；
- 若任务需要品牌名或短标签，明确其准确位置，包装/标签正面无遮挡；无字素材不添加额外品牌文字；
- 少量陪衬道具和干净的标题留白，不能把英雄图变成货架陈列。

**可替换变量：** 品牌名与短句、产品类别和数量、包装形状、台面材质、背景色、主光方向、镜头景别、标签是否出现。

**完整原创示范 prompt：**

```text
为高端香氛蜡烛品牌“暮潮”制作一张 3:4 竖版商业英雄图。只突出一只琥珀玻璃蜡烛，蜡面细腻、灯芯微燃、玻璃边缘有真实反光；产品立在深灰石材台面上，旁边只放一枝干燥海蓬子。用左侧柔和聚光和窄轮廓光区分玻璃、蜡与石材的粗糙度，背景为克制的深蓝灰渐变。标签只保留“暮潮”和“潮汐 01”，正面清晰无乱码；主体约占画面三分之二，上方保留留白。避免多件产品、塑料质感、过度反射、杂乱道具和水印。
```

**失败征兆：** 商品被道具或大段文案压住；玻璃、蜡、石材看起来是同一种塑料；标签变形或出现随机品牌；光源互相矛盾；画面像多商品目录而没有唯一焦点。

## c362 · 抹茶品牌触点系统视觉板

**来源标题：** 抹茶品牌触点系统视觉板（`cases.json` id 362；来源 @Preda2005）
**来源：** [gallery-part-2.md#case-362](https://github.com/freestylefly/awesome-gpt-image-2/blob/main/docs/gallery-part-2.md#case-362)

**实核主题：** 原始 prompt 明确要求完整的品牌触点系统，而不是单张产品图：以抹茶饮品为 hero，延伸到外带杯、玻璃瓶、包装盒、手提袋、标签、贴纸、封签、菜单和生活方式场景，并共享极简日式排版、绿色调和真实材质。

**适用：** 品牌提案、产品发布或 PPT 中需要一眼展示“同一品牌如何落到多种物料”的视觉板。
**不适用：** 只需要一张产品主图、需要逐字准确的大量菜单或报价表、或每个触点有不同艺术方向的任务。

**具体视觉机制：** 用一个最大面积的 hero 产品建立品牌世界，再用尺寸、排列和重复的图形规则把包装、容器、纸品和生活方式片段串起来；材质可以变化，但字标、色板、留白和图形符号必须贯穿所有触点。整体应像有层级的设计机构展示板，而不是随机物品拼贴。

**必须保留的设计锚点：**

- 一个明确的 hero 场景和有限的触点清单；
- 所有物料共享同一品牌名、主辅色、字形气质和图形符号；
- 触点按主次排列，有对齐线、间距和呼吸空间；
- 纸张、玻璃、织物、陶瓷等真实材质各有区别，文字只保留可验证的短标签。

**可替换变量：** 品牌名、核心产品、触点种类、色板、字标形状、图形母题、背景材质、展示板比例、需要出现的短文本。

**完整原创示范 prompt：**

```text
为虚构生活方式品牌“柚见”制作一张品牌触点系统视觉板，主视觉是一杯柚香冷萃茶：透明杯、浅金茶液和新鲜柚皮在柔和日光下清晰可见。以它为最大区域，周围按层级展示纸杯、玻璃瓶、外带盒、帆布袋、贴纸和一张小菜单。所有触点统一米白、柚黄、墨绿，使用同一窄体字标与半月图形，纸张、玻璃和织物保持真实质感；可读文字仅为“柚见”“柚香冷萃”“柚子清茶”，不添加价格或功效。版面整齐但有自然错落和留白，避免随机 logo、密集小字、风格割裂和杂乱拼贴。
```

**失败征兆：** 画面只剩一个产品；触点数量过多且没有主次；每件物料像来自不同品牌；字标、颜色或图形在各处变化；菜单小字成乱码；物料互相遮挡，缩小后无法看出系统关系。

## c346 · 立体刺绣小鸟花枝

**来源标题：** 立体刺绣小鸟花枝（`cases.json` id 346；来源 @dotey）
**来源：** [gallery-part-2.md#case-346](https://github.com/freestylefly/awesome-gpt-image-2/blob/main/docs/gallery-part-2.md#case-346)

**实核主题：** 原始 prompt 是浅浮雕纤维艺术插画：蚕丝白与奶白底色上，数只小鸟停在蜿蜒花枝，羽毛、花朵和叶片分别由不同颜色的细丝线、堆绣和层叠针脚表现，画面轻盈并保留大量留白。

**适用：** 需要把插画主题转成可触摸的手工材料语言，或需要柔和、精致、静态装饰感的封面和配图。
**不适用：** 需要写实摄影、锐利工业材质、复杂文字版面或动作事件优先的任务。

**具体视觉机制：** 让布面成为统一的底，使用针脚方向和堆叠高度塑造主体，不靠泛泛的“手工感”形容词；主体枝条提供流动路径，少量花叶形成次级节奏，浅浮雕阴影和大面积留白共同保持轻盈。

**必须保留的设计锚点：**

- 可见的布面、丝线方向、针脚边缘和浅浮雕高度；
- 一条主枝或主线组织主体，鸟/植物与枝条有明确停靠关系；
- 主体、花叶和底布使用有层次但克制的配色；
- 留白和柔和侧光必须存在，不能变成平面矢量或光滑 3D 塑料。

**可替换变量：** 动物或植物主题、底布颜色、丝线色板、针脚密度、主体数量、构图方向、浮雕强度、是否加入边框。

**完整原创示范 prompt：**

```text
生成一幅以“雨后荷塘”为主题的立体刺绣纤维艺术插画：一只青蛙停在弯曲荷梗上，几片荷叶和两朵未完全开放的荷花围成轻盈的斜向构图。使用深靛蓝布面作底，青蛙以苔绿和浅金丝线表现，荷叶用不同方向的绣线压出叶脉，花瓣采用层层堆绣形成浅浮雕边缘；侧面柔光只强调针脚高度和细微阴影，周围保留大面积安静留白。画面无文字、无边框装饰、无塑料光泽、无平面渐变和水印。
```

**失败征兆：** 只有刺绣风格滤镜却看不见针脚；所有对象同样平整或同样凸起；底布和主体材质混为一体；枝条失去引导作用；色彩过多、背景填满，最终像普通数字插画。

## c347 · 4×4 动作分解参考表

**来源标题：** 4×4 动作分解参考表（`cases.json` id 347；来源 @oggii_0）
**来源：** [gallery-part-2.md#case-347](https://github.com/freestylefly/awesome-gpt-image-2/blob/main/docs/gallery-part-2.md#case-347)

**实核主题：** 原始 prompt 指定灰阶 3D 角色、白底、4×4 共 16 格、细黑边框、1–16 编号，并要求每格都有同一角色的全身姿态、短标题、动作说明和方向箭头；它是动作参考表，不是 16 个不同角色的海报。

**适用：** 角色动作设计、游戏/动画参考、教学分解或需要横向比较一组姿态的任务。
**不适用：** 需要丰富场景叙事、每格不同角色或需要大段可读说明的页面；格数不可压缩时也不适合塞入复杂服装细节。

**具体视觉机制：** 固定网格和统一视图给角色建立比较基准，先锁定身份锚点，再让动作、重心和箭头成为每格的差异；纯净背景与一致光影避免把动作信息误读为场景变化。

**必须保留的设计锚点：**

- 明确的行列数、格线、编号顺序和统一面板尺寸；
- 同一角色的脸型、发型、服装、比例和配件在用户要求的所有面板中保持一致；
- 每格完整呈现身体，动作差异由姿态和少量方向箭头表达；
- 灰阶/单一媒介、白底和短标签，不能让背景抢走动作信息。

**可替换变量：** 角色身份、服装和道具、网格行列、动作序列、箭头类型、标签语言、线稿或灰阶 3D 媒介、是否保留说明栏。

**完整原创示范 prompt：**

```text
制作一张三列两行的灰阶角色动作参考表，共六个等大面板，白底、细黑边框，编号从 1 到 6。所有面板使用同一名穿短款防风夹克的城市快递员：同一张脸、短发、背包、鞋和身体比例。每格完整展示全身，按阅读顺序分别表现起步、急停、转身、跨台阶、递件、回头观察；对应短标签准确写为“起步”“急停”“转身”“跨台阶”“递件”“回头”，配清晰的方向箭头。采用统一的 3D 灰阶光影，人物尺度和地面基线一致；禁止换脸、换装、缺格、多格、额外人物、复杂场景和长段文字。
```

**失败征兆：** 网格合并或缺格；同一角色在不同格子换脸、换装、变比例；脚或道具被裁掉；箭头方向与动作不一致；标签过长导致乱码；背景变成故事场景并抢走参考表功能。

## c378 · 高端 3D 收藏玩具头像

**来源标题：** 高端 3D 收藏玩具头像（`cases.json` id 378；来源 @Genematicai）
**来源：** [gallery-part-2.md#case-378](https://github.com/freestylefly/awesome-gpt-image-2/blob/main/docs/gallery-part-2.md#case-378)

**实核主题：** 原始 prompt 要求把输入照片转成高端风格化 3D 收藏人物：头部略大、面部特征适度夸张但尽量保留身份，皮肤有细微纹理，整体为哑光 vinyl、柔和棚拍、干净黑底、居中全身和设计师玩具质感。

**适用：** 已有参考照片，需要在保留可识别特征的前提下转译成一名高级收藏公仔或潮玩头像。
**不适用：** 需要逐像素肖像复制、多人合影、写实环境人像或复杂包装信息的任务；若没有可用参考图，不应假装能锁定人物身份。

**具体视觉机制：** 先以参考图中的脸型、发型、眼镜、服装和姿态建立身份锚点，再用大头比例、简化身体和哑光材质完成玩具化；干净背景、接触阴影和轮廓光让它像真实收藏品，而不是普通卡通头像。

**必须保留的设计锚点：**

- 仅一个主体，正面或三分之四角度、完整入镜和稳定比例；
- 参考图中少量高辨识度特征与服装配件，避免增加身份无关元素；
- 哑光 vinyl/树脂、细腻涂装、柔和棚拍光和真实接触阴影；
- 背景干净、包装文字极少或不出现，不用文字弥补身份漂移。

**可替换变量：** 参考人物、保留的身份特征、头身比例、服装和底座、材质（vinyl/树脂/涂装）、背景色、视角、是否加入一条短系列名。

**完整原创示范 prompt：**

```text
使用参考照片中的同一位咖啡师，制作一尊高端 3D 收藏公仔：尽量保留其脸型、短卷发、圆框眼镜、轻微笑意和深绿色围裙这些识别特征，头部比例略大，身体简化但保持自然站姿与双手位置。材质为细腻哑光 vinyl，皮肤、头发、棉质围裙和金属咖啡勺有不同的粗糙度与反光；黑色无缝背景、柔和棚拍主光、窄轮廓光和真实接触阴影，居中全身入镜。只保留一个主体，禁止塑料亮光、多人、随机包装字样、面部过度变形和水印。
```

**失败征兆：** 只剩“可爱玩具”而看不出参考人物；脸部被夸张到失去关键特征；材质像廉价亮塑料；主体被裁切或混入第二个人；黑底出现随机文字；服装和配件被模型任意替换。

## c376 · 泼洒抹茶街头手机照片

**来源标题：** 泼洒抹茶街头手机照片（`cases.json` id 376；来源 @Shinning1010）
**来源：** [gallery-part-2.md#case-376](https://github.com/freestylefly/awesome-gpt-image-2/blob/main/docs/gallery-part-2.md#case-376)

**实核主题：** 原始 prompt 描写一杯绿色冰饮在户外石板路上被打翻的偶发瞬间：透明杯侧倒、杯盖和冰块散落、液体沿粗糙地砖扩散，午间硬光投下人的影子，采用略俯拍的手持手机视角和 9:16 纪实构图，并明确排除 CGI、棚拍和过度完美。

**适用：** 需要让一个事件看起来刚刚发生、带有偶然性和现场证据的纪实图、社媒图或报告插图。
**不适用：** 高级广告主图、产品包装精确展示、需要品牌 logo 清晰可读或需要完全可控摆位的静物摄影。

**具体视觉机制：** 用一个可见后果统领画面，再加入少量现场证据（液体轨迹、散落物、地面纹理、经过的影子）；手持视角、自然光、轻微不完美和不过度处理共同制造真实感，不能把事故整理成广告构图。

**必须保留的设计锚点：**

- 明确的偶发动作和可见后果，而不是摆拍好的物品；
- 真实地面/环境纹理、自然液体形态和符合光源的阴影；
- 手机视角、合理裁切、普通色彩和少量现场线索；
- 负面约束排除棚拍、CGI、过度锐化、漂浮物、复制物体和水印。

**可替换变量：** 事件主体、地面材质、时间和天气、手持角度、影子来源、画幅比例、现场散落物数量、是否需要隐藏品牌文字。
