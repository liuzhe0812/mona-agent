# 海报与 Campaign 模板

按需读取 4–8 项：单张海报、运动 Campaign、概念字体、水墨双重曝光和自然科普海报。它们共享成品级主视觉与文字层级，但不要把展示板、过程稿或多方案误当成单张成品。

详细目录见 template-catalog.md；当前文件只包含本组条目，生成时按需读取相关条目即可。

## 4. 海报排版系统（poster-layout-system）

**适用场景**  
用于活动、电影、产品、展览、章节封面和社媒传播海报。它是单张传播视觉的主路由，可按主题借用复古、未来、极简、电影感或编辑风。

**视觉结构 / 构图**  
先确定一张成品海报的主视觉、标题、副标题和画幅，再选择居中、左对齐、对角线或强裁切构图。主体与文字要形成明确的主次关系，预留足够负空间，让海报在缩小后仍能识别。

**风格 / 材质**  
风格服务主题而不是堆砌形容词：复古可用纸张、印刷颗粒和有限色板，未来主题可用清晰几何与受控光效，电影主题可用高反差光影。材质、背景和色彩数量要统一，避免一张图同时出现多种不相关的媒介。

**文字与标签策略**  
标题和必要副标题必须作为准确文本提供，字数越少越可靠。其他信息只留日期、地点、短口号或一个品牌标识；把层级写清楚，不能让模型自由添加大段说明、随机图标或第二个主标题。

**关键约束 / 常见失败**  
常见失败是生成 moodboard、网格展示板、拼贴过程稿而不是单张海报，也包括标题错字、主视觉不明确和装饰抢焦。明确“单张成品”、比例、主体位置和文字清单；若需求是字体海报、运动海报或自然科普海报，改用对应的第 5、6 或 8 项细化结构。

**可组合提示词片段**

1. 只生成一张完成度高的 [用途] 海报，以 [主体] 和准确的 [标题] 建立唯一主视觉。
2. 选择 [居中、左对齐或对角] 构图，保留聪明留白并让标题、主体和辅助信息形成三级层级。
3. 采用 [风格] 的受控色板与相应的 [纸张、印刷或光影] 质感，禁止额外方案、随机文案和杂乱拼贴。

## 5. 运动商业 Campaign（sports-campaign-poster）

**适用场景**  
用于运动员、健身器材、球鞋、服饰和运动品牌 Campaign。适合需要速度、力量、品牌色和可传播标题同时出现的广告画面。

**视觉结构 / 构图**  
先选单张强主视觉、三联画或数据涂鸦中的一种结构。运动员、核心产品或道具是第一锚点，球拍、哑铃、球鞋、球等可通过夸张比例、对角线或近景裁切承担构图骨架；动作方向应把视线带向标题或产品。

**风格 / 材质**  
使用高端运动广告的强光影、轮廓光、反光地面和干净背景。材质要能区分织物、橡胶、金属、皮肤和汗水；品牌色集中在服装、道具或局部光线上，避免大面积无意义渐变。

**文字与标签策略**  
大标题、短精神口号、日期或一项数据足够构成信息层。关键文案要准确、对比度足够，品牌名和标识只保留必要尺寸；不要让模型编写长广告正文或把数据标签散落在动作主体上。

**关键约束 / 常见失败**  
常见失败是错误运动器材、动作解剖异常、运动员变成背景、三联画互相割裂和促销文字过多。先锁项目、器材角度、动作和版式，再补光影；如果器材是识别重点，应单独写出尺寸、位置和朝向。

**可组合提示词片段**

1. 让 [运动员或产品] 以 [动作] 占据主导，并用 [器材] 的夸张角度形成画面斜向锚点。
2. 使用强方向光、清晰轮廓和真实的 [橡胶、织物或金属] 质感，维持统一的 [品牌色]。
3. 仅加入准确的 [主标题]、一条短口号和最多一个数据标签，保持背景干净、器材正确、动作可读。

## 6. 概念字体海报（conceptual-typography-poster）

**适用场景**  
用于标题、词语或短句本身需要成为视觉主角的概念海报、文化封面和展览视觉。适合文字的含义、语气和心理张力比具体场景更重要的任务。

**视觉结构 / 构图**  
只做一张成品海报，标题占据主要视觉结构。字形可以被人物、风景或物体穿过、遮挡、托起或切开；若标题指向知名人物，人物肖像可成为大面积锚点，但必须与字形互动而不是站在旁边装饰。

**风格 / 材质**  
字形应有定制感，明确字重、宽窄、间距、负形、边缘和墨迹节奏。采用四到六种相互协调的颜色，加上丝网、平版或孔版印刷颗粒、纸纤维和轻微油墨不均匀，避免光亮的默认 3D 字效。

**文字与标签策略**  
把必须出现的标题原样锁定，要求拼写、大小写、换行和语言不被替换。除标题外只保留极少必要信息；不要让模型自行加入解释文字、说明标签、口号或无关 logo。

**关键约束 / 常见失败**  
常见失败是通用字效、标题不可读、人物与文字脱节、生成多张方案或把海报变成 moodboard。明确“单张”、标题是唯一大字、图像必须服务标题含义，并限制色彩和装饰数量。

**可组合提示词片段**

1. 让准确的 [标题] 成为唯一主视觉，字形的重量、节奏、负形和边缘质感都表达它的含义。
2. 让 [人物、物体或环境] 穿过、遮挡或托起字形，把图像与标题连接成一个视觉隐喻。
3. 使用四到六色的克制印刷色板与纸纤维颗粒，只保留一张成品海报、必要留白和准确标题。

## 7. 水墨双重曝光海报（ink-double-exposure-poster）

**适用场景**  
用于诗意人像、品牌主理人、运动员、传统文化和带有东方气质的电影式海报。适合同时需要人物身份锚点与内在场景叙事的画面。

**视觉结构 / 构图**  
上方以放大的头部、面部轮廓或半身剪影建立识别，下方出现同一人物的完整或半身姿态。剪影内部嵌入与人物相关的场景、象征物或叙事片段，再用水墨扩散、云雾、飞白和负空间把上下两层连成视觉动线。

**风格 / 材质**  
把东方水墨的宣纸、墨色浓淡、晕染和飞白与克制的写实电影光结合。色彩宜少而有层次，边缘可以自然渗化，主体面部和轮廓仍需清晰；不要让奇幻特效覆盖真实材质。

**文字与标签策略**  
海报只需姓名、标题或一条短句，像题签一样放在留白处。必须出现的字应少量、清晰并与画面方向一致；不在剪影内部塞长说明、分段标签或多个大标题。

**关键约束 / 常见失败**  
常见失败是把两个画面硬拼、背景塞满、主体身份丢失和廉价武侠特效。内部叙事元素必须与人物有关系，双重曝光的边界要靠光墨过渡而不是硬边框；控制人物数量和装饰密度。

**可组合提示词片段**

1. 以 [人物] 的放大面部剪影作为上方识别锚点，并在下方保留同一人物的 [姿态]。
2. 将与人物相关的 [场景或象征物] 融入剪影内部，用墨色晕染、飞白和负空间自然连接两层。
3. 采用克制的东方水墨与写实电影光，只放置少量 [标题或姓名]，保持留白、身份清晰和边缘自然。

## 8. 自然科普海报（nature-science-poster）

**适用场景**  
用于稀有动物、昆虫、爬行动物、植物和其他自然主题的高级科普海报。适合自然科学 PPT、展览页和需要“主体先于信息”的竖版传播画面。

**视觉结构 / 构图**  
使用 9:16 竖版、纯白或极浅灰背景。顶部放物种名与定位副标题，中部让主体占据约一半到七成画面并带有真实接触阴影，底部用四列极简信息区展示四个短知识点，信息列之间用细线分隔。

**风格 / 材质**  
采用高端编辑和产品发布会式的干净语言，主体像高级摄影或精细 3D 渲染一样锐利。毛发、鳞片、甲壳、皮肤褶皱和羽毛要有可信纹理；强调色只用于小图标和标签，不用卡片、厚边框或大色块填充。

**文字与标签策略**  
中文物种名是最大标题，副标题、英文名、分布区和四个特征标签使用短句。每个信息列控制在一到三行，底部可有一句克制总结；准确的物种名、单位和分布应列为硬文本，背景不要出现随机 logo。

**关键约束 / 常见失败**  
常见失败是主体太小、儿童科普风、旧纸背景、卡片网格、百科正文过密、文字压住动物和解剖或纹理错误。先锁主体比例与白底，再分配四个标签；不要用密集装饰补空白。

**可组合提示词片段**

1. 在纯白或极浅灰背景上放大展示 [物种]，让主体占据画面约五到七成并具有可信的真实纹理。
2. 顶部保留准确物种名与一句副标题，底部只用四列细线信息栏承载四个短知识点。
3. 使用柔和棚拍光和中性编辑排版，颜色只点缀图标与标签，拒绝卡片、厚边框、卡通感和密集正文。
