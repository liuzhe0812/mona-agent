# 接口与信息模板

按需读取 1–3 项：界面截图、信息图和科学尺度图。它们都强调平台或信息结构、模块数量、阅读顺序与短标签；先确定图像的职责，再补视觉系统。

详细目录见 template-catalog.md；当前文件只包含本组条目，生成时按需读取相关条目即可。

## 1. UI 截图系统（ui-screenshot-system）

**适用场景**  
用于 App、网页、仪表盘、社交平台截图、直播间界面和产品概念展示。适合需要把功能、平台特征和界面层级一起呈现的 PPT 配图。

**视觉结构 / 构图**  
先固定平台、视口比例和页面骨架，再分出顶部系统区、主内容区、操作区或底部 Tab。卡片流、双栏、数据面板和直播叠加层都应有明确边界；直播评论、商品卡或弹幕可以增加真实感，但不能遮挡主播面部或主要数据。

**风格 / 材质**  
根据产品选择浅色、深色、极简、科技或拟物语言。面板使用克制的层级、细边界和一致的圆角；字体、图标、状态色和间距应像同一套设计系统，内容图片才承担摄影或插画质感。

**文字与标签策略**  
锁定平台名称、页面标题、关键按钮、核心数值和必要的账号信息，文字越少越容易准确。其余模块用短标题、数字和一两词状态标签，要求可读且不出现随机占位文本；平台特有的状态栏、认证标记、互动动作要与目标平台对应。

**关键约束 / 常见失败**  
常见失败是平台特征混搭、手机比例被默认成 9:16、信息层级过多、文字乱码、界面覆盖主体，以及把直播画面做成普通海报。一次只锁定一种平台和一种布局；若重点是准确文字，应减少文本量并把复杂正文留给后期排版。

**可组合提示词片段**

1. 先锁定 [平台]、[画幅比例] 与 [布局骨架]，让系统栏、内容区和操作区具有清楚的层级边界。
2. 以 [核心功能或数据] 作为唯一视觉焦点，使用少量对齐卡片和足够留白保持界面干净。
3. 只保留 [标题、按钮、关键数值] 等必要短文本，要求平台控件真实、字面可读且不出现乱码。

## 2. 信息图引擎（infographic-engine）

**适用场景**  
用于流程说明、关系图、技术解释、时间线、知识卡和教育型信息可视化。适合把复杂主题压缩为一张可扫描的 PPT 页面或社媒图。

**视觉结构 / 构图**  
先设定标题区，再限制为三到五个模块；模块之间用流程箭头、连接线、对比色或空间顺序表达关系。每个模块有统一的图标、短标题和说明位置，整体沿网格对齐，不让装饰元素抢过信息流。

**风格 / 材质**  
可采用专业报告、科学图谱、科普插画或低饱和编辑风。图标保持同一笔画或同一 3D 视角，背景可用极浅纸张纹理、纯色或中性暗底；颜色承担分类和方向提示，不用高饱和色填满所有区域。

**文字与标签策略**  
主题必须具体，受众和模块数先于风格词。标题、模块名、数字和箭头标签使用短语；正文只保留一到两句关键说明，长段论证交给文档正文，不让图片模型排版大块文字。

**关键约束 / 常见失败**  
常见失败是模块过多、箭头关系不明、图标风格不一致、装饰大于内容，以及模型生成无法阅读的长文。先锁信息结构和数量，再补颜色与材质；需要严格数据时，应把数字和单位列为硬约束并减少非必要文案。

**可组合提示词片段**

1. 把 [具体主题] 拆成三到五个互不重叠的模块，并用单一方向的信息流连接它们。
2. 每个模块只放一个图标、一个短标题和一条核心说明，全部沿统一网格对齐。
3. 采用 [专业报告或科普图谱] 的克制配色，让颜色只承担分类、对比和路径提示。

## 3. 科学尺度缩放图（scientific-scale-diagram）

**适用场景**  
用于从微观到宏观展示同一主题的尺度变化，例如材料结构、生物组织、生态系统或宇宙层级。适合科普封面、课堂图解和科学主题 PPT。

**视觉结构 / 构图**  
按尺度递进排列六到八个圆形或六边形单元，用细线连接从小到大的观察路径。每个单元同时呈现尺度名称、单位或倍率和对应的细节渲染；单元的视觉尺寸与层级应有变化，不能把所有尺度画成相同大小。

**风格 / 材质**  
使用科学编辑图谱、精准微距光和清晰的 3D 或剖面细节。背景可为白色、浅灰或带轻微纸纹的中性底，微观对象强调表面和结构材质，宏观对象保留环境尺度感。

**文字与标签策略**  
主标题只需表达主题与“每个尺度”的概念；每格使用三到五个词的洞察、单位和倍率。标签必须短、位置固定、顺序可追踪，避免把解释性段落压缩进圆框。

**关键约束 / 常见失败**  
常见失败是所有框大小相同、尺度顺序不明、不同尺度画成同一类特写，以及使用通用放大镜图标代替真实层级。明确起点、终点和倍率，禁止长正文与无关装饰；如果数据不确定，宁可减少尺度数量也不要编造精确数字。

**可组合提示词片段**

1. 将 [主题] 按真实尺度从微观排到宏观，使用六到八个递进单元和一条清楚的连接路径。
2. 每个单元同时显示 [尺度名称]、[单位或倍率] 与该层级的高细节结构，单元大小随尺度关系变化。
3. 使用科学编辑图谱的精准光线和留白，拒绝通用放大镜、长段正文与重复的框架造型。
